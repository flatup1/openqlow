# JAPAN MMA JIU-JITSU（旅行者向け体験サイト）

成田空港の近くで、外国人旅行者に「MMA柔術」体験（道着なし。足関節・ヒールフック・三角絞め・腕十字。打撃とスパーリングはなし）を案内する1ページのサイトです。コースは30分・60分・90分の3つ。
運営は FLATUP GYM。言語は英語・繁体字・簡体字・韓国語の4つ（日本語版は2026-11-14にJIN判断で廃止）。

## トップ画像の作り方（写真 → 墨絵風）

1. インストラクター2人で技の形を撮る。マットから約30cmの高さ、攻める側の頭側から斜め45度。ロゴのない服で。
   - **ジムの緑の壁とマットの前で撮るのが一番確実**（緑を抜くので、白い服・バンテージ・肌が残る）。緑や迷彩の服は避ける。
   - 白い壁の前で撮る場合は、白い服が壁と一緒に消える。白い服は避ける。
2. 人物画像に変える（緑の壁と白いマットが両方写るなら `--bg auto`、緑だけなら `--bg green`、白い壁なら `--bg white`）:
   `python3 tools/ink.py 写真.jpg tools/out/figure.png --bg auto`
   - 床に寝た技を上から撮った写真は、2人が黒いかたまりに重なって形が読みにくくなる。低い位置から、緑の壁を背にして撮るのがよい。
   - 画面の端で体が切れているときは `--fade-right 0.07` や `--fade-bottom 0.1` で、墨がかすれるように消せる。
   - ロゴが写ったら `--erase "x0,y0,x1,y1"` で消せる（元写真の座標）。
3. `figure.png` をWebPにして `images/hero-figure.webp` に上書きする（例: `python3 -c "from PIL import Image; Image.open('tools/out/figure.png').save('images/hero-figure.webp', quality=82)"`）。
4. 見本やシェア用の1枚絵が要るとき: `python3 tools/compose.py 人物PNG 円相PNG 筆文字フォント.ttf 出力.png 2560 1440`

必要なもの: Python 3、`pip install opencv-python-headless pillow numpy`。
