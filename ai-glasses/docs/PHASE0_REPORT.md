## 次の一手

**`ai-glasses/core/` に、実機なしでテストできる「転送の心臓部」をKotlinで作る。**

中身は4つだけです。

1. `media.config`（グラスが返すファイル一覧）を読み取る処理
2. 同じ写真を二重に保存しない仕組み
3. 途中で切れたときに続きから再開するためのキュー
4. エラーを「容量不足・通信切断・Wi-Fi失敗・HTTPエラー・権限不足」に分ける処理

- **実機不要**（この環境の Gradle で単体テストが回る、確認済み）
- **費用0円**
- ここが完成すると、Android版でもiOS版でも同じ仕様をそのまま使えます
- 転送の一番こわい部分（重複・データ破損・再開）を、実機を待たずに先に潰せます
