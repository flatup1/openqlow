## 制作の進め方

```
1. 00_SERIES_MASTER_CONTEXT.md で制約を確認
2. 各話の 10_REFERENCE_PROMPTS_READY.md でキャラ基準画像を生成
   → 人間承認（ここまで無料）
3. 720p プレビューで全カット生成 → 構図確認
   → 人間承認（ここまで低コスト）
4. 🔴 本番生成（課金開始）— オーナー承認が必要
5. 各話の 07_EDIT_DELIVERY.md で編集
6. 02_QA_CHECKLIST.md §8 の最終ゲート
7. 各話の 08_TESTING_METRICS.md で公開・計測
```

**費用が発生するのはステップ 4 から。** それ以前で止められる設計です。
