# シリーズ配信計画（EP09–EP13）

**ステータス**: 案。配信順序と日程はオーナー承認後に確定。

---

## 1. 配信順序の 3 案

### A案: 物語順（推奨）

EP09 → EP10 → EP11 → EP12 → EP13

- **利点**: 「相手を見る」3話 → 「自分を見る」2話 の弧が伝わる。EP13 が中核コピーの着地になる
- **欠点**: 最初の EP09 が「勝ち負け三部作」の続きのため、単体では文脈が弱い
- **向く場面**: フォロワーに継続視聴してもらう前提の運用

### B案: 強い順（初速重視）

EP13 → EP12 → EP11 → EP10 → EP09

- **利点**: EP13（昨日の自分）が最も普遍的で、初見に刺さりやすい
- **欠点**: 物語の積み上げが崩れる
- **向く場面**: 広告出稿で新規リーチを最優先する場合

### C案: テスト先行（推奨・低リスク）

EP13 と EP12 の 2 本を先に出して反応を見る → 良い方の型で残り 3 本を作る

- **利点**: 全話を作り切る前に方向修正できる。**生成コストの無駄が最小**
- **欠点**: 公開間隔が空く
- **向く場面**: 生成予算が確定していない現状に最も適合

> **推奨: C案**。理由は §5 の通り、5 話分の本番生成を先に走らせると、外れたときの損失が大きいため。

## 5. 生成コストの考え方

正確な単価はツール選定後に確定するが、判断の型は以下。

```
1話 = 静止画 10カット × 試行3回 + i2v 10カット × 試行2回
　　≒ 静止画30回 + 動画20回

5話まとめて本番生成すると、外れたときに 5話分が無駄になる。
→ C案（2話先行）なら損失は 2話分に収まる。
```

**やること**: 本番生成の前に、必ず 720p プレビューでオーナー確認を取る（`01_TECHNICAL_SPECS.md` §2）。

---

## 6. 中止・方向転換の判定

以下のいずれかに該当したら、残りの話の生成を**止めて**設計に戻る。

- 3秒視聴維持率が 40% を下回る（フックが機能していない）
- 保存率が 0.5% を下回る（感情が動いていない）
- コメントに不安・違和感の指摘が複数出る（ブランド毀損リスク）
- キャラの一貫性が担保できず、再生成コストが想定の 2 倍を超える

**止めない条件**: 数値が悪くても、世界観（優しさ・余白・夜のマスコット）は最初のラウンドでは崩さない。崩す判断はオーナーのみ。
