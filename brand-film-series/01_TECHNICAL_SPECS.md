# シリーズ共通 技術仕様（EP09–EP13）

各話の `07_EDIT_DELIVERY.md` は本ファイルを参照する。ここが技術仕様の唯一の正本。

---

## 1. マスター仕様

| 項目 | 値 | 理由 |
|---|---|---|
| 解像度 | **1080×1920（9:16）** | リール/ショート/TikTok が主力 |
| フレームレート | **24fps** | アニメの見た目に最も近い。EP01 と統一 |
| カラースペース | **Rec.709 / Gamma 2.4** | Web配信の標準。HDR は使わない |
| ビット深度 | 中間 **10bit** → 納品 8bit | グラデーションのバンディング防止 |
| 中間コーデック | **ProRes 422 HQ**（または DNxHR HQ） | 生成物の再エンコード劣化を防ぐ |
| 納品コーデック | **H.264 High Profile** | 全媒体互換 |
| 目標ビットレート | **12 Mbps**（30秒以下は 14 Mbps 可） | 圧縮ノイズ回避 |
| 音声 | AAC 320kbps / 48kHz / ステレオ | — |
| ラウドネス | **-14 LUFS**（True Peak -1.0dBTP） | SNS の自動音量調整基準 |

### 横位置バリエーション（HP・YouTube通常用）

- 1920×1080（16:9）を**別書き出し**で用意。9:16 からの単純クロップ禁止（キャラの頭が切れる）
- 16:9 が必要なカットは、生成時に横構図で**別途生成**する

## 2. AI生成の解像度戦略

生成コストを抑えつつ品質を守るため、**2段階生成**を必須とする。

```
Step 1: プレビュー生成（720p / 短尺）
        → 構図・表情・動きを確認。ここで却下すれば本番費用が発生しない
Step 2: 本番生成（1080p以上）
        → 承認済みプレビューと同一プロンプト + seed 固定
Step 3: アップスケール（必要時のみ）
        → 1080p で足りない場合のみ。グレーディングより先に実行する
```

**重要**: アップスケールは必ず**カラーグレーディングより前**。順序を逆にするとノイズが増幅される。

---

## 3. カラーグレーディング手順

AI生成映像は「黒が浮く（milky shadows）」傾向がある。以下の順で処理する。

| 順 | 工程 | 内容 |
|---|---|---|
| 1 | アップスケール | 必要な場合のみ、グレーディング前に完了させる |
| 2 | ショットマッチ | 全カットの露出・ホワイトバランスを揃える（AI補助可） |
| 3 | 黒の締め | 浮いたシャドウを意図的に沈める。ただし潰し過ぎない |
| 4 | 話別LUT適用 | 下表の 2 本のみ作成し、該当カット全部に同一適用 |
| 5 | 個別微調整 | 核ショットのみ +5% 明度で「気づきの光」を強調 |

### 話別 LUT（各話 2 本まで）

| 話 | LUT-A（日常・ジム） | LUT-B（象徴世界・夜） |
|---|---|---|
| EP09 | ウォームゴールド（勝利の熱） | クールグレー→ゴールド遷移 |
| EP10 | ウォームピンク（感謝） | ブルー月光＋ピンク |
| EP11 | グリーン＋ベージュ（希望） | グレー→ウォームグリーン |
| EP12 | パープル夕光（内省） | グレー→ゴールドパープル |
| EP13 | 黄金夕光（成長） | グレー→ウォームゴールド |

**禁止**: ティール&オレンジ等の広告的グレーディング。彩度・コントラストは控えめに保つ。

## 4. セーフエリア（全媒体共通）

| 領域 | 余白 |
|---|---|
| 上部 | 250px |
| 下部 | 420px |
| 左右 | 60px |

- この範囲に**字幕・ロゴ・キャラの顔**を置かない
- 字幕の基準ライン: **下端から 480px 上**
- 核ショットのキャラの目線は**画面中央 ±200px** に置く（UI被り回避）

## 5. 媒体別書き出し

| 媒体 | 尺 | 版 | 備考 |
|---|---|---|---|
| Instagram リール | 30秒（主力）/ 15秒 | 字幕焼き込み | カバー画像は各話の核ショット静止画 |
| Instagram ストーリーズ | 15秒 | 字幕焼き込み | リンクスタンプ → LINE登録LP |
| TikTok | 30秒 / 15秒 | 字幕焼き込み | ネイティブ字幕は使わず焼き込みで統一。ハッシュタグ3個以内 |
| YouTube ショート | 30秒 | 字幕焼き込み | 概要欄に体験案内とLINEリンク |
| YouTube 通常 / HP埋め込み | 45〜60秒 | クリーン版 + CC字幕(.srt) | 16:9 別書き出し |
| LINE VOOM | 30秒 | 字幕焼き込み | 投稿文200文字以内・3文程度・絵文字1〜2個 |
| 静止画（リッチメッセージ） | — | 核ショット静止画 | 動画と同一世界観 |

各尺で**「字幕焼き込み版」と「クリーン版」の2種**を必ず書き出す。

## 6. 命名規則

```
FUG_EP<話数>_<尺>s_<版>_<エンドカード>_v<番号>.<拡張子>
```

| 記号 | 値 |
|---|---|
| 話数 | 09 / 10 / 11 / 12 / 13 |
| 尺 | 15 / 30 / 45 / 60 |
| 版 | `sub`(字幕焼込) / `clean`(字幕なし) |
| エンドカード | `A` / `B` / `C` |
| 番号 | v1, v2, … |

**例**: `FUG_EP12_30s_sub_A_v1.mp4` / `FUG_EP13_60s_clean_B_v2.mov`

### 素材の命名

```
FUG_EP<話数>_<カットID>_<種別>_v<番号>.<拡張子>
例: FUG_EP12_C07_img_v3.png / FUG_EP12_C07_i2v_v1.mp4
```

## 7. アーカイブ

| 保管対象 | 形式 | 場所 |
|---|---|---|
| 採用カットの元画像 | PNG（無圧縮） | `brand-film-ep<n>/assets/img/` |
| 採用カットの i2v 出力 | ProRes 422 HQ | 外部ストレージ（リポジトリに置かない） |
| 編集マスター | ProRes 422 HQ | 外部ストレージ |
| 納品版 | H.264 | 外部ストレージ + 媒体 |
| プロンプト最終形 | Markdown | `10_REFERENCE_PROMPTS_READY.md` |

**リポジトリに動画バイナリを置かない**（容量とレビュー性のため）。画像は 1 カットあたり採用 1 枚まで。

## 8. エンドカード共通仕様

- 背景: `#0A0A0C`（完全な黒ではなく夜の闇）
- ロゴ: FLATUP GYM（白）をゆっくりフェードイン
- コピー: 各話のテロップ最終行 + `canon.ts` のタグライン
- 最終行: **「怒鳴らない。比べない。置いていかない。」** は全話共通で固定
- 音: ピアノの最後の1音の残響のみ
- 料金・電話番号・URL文字列は**載せない**
