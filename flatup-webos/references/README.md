# references — 参考サイト資料の置き場

オーナー（JIN）が以下を準備する:

- 参考サイトURL
- GoFullPage等で撮影したフルページスクリーンショット
- 現在のFLAT UP GYMサイトのスクリーンショット
- 良いと思ったUI / アニメーション / コピー / 構成

## 扱い方（重要）

AIはこれらを **「コピーする対象」ではなく「デザイン原則を抽出する資料」** として扱う。

抽出の観点の例:

| 参考 | 抽出する原則 |
|---|---|
| Apple | 情報量・余白・スクロール |
| Nike | 感情・ストーリー |
| Porsche | 映画的没入感 |
| Nothing | 未来感・タイポグラフィ |
| ゲームUI | 選択・進行・成長感 |
| Typeform | 一問一答UX |

複数サイトの長所を抽象化し、**FLAT UP独自のUI**へ再構成する。
既存作品のキャラクター・UI・ロゴ・音楽・デザインの直接模倣は禁止。

## 置き方のルール

- URLとメモはこのディレクトリの `.md` ファイルに記録する。
- 大きな画像・動画の生データはGit管理しない（flatup Vaultの運用ルールと同様）。
  スクリーンショットは共有ドライブ等に置き、ここにはリンクと「何が良かったか」のメモを残す。
- 他社サイトの素材をWebOSへ流用しない。
