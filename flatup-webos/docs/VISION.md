# VISION — FLAT UP WebOS

## North Star（正式記録）

> **世界一初心者に優しい格闘技ジム FLAT UP GYMへ、
> 安心して一歩を踏み出せる、世界一優しいWebOSをつくる。**

FLAT UP GYMは「世界一初心者に優しい格闘技ジム」を目指している。
このWebOSはそのWeb版であり、ユーザーを迷わせず、必要な情報だけを必要な瞬間に届け、
安心して最初の一歩＝体験予約まで進める体験を提供する。

## ブランド感情（Brand Emotions）

WebOSがユーザーに感じさせるべき感情を、以下のとおり定義する。

| 感情 | 意味 |
|---|---|
| **優しさ** | 責めない。急かさない。笑わない。 |
| **安心** | 「怖くない場所だ」と感じられる。 |
| **冒険** | 少しずつ世界が開いていくワクワク感。 |
| **成長** | 「変わっていける」実感。 |
| **仲間** | ひとりじゃない。ジムは主人公を助ける仲間。 |
| **挑戦** | 押しつけない、けれど背中をそっと押す。 |
| **自分にもできそう** | 最重要。すべての導線の出口はここ。 |

## 主人公はジムではない

このWebOSの主人公は、Webサイトでも、ジムでも、インストラクターでもない。

**主人公は、ユーザー本人。**

FLAT UP GYMは「主人公を助ける仲間」という位置づけ。
したがってコピーは「私たちはすごい」ではなく **「あなたにもできる」** を中心にする。

## 成功の定義

> 「格闘技はちょっと怖い」と思っていた人が、WebOSを見終わる頃には
> 「ここなら私でも大丈夫かも」と思えて、そのまま自然に体験予約できる。

そこまでできて初めて成功。数値上の最重要KPIは **体験予約への到達率**（→ ANALYTICS.md）。

## 判断基準（すべての機能・デザイン・文章・演出に適用）

1. これはユーザーを安心させているか？
2. これはユーザーを迷わせていないか？
3. これは体験予約までの心理的負担を減らしているか？

かっこよくても不安を増やす機能は不要。技術的に高度でもユーザーを迷わせる機能は不要。

## 合言葉

> 見せすぎない。聞きすぎない。迷わせない。同じことを二度聞かない。
> 必要なときに、必要なことだけ。主役はユーザー。
> 小さく完成させて、大きく育てる。
