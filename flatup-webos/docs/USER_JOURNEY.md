# USER_JOURNEY — 体験設計

## 従来型サイトとの違い

```text
従来型サイト:
  閲覧 → 大量の情報 → ユーザー自身が探す → 比較する → 迷う → 予約

FLAT UP WebOS:
  訪問 → 優しく質問 → 選択 → ユーザーを理解 → 不要情報を消す
  → 必要な情報だけ見せる → 安心 → 相談 → 体験予約
```

これは「情報を全部並べるホームページ」ではない。
質問に答えるだけで「その人専用に編集されたFLAT UP GYM」が現れる体験である。

## サイトではなく「優しい冒険」

世界観にはRPG的な思想を取り入れる。
ただし、Dragon Quest・Pixar・Toy Story等の既存作品のキャラクター・UI・ロゴ・音楽・
デザイン等を直接模倣してはいけない。参考にするのは抽象的な体験設計だけ:

冒険 / 成長 / 仲間 / 選択 / 発見 / 安心 / 少しずつ世界が開く感覚 /
主人公が一歩踏み出す体験 / 温かい3D世界 / 映画的なストーリーテリング

完全オリジナルのFLAT UP GYM世界観として構築する。

### RPG的演出の初期範囲（作り込みすぎない）

- 選択すると次の世界が開く
- 柔らかいトランジション
- 小さな成功感
- 次に進みたくなるコピー
- 「冒険を始める」程度のニュアンス

ゲームそのものにしない。UXの比喩としてRPGを使う。

## ファーストビューの思想

最初から料金表・クラス一覧・長文・メニューを大量表示しない。
最初は非常にシンプルにする。

```text
ようこそ。

ここは、
強い人だけの場所ではありません。

あなたに合った道を、
一緒に探します。

あなたは、誰のために来ましたか？
```

そして選択肢へ進む。

## 感情のジャーニー

| 段階 | ユーザーの感情 | WebOSがすること |
|---|---|---|
| 訪問 | 「格闘技ってちょっと怖い」 | 優しい言葉で迎える。情報を出しすぎない |
| Q1〜 | 「答えるだけでいいんだ」 | 1タップの質問。責めない選択肢 |
| 分岐 | 「自分のことを分かってくれてる」 | 回答に応じて世界を変える |
| 結果 | 「私でもできるかも」 | 専用ページ。断定せず、そっと提案 |
| 相談 | 「聞いてみようかな」 | AIコンシェルジュ。同じことを二度聞かない |
| 予約 | 「行ってみよう」 | 心理的負担の少ない体験予約CTA |

## 結果画面の思想 —「その人専用のページ」

質問終了後に単なる診断結果を表示するのではなく、
**あなた専用に編集されたFLAT UP GYM** を見せる。

- 「あなたには、こんな始め方が合いそうです。」という優しい言葉から始める。
- 断定しすぎない。「あなたは○○タイプです！」のような診断サイト的な押し付けは避ける。
- そのユーザーに関係のない情報は、原則として前面に表示しない。

## キッズ保護者ルートの二層UX

キッズルートでは **子どものワクワク感 + 保護者の安心感** の二層UXにする。
保護者が読む文章は安心・安全・礼儀・成長を、子どもに見せる要素は楽しさ・冒険を担う。
