# DESIGN_SYSTEM — Gentle Adventure

## 方向性

**Gentle Adventure（優しい冒険）**

目指すのは「未来的 × 映画的 × RPG的 × 温かい × 優しい」。
ただし優先順位は:

> **優しさ > 未来感 > 派手さ**

「サイバーで冷たいサイト」にはしない。

## キーワード

Warm / Emotional / Cinematic / Friendly / Soft / Premium /
Simple / Playful / Modern / Immersive

## 禁止事項

- 威圧感
- 血・暴力の強調
- 黒赤だけの典型的格闘技デザイン
- 過度な煽り
- 情報過多
- 自動再生音声
- 読めない文字
- 重すぎる3D

## コピーライティングの方向

| ✕ 使わない | ○ 使う |
|---|---|
| 強くなれ | 始めてみませんか |
| 限界を超えろ | あなたのペースで大丈夫 |
| （威圧・煽り全般） | 初心者歓迎 |
| | ◎ 初めての人のために作った場所です |

ただし、過剰に弱々しいブランドにはしない。
**「優しい」と「かっこいい」を両立する。**

## カラー・トーン（Phase 1初期値）

既存LP（`openqlow/flatup-lp/index.html`）のトーンを引き継ぐ:
クリーム系の背景・グリーン基調・ピンク/イエローのアクセント・ダークモード対応。
黒赤の格闘技的配色は使わない。正式なトークン定義はPhase 2で整備する。

## レスポンシブ優先順位（モバイルファーストは最重要要件）

1. **iPhone（最優先）**
2. Android
3. Tablet
4. Desktop

PCから作ってスマホへ縮小する思想は禁止。スマホから設計する。

スマホ操作の具体基準:

- 片手（親指1本）で操作できる。主要ボタンは画面下半分寄りに置き、位置を迷わせない
- 選択肢は大きなタップ領域（最低44px、標準56px）
- 文字入力を極力減らす（1タップ選択が基本）
- 1画面1質問。スクロール量を必要以上に増やさない
- 読ませすぎない
- 表示速度を優先する
- **3Dやアニメーションによって操作性を落とさない**（落ちるなら削除）

## パフォーマンス（映画的でも速度を犠牲にしない）

必須: lazy loading / 動画最適化 / responsive images / 適切なキャッシュ /
依存削減 / Core Web Vitals意識 / JS肥大化防止 / `prefers-reduced-motion` 対応

## アクセシビリティ

アニメーションを使っても以下を守る:

- キーボード操作
- aria属性
- コントラスト
- focus state
- reduced motion
- 読みやすいフォント
- 十分なタップターゲット

## RPG的演出の範囲（Phase 1〜2）

最初からゲームUIを作り込みすぎない。まずは:

- 選択すると次の世界が開く
- 柔らかいトランジション
- 小さな成功感
- 次に進みたくなるコピー
- 「冒険を始める」程度のニュアンス

だけで十分。ゲームそのものにしない。UXの比喩としてRPGを使う。
既存作品（Dragon Quest / Pixar / Toy Story等）の直接模倣は禁止。
