## 公開前に確認すること

1. **ダウンのルール**：旧ポスターは「2回ダウンで、そのラウンドは終了」、2026版は「試合全体で2回目のダウンで試合終了」。動画は2026版に合わせた。
2. **「※確認用・配布前」の表示**：主催者・審判の最終確認が済んだら、`v2/index.html` の `#note` を消して書き出し直す。
3. **音**：入っていない（無音トラックのみ）。BGMは各SNSの音源ライブラリから選ぶのがおすすめ。声を入れる場合は下の台本を使う。
4. **v2で省いたもの**：首相撲のヒザ1回まで、10カウント、防具（レガース・胴当て）、反則の段階、救護体制。v2の最後で「くわしくはルールブック」に案内している。

## 作り直し方（v2）

必要なもの：Node.js＋Playwright（Chromium）、ffmpeg、Python（Pillow・opencv-contrib-python-headless）、Google Fontsに届くネット接続。

```bash
cd uizin-rule-short/v2
python3 prepare_assets.py <旧ポスターのPNG>   # assets/ にイラストを切り出す（済み）
node render.mjs preview                      # 各場面の静止画だけ作って確認
node render.mjs                              # 全コマを書き出して ../uizin-2026-rule-short-v2.mp4 を作る
```

文字・秒数は `v2/index.html` で直す（各場面の `data-dur` が秒数）。
