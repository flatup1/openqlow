## 30秒版・シーン構成（基本構成）

### 全体フロー

```
S1-2（練習と労力） 5s → S3-5（気づきのプロセス） 9s → S6（役割交代） 5s → S7（エンディング） 5s + 6s テロップ
```

## シーン別詳細（30秒版ベース）

### S1｜練習フロア・夕方（ハルナの集中）

**尺**: 4秒  
**アクション**: ハルナが連打、コウが腕を震わせながら支える

**撮影指示**
- カット1（4s）: ハルナの集中した顔 + コウの震える腕

**表情指示**
- ハルナ: 集中しきった真剣な顔（周りが見えていない）
- コウ: 腕が震えているが、我慢して支え続ける

**BGM**: 集中力のあるリズム（テンポよく）

**効果音**: 連続する打撲音、水音

**子に伝える**: 頑張っているとき、周りが見えなくなることがある

---

### S2｜練習フロア・夕方（コウの疲労・見えない）

**尺**: 2秒  
**アクション**: コウが腕をさすり、ハルナが振り向かずに去る

**撮影指示**
- カット1（1s）: コウが腕をさするアップ（疲れが可視化）
- カット2（1s）: ハルナが水を飲みに行く（相手を見ていない後ろ姿）

**表情指示**
- コウ: 腕をさすりながら少し困った顔（苦しいが言わない）
- ハルナ: 「ありがとうございました」と言うが、振り向かない

**BGM**: 変わらず

**効果音**: 腕をさする音、水を飲む音、静寂

**子に伝える**: ありがとうって言っても、相手を見てないことがある

---

### S3｜夜のジム・深夜（ミットの独白）

**尺**: 3秒  
**アクション**: ミットとフラットちゃんが円座で話す

**撮影指示**
- カット1（3s）: ミット + フラットちゃんのミディアム（円座）

**表情指示**
- ミット: 少し疲れたような、でも穏やかな表情
- フラットちゃん: 聞き役に徹し、温かく応答

**BGM**: 温かいピアノ（内省的）

**効果音**: 静かな衣擦れ

**子に伝える**: 支えてくれる人にも、疲れがある

---

### S4｜象徴世界（ハルナの気づき第1段階）

**尺**: 3秒  
**アクション**: フラットちゃんが問いかけ、ハルナが思い出す

**撮影指示**
- カット1（3s）: ハルナ + フラットちゃんのミディアム（灰色空間）

**表情指示**
- ハルナ: 最初は戸惑い → 思い出して気まずさが表情に出る
- フラットちゃん: 責めずに、静かに問い続ける

**BGM**: 静かに温度が上がる

**効果音**: 静寂、静かな呼吸

**子に伝える**: 夢中になると、周りが見えなくなることがある。気づけたら、直せる

---

### S5｜象徴世界・心の技レッスン（★核ショット）

**尺**: 6秒  
**アクション**: ミットの問いかけで、ハルナの表情が気づきから決意に変わる

**撮影指示**
- カット1（6s）: ハルナ + ミット + フラットちゃんの3人フレーム（象徴世界）

**表情指示**
- ハルナ: 
  - 0-2s: 戸惑い、気づきの途中
  - 2-4s: はっとした表情（「打つ場所がない」の問いで目が開く）
  - 4-6s: 決意の表情に変わる（相手の大切さを実感）
- ミット: 温かく見守る（責めない）
- フラットちゃん: 微笑む（ハルナの気づきを喜ぶ）

**BGM**: 静かな響き → 朝日のように柔らかく上向く

**効果音**: 静寂から、環境音が徐々に入る

**スローモーション気味**: 表情の変化を強調

**子に伝える**: 相手がいてくれるから、練習できる

**🔴 核ショット（ここが本話の最重要）**
- ハルナが「相手の存在」の価値を実感する瞬間
- 「相手がいるから、できることがある」という本質的な気づき
- 表情だけで「人格的変化」が明確に映る

---

### S6｜練習フロア・翌日（役割交代・実行）

**尺**: 5秒  
**アクション**: ハルナがコウの顔を見て「今度は私が持つね」と言い、役割交代

**撮影指示**
- カット1（2.5s）: ハルナがコウの顔を見て挨拶・申し出
- カット2（2.5s）: ハルナがミットを構え、コウが打つ対等な2ショット

**表情指示**
- ハルナ: 真剣な表情（約束を守る意志）
- コウ: 最初は驚く → 信頼に満ちた表情に変わる

**BGM**: 温かく前向き

**効果音**: 練習前の静かな空気、ミット音、拍手音

**子に伝える**: 今度は自分が支える番になってみる

**重要**: 役割交代という**具体的な行動**で「相手を見る」ことを実演

---

### S7｜夜のジム・エンディング

**尺**: 5秒（本編） + 6秒（テロップ）

**分割**
- S7a（3s）: ミット + フラットちゃんの円座での言葉
- S7b（2s）: ハルナ + コウが交代でミットを持ち合う後ろ姿シルエット
- テロップ（6s）: メッセージ + ロゴ

**表情指示**
- ミット: 穏やかな笑顔
- フラットちゃん: 満足げな微笑み

**BGM**: 温かく余韻を残す

**テロップ内容**
```
相手がいてくれるから、練習できる。
「お願いします」「ありがとうございました」には、そんな意味がある。

今日も、小さな優しい強さを。

怒鳴らない。比べない。置いていかない。
FLAT UP GYM
```

**撮影指示**
- 夜のジム全景（星型フロア、ピンク月光）
- ミット + フラットちゃん（円座）
- 手前にハルナ + コウの後ろ姿シルエット（交代する動き）

## 15秒版への圧縮（参考）

```
S1-2（2s） + S4-5（4s） + S6（2s） + S7（3s+3s テロップ）= 15s
```

**削減ポイント**
- S3（ミット独白）をカット
- S4: フラットちゃんの問いかけを短縮
- S5: 核ショットを 3s に短縮（ただしループ保持）
- S6: リアクションを最小限に

---

## 45秒版への拡張（参考）

```
S1-2（6s） + S3（4s） + S4-5（12s） + S6（8s） + S7（9s+3s テロップ）= 45s
```

**追加要素**
- S1-2 を分離・拡張（ハルナの集中 → コウの疲労を詳しく）
- S3 を独立シーン化（ミットの独白をじっくり聞かせる）
- S4-5 の間延びを活かす（気づきのプロセスを丹念に）
- S6 を拡張（ハルナとコウの会話、役割交代の細部）

## タイミング・リズム設計

### 「労力が見えない」の間の使い方

```
S1 終盤（1.5s）: ハルナが集中している
    ↓
    【1s の間】: 見えない疲労が隠れている
    ↓
S2 開始（0.5s）: コウが腕をさする
```

この**間の質感**が重要。  
ハルナは気づかないが、支える側は消耗している瞬間を **テンポよくではなく、ゆったり** 見せる。

### 気づきのプロセスの間

```
S4「コウの腕、見てた？」（1s 短い質問）
    ↓
    【1s の間】: ハルナが思い出す
    ↓
S5「相手がいてくれるから」（4s 核ショット、時間をかける）
```

このプロセスで、単なる「頭での理解」ではなく「人格的な変化」を見せる。

## オーディオ設計

### BGM トランジション

| シーン | BGM | 意図 |
|---|---|---|
| S1 | 集中力のあるリズム | 練習への没頭感 |
| S2 | 変わらず（静寂追加） | 労力の見えなさ |
| S3 | 温かいピアノ | ミットの内面性 |
| S4 | 静かに温度が上がる | 重圧感から解放へ |
| S5 | 朝日のように上向く | 決意の瞬間 |
| S6 | 温かく前向き | 関係が戻る |
| S7 | 温かく余韻を残す | 結びの余韻 |

### 効果音

- **S1**: 連続する打撲音（集中）
- **S2**: 腕をさする音、水音（静寂を強調）
- **S3**: 静寂 + 衣擦れ（瞑想的）
- **S4-5**: 静寂 + 静かな呼吸（内面性）
- **S6**: 練習前の空気感、ミット音（日常が戻る）
- **S7**: 静か + 柔らかい BGM
