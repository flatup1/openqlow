## 制作フロー

1. `10_REFERENCE_PROMPTS_READY.md` §1 でキャラ基準画像を生成 → **人間承認**
2. 6方向ポーズを生成 → `../brand-film-series/02_QA_CHECKLIST.md` で一貫性チェック
3. 720p プレビューで全10カットを生成 → 構図確認 → **人間承認**
4. 本番解像度で再生成（seed 固定）→ `10_REFERENCE_PROMPTS_READY.md` §5 に seed を記録
5. `05_VIDEO_PROMPTS.md` で i2v 生成
6. `07_EDIT_DELIVERY.md` のタイムラインで編集・グレーディング
7. `../brand-film-series/02_QA_CHECKLIST.md` §8 の最終ゲート → **オーナー承認**
8. `08_TESTING_METRICS.md` の設計で公開・計測

**課金が発生するのはステップ 4 から。** それ以前で止められるよう設計しています。

## 本話で特に注意すること

- ハルナが「自分勝手な子」に見えないこと。**気づきであって反省ではない**
- コウの腕の震えを大きくしない。大きいとコミカルになり労力の重さが消える
- 核ショット 6 秒はシリーズ最長。ここでの離脱率が EP11〜EP13 の設計に直結する。最優先で計測する
