EN: No-sparring leg lock technique lessons in English, near Narita Airport.

「日本発祥のASHIKAN」という言い方は、根拠がそろうまで使わない【未確認】。

## 誰に・なぜこれを選ぶか

- 日本に旅行に来る、BJJ・MMA・グラップリング経験1年以上の外国人
- 成田に泊まる前後の日の夜（到着した日の夜や、出国前の夜）に時間がある人
- 普通のビジター参加（初回体験500円・2回目以降3,000円【事実】）との違い：**通常クラスに混ざらない少人数の貸切、足関節だけに絞った105分、英語での1人ずつの修正、自分用の動画のおみやげ**

## 申込から当日まで【案】

1. SNSのプロフィールのリンクから、LINE公式アカウントに友だち追加（LINEを使わない人はInstagramのDMで受ける）
2. LINE（またはDM）の英語の質問で、日程・経験・ケガを聞く
3. 講師が空きと安全を確認して、**人が**予約を確定する（自動返信で確定しない）
4. オンラインで前払い

## 安全ルール【案】

- スパーなし。決まった動きのくり返しと、講師の修正だけ
- ひざをひねるヒールフックは教えない
- 極めはゆっくり、痛む前に止める。タップのルールを最初に英語で説明する
- 英語の同意書（ケガのリスク・撮影）に署名してもらう
- お酒を飲んでいる人、ケガが治っていない人は受けない
- 高血圧・心臓など運動に不安がある人には、事前に医師へ相談するよう案内する
- ケガの保険に入ってもらうようすすめる
- 緊急時：練習を止める → 119番・AED → オーナーへ連絡。近くの病院を先に決めておく
- 健康情報は確認に使うだけ。レッスンが終わったらLINE・DMのケガの回答を消す

## どうやって呼ぶ（広告費0円）【案】

流れ：**SNSで知る → LINEで相談・予約 → 来店 → 口コミ**

1. SNS（Instagramのリール中心）で英語の投稿を、2か月目から週2本（1か月目は無料体験の撮影とGoogleマップの準備だけ）。すべての投稿に「LINEで予約（QRコード／リンク）」を入れる
   - 米国の人はLINEをあまり使わないと言われる【未確認】ので、InstagramのDMでも受ける。台湾・タイなどの人はLINEのまま
2. Googleマップの英語の説明を整える
3. 来た人にGoogleの口コミを英語でお願いする（お礼の品などの見返りは付けない）
4. 投稿に使う写真・動画は、写る人全員の同意書（安全ルール参照）がそろったものだけ

1. 教える講師（英語で説明できるか）と、紹介できる経歴。1か月目に無料で試してくれる知り合いの外国人がいるか

3. 価格・キャンセル規定・前払いの方法（どの決済サービスか）と返金の手順をオーナーが承認、投稿の担当者を決める
