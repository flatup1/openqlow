## 1. 結論（1分で読む）

**成田空港に近い FLAT UP GYM で、海外の格闘技ファンに「日本の足関節（ASHIKAN）」を、スパーなし・英語・少人数で教える。**

- **まず売るもの**：105分のレッスン（ジムが直接売る。旅行の手配はしない）
- **次に売るもの**：レッスン後に成田を楽しむ「セルフガイド付き1日プラン」（案内だけ。手配・代金の受け取りはしない）
- **最後に売るもの**：宿泊込み3日間ツアー（登録旅行会社が販売。ジムはレッスン部分を卸す）
- **宣伝はSNS、予約はLINE**（米国の人向けにInstagram DMも受ける）
- **3か月で有料6名が目標**。4名以下なら中止、5名なら見直して1か月延長。病院に行くケガが1件出たら一時停止

## 4. なぜ売れるか（根拠）

- 【事実】FLAT UP のビジター料金は初回体験500円・2回目以降3,000円。スタッフ対応は平日10:00〜12:00・18:00〜21:00、日曜・祝日休み（正本 `src/shared/canon.ts`）
- 【事実（外部の記事が出典・広告で使う前に原文を確認）】日本には足関節の長い伝統がある。講道館柔道の初期には足絡み（ashi-garami）があり、のちに試合で禁止。サンボやシュートスタイル、パンクラス、今成正和選手（通称「足関十段」）などが技を磨いてきた（出典：Wikipedia「Ashi garami」、ESPN・ONE の選手紹介 ほか）
- 【注意】「足関節は日本が発祥」とは言えない。キャッチレスリングやサンボでも別に育った。広告では **「日本には足関節の長い伝統がある」** と書く
- 【注意】FLAT UP は今成選手・今成柔術と関係がない。名前を使うときは「関係ありません」と必ず書く
- 【未確認】米国の人はLINEをあまり使わないと言われる → Instagram DMも受ける

**ビジター参加との違い（高い理由）**：通常クラスに混ざらない貸切、足関節だけに絞った105分、英語で1人ずつ直す、自分用の動画と修了証がもらえる。

## 5. 商品（3段階）

### A. ASHIKAN レッスン【案】（最初はこれだけ売る）

| 項目 | 内容 |
|---|---|
| 時間 | 105分（説明15分 → 技の反復70分 → 1人ずつの修正20分） |
| 日時 | 平日19:00〜20:45。21時のスタッフ対応終了【事実】までに片付けまで終わる。土日祝はしない |
| 人数 | グループ2〜4名、または個人1名（講師が相手役） |
| 対象 | 18歳以上、グラップリング経験1年以上（自己申告＋当日講師が確認） |
| 価格 | グループ1人19,800円（約125ドル）／個人29,800円（約190ドル）。ドルは目安 |
| 持ち物 | ラッシュガード・短パン・タオル・水（貸出なし） |
| おみやげ | 修了証、30秒の修正動画（撮影に同意した人だけ） |
| しないこと | スパー、ひざをひねるヒールフック、宿泊・送迎の手配 |

グループが1名しか集まらないときは、個人料金に変えるか、全額返金で中止かを本人が選ぶ。

### B. ASHIKAN Narita Day【案】（レッスン＋自由行動の「案内」）

レッスンの前後に楽しめる成田の見どころを、英語の1枚ガイドで渡す（例：成田山新勝寺、表参道の食べ歩き）。
- ジムは**案内するだけ**。交通・食事・入場の予約や代金の受け取りはしない（旅行業にあたるのを避けるため）
- 価格はAと同じ。ガイドは無料の付録

### C. ASHIKAN 3-Day Tour【案・将来】（宿泊込み）

- **登録旅行会社が販売する**。ジムはレッスン部分を旅行会社に卸す（卸価格は相談）
- 条件：A を3か月続けて、有料6名・口コミ星4以上・病院に行くケガ0件を達成してから始める
- 3日間の中身の例：1日目 到着・休む／2日目 レッスン＋成田観光（旅行会社手配）／3日目 2回目のレッスン（復習と修正）→ 空港

## 7. 安全ルール【案】

- スパーなし。決まった動きのくり返しと講師の修正だけ
- ひざをひねるヒールフックは教えない。極めはゆっくり、痛む前に止める
- 最初にタップのルールを英語で説明。英語の同意書（ケガのリスク・撮影）に署名
- お酒を飲んだ人、ケガが治っていない人は受けない
- 高血圧・心臓などが心配な人には、事前に医師へ相談するよう案内
- スポーツ保険（または格闘技のケガも補償する旅行保険）への加入をすすめる
- 緊急時：練習を止める → 119番・AED【未確認：ジムにあるか】 → オーナーへ連絡。近くの病院を先に決めておく
- 健康情報は確認だけに使い、レッスン後にLINE・DMの回答を消す

## 8. 申込・支払い・キャンセル【案】

1. SNSのリンクから LINE 公式アカウントに友だち追加（LINEを使わない人はInstagram DM）
2. 英語の質問で、日程・経験・ケガを聞く
3. 講師が空きと安全を確認し、**人が**予約を確定する（自動返信で確定しない）
4. オンラインで前払い

| キャンセル | 返金 |
|---|---|
| 3日前まで | 全額 |
| 2日前〜当日の自己都合 | なし |
| 当日、講師が確認してお断りした | 全額 |
| ジムの都合で中止 | 全額 |
| 飛行機の遅れ（航空会社の通知を見せる） | 全額 |

---

## 9. 集客（広告費0円）【案】

流れ：**SNSで知る → LINEで相談・予約 → レッスン → 口コミ → 次の人がSNSで知る**

| いつ | やること |
|---|---|
| 1か月目 | 知り合いの外国人1組に無料で試してもらう。同意を取って写真・動画を撮る。Googleマップの英語説明を整える。英語サイトを整える |
| 2か月目〜 | Instagramリールを週2本。全投稿に「LINEで予約」のQR・リンク |
| 毎回 | 来た人に英語で口コミをお願いする（お礼の品などの見返りは付けない） |

投稿の中身の例：「足関節の30秒ワンポイント」「成田空港から来た〇〇さんの初ASHIKAN」「日本の足関節の歴史を30秒で」

写真・動画は、写る人全員の同意書がそろったものだけ使う。

## 11. 3か月の目標と、やめる条件

| 月 | 目標 |
|---|---|
| 1か月目 | 準備。無料で1組試してもらい、感想をもらう |
| 2か月目 | 有料で2名 |
| 3か月目 | 有料で合計6名（2か月目を含む）、口コミ4件 |

- 3か月の結果で3段階に分ける：**4名以下＝中止**／**5名＝内容を見直して1か月延長（延長後に合計6名に届かなければ中止）**／**6名以上＝継続**
- 口コミの平均が星4未満なら、人数にかかわらず内容を見直す
- 病院に行くケガが1件出たら、すぐ一時停止。オーナーが原因と対策を確認してから再開する。この場合、C（3日間ツアー）の相談は再開後にもう一度3か月、ケガ0件を確認してから始める
- 目標を達成したら、C（3日間ツアー）の相談を登録旅行会社と始める

## 12. リスクと対策

| リスク | 対策 |
|---|---|
| ケガ | スパーなし・ヒールフックなし・経験1年以上・同意書・保険のすすめ |

| 旅行業法違反 | 宿泊・交通・食事の手配や代金の受け取りをジムがしない。宿泊込みは登録旅行会社が売る |
| 通常クラスとぶつかる | 平日夜で、マットと講師が空いている曜日だけにする |
| 来ない | 広告費0円で始め、3か月の判断基準で止める |

## 13. 始める前に決めること（6つ）

1. 教える講師（英語で説明できるか）と、紹介できる経歴
2. マットと講師が空いている曜日（平日19時以降は男性体験の受付時間【事実】と重ならないか）。空かなければ平日10:00〜12:00にするか、始めない
3. 価格・キャンセル規定・前払いの方法（どの決済サービスか）・返金の手順をオーナーが承認
4. 講師の人件費と、投稿の担当者
5. 1か月目に無料で試してくれる知り合いの外国人
6. ジムにAEDがあるか（なければ一番近い場所）と、近くの救急病院

**投稿・予約受付・お金を受け取るのは、オーナーOKのあと。**
