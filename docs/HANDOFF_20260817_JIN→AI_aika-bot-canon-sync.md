## §0 このシステムは何か（誰が見てもわかる説明）

FLATUP GYM（千葉県成田市の格闘技ジム）が、**お客様対応と経営判断をAIで回すための仕組み**です。
AIは2体いて、役割がはっきり分かれています。

```
        お客様                          オーナー（JIN）
          │                                   │
     LINEで質問                          今日やること
          │                                   │
          ▼                                   ▼
    ┌───────────┐                    ┌───────────┐
    │   AIKA    │                    │  openQLOW │
    │  守りのAI  │                    │  攻めのAI  │
    │  受付・返信 │                    │ 営業・経営支援│
    └─────┬─────┘                    └─────┬─────┘
          │                                 │
          └────────────┬────────────────────┘
                       ▼
          ┌──────────────────────────┐
          │  正本 canon.ts            │
          │  料金・時間・クラスの      │
          │  たった1つの正しい答え     │
          └──────────────────────────┘
```

**大事な原則がひとつだけあります。**

> 事実（料金・時間・クラス）を書いていい場所は、世界に**1か所だけ**。
> 他の全部は、そこから写した「コピー」。

なぜなら、2か所に書くと必ずズレるからです。実際、今回見つかった不具合5件は**すべてコピー側のズレ**でした。

### AIが絶対にやらないこと

送信・予約確定・料金判断・返金・退会・休会・本番反映は、**必ず人間が最後に決めます**。
AIは下書きと整理までです。

**Q. どこを直せば「返信がおかしくない」状態になりますか？**

（「証本」＝正本、「口返して」＝繰り返して、と読みます）
