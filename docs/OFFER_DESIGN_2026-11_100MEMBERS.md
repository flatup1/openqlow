## 0. 結論（先に3つ）

1. **20名純増には、入会27名が必要。** 純増20名だけを数えると足りない。2か月で退会が約7名出る前提を入れると、必要な入会は約27名（月13〜14名）。これを体験本数に直すと**月38本の体験実施**が要る。現行の月間体験目標は30本（`src/commands/trial_kpi.ts`）なので、**まず体験の本数が足りない**。
2. **やるのは3本だけ。キッズ / 女性 / 紹介。** 男性オファーは4番手、親子は「単独の新施策にしない」（キッズ入会時の同時提案として運用する）。
3. **このまま行くと11月1日の着地は在籍93〜96名。100名には届かない見込み。** 届かせる条件はひとつ、**9月中に体験実施を月35本以上に乗せること**。乗らなければ100名到達は12月上旬にずれる。ここは正直に見ておいた方が、11月に慌てて値引きするより安全。

## 2. 必要数の逆算（ここが設計の土台）

```

退会 ＝ 80名 × 4%/月 × 2か月 ≒ 6.4名（在籍が増える分を見て 7名で置く）

必要な体験予約 ＝ 77 ÷ 到達率75%  ≒ 103件（月51件）
```

読み方はひとつだけ。**「入会を増やす」ではなく「体験予約を月51件つくる」が今回の仕事**。

## 3. 500円体験の位置づけ（表現を修正）

**使わない表現**：「無料体験より心理的ハードルが低い」
→ 心理的ハードルだけを比べれば、**無料の方が低い**。事実と逆なので広告にもLPにも出さない。

**使う表現**：「十分に低価格でありながら、来店意欲の高い方が集まる価格」

500円にしている理由は4つ。社内の共通認識として固定する。

1. 無料目的だけの申込みをある程度減らせる
2. 500円なら、ためらう金額ではない
3. 少額でも支払う人は、当日の来店率が高い（**仮説・要実測**：無料時代のデータが無いため断定しない）
4. 「安売りのジム」に見せない

## 4. 本当の競争相手（再定義）

FLAT UP GYMが取りたいのは「すでに格闘技ジムを探している人」だけではない。むしろ本命は、
**運動を始めたいが、格闘技ジムは怖そうなので選択肢に入れていない人**。

したがって競争相手はこの範囲まで広がる。

- 24時間フィットネス（chocoZAP、エニタイム、FiT24 など）
- パーソナルジム
- ヨガ、ピラティス
- 子どもの習い事（スイミング、体操、サッカー、学習塾）
- 家でYouTubeを見て運動する
- **何もしない**（最大の競争相手）

取りに行くポジションは1行。

> **格闘技ジムなのに、怖くない。**

## 5. 価格ではなく価値で比べる（カテゴリ比較・競合名は出さない）

LPに置くのはこの形。**特定のジム名は書かない**。お客様が「自分にはどれが合うか」を選べる表にする。

| | 一般的な24時間ジム | 一般的な格闘技ジム | パーソナルジム | **FLAT UP GYM** |
|---|---|---|---|---|
| 月額の目安 | 3,000〜8,000円 | 10,000〜15,000円 | 20,000円〜 | **7,700〜9,900円** |
| 手に入るもの | 場所と器具 | 指導と技術 | 完全個別の指導 | **場所＋器具＋指導＋技術＋仲間** |
| 指導 | ほぼなし | あり（経験者中心のことも） | あり | **あり（初心者中心）** |
| 24時間利用 | あり | ほとんどない | なし | **あり（カードキー）** |
| 初心者のはじめやすさ | 自分次第 | 店による | 高い | **初心者が基準** |
| 雰囲気 | 無人・黙々 | 店による | 1対1 | **怒鳴らない・威圧しない** |

> 月額の目安レンジはオーナー提示（2026-09-04）。**公開前に、実際の掲示・公式サイトで確認した数字に置き換える**。確認できない数字は載せない。

**1回あたりに直す見せ方**（LP用）

```
男性9,900円 ÷ 月8回通うと → 1回あたり約1,240円
そこに、指導・技術・24時間利用・仲間がついてくる。
（「月8回」は例。回数は人によります）
```

24時間ジムは「場所と器具を借りる」。FLAT UPは「場所＋器具＋指導＋技術＋仲間＋24時間」。
**この差を書かずに月額だけ並べると、必ず高く見える。**

## 7. 親子割を強化するかどうか（感覚で決めない）

**まず事実の確認**：親子割は**すでに正本にある**（親子合計で月500円引き）。ゼロから作る話ではない。

強化案（親子合計 −1,100円 ＝ 17,600円 → 16,500円）を入れた場合の**追加**負担は、
1,100 − 500 ＝ **600円/月/組**。

```
追加の減収 ＝ 600円 × 既存の親子組数N × 月数
増収       ＝ 16,500円 × 新規に増えた親子組数

損益分岐（月あたり）:  600円 × N ＜ 16,500円 × 新規組数
→ N＝5組なら、追加減収は月3,000円。新規が0.18組（2か月で1組）増えれば元が取れる。
→ N＝20組なら、追加減収は月12,000円。新規が0.73組（月1組弱）必要。
```

**判断ルール（提案）**

1. まず **現在の親子組数Nを数える**（未計測）。
2. N ≤ 10組 なら、強化して良い（2か月で1組増えれば黒字）。
3. N ≥ 15組 なら、**強化しない**。値引きより、キッズ入会時の声かけを1回入れる方が安い。
4. どちらでも、**既存の親子会員にも同条件を適用する**（しないと不公平が残る）。

紹介特典も同じ考え方で見る。バンテージ原価 ____ 円 × 2名 ＝ ____ 円。入会1名の初月会費（7,700〜9,900円）で回収できるなら、**値引きより安全な投資**。
