## 3. 推薦：② はじめてのミット

理由は3つ。

1. **3秒以内の引きが一番強い**（配点20点の項目）。ミットが動く瞬間は、音を想像させる。指が止まる。
2. **体験の中身が1本で伝わる**。「行ったら何をするのか分からない」が未経験者の一番の不安。①③④⑤は雰囲気は伝わるが、中身は伝わらない。
3. **CTAとつながる**（配点16点）。「1発打ってみる」と「体験に行く」の距離が短い。

②が外れた場合の次点は③「教わり方が見える」。安心感（配点18点）が最も高い案で、②とは訴求軸が違うので、STEP4ではこの2案を伸ばす想定。

承認後の実行手順：


`--submit` を付けても、次の4つが全部そろっていなければ**送信も課金もされない**。

## 6. 実装の中身（`src/ad_video/`）

| ファイル | 役割 |
|---|---|
| `catalog.ts` | モデルの仕様と単価。**公式確認済みかを必ず持つ**。未確認なら生成に進まない |
| `concepts.ts` | 5案のデータ。料金・住所は書かず、CTAは canon から引く |
| `guard.ts` | 表現の門番。KO・流血・断定・護身・怒鳴る・地下ジムなどを止める |
| `plan.ts` | 計画と見積り（本数×秒数×単価）、承認ゲート、ファイル命名 |
| `client.ts` | fal.ai へ投げる唯一の口。既定はドライラン。キーはヘッダにだけ使い、記録にもログにも出さない |
| `history.ts` | 生成1本ごとの追記記録（プロンプト／モデル／解像度／尺／日時／コスト／request_id／採点／改善） |
| `scoring.ts` | 8観点100点満点の採点と、上位2案の絞り込み |
| `run_cli.ts` | `npm run ad-video` |

依存は増やしていない（`@fal-ai/client` は入れず、Node標準の `fetch` で公式のキューAPIを叩く）。既存の `src/brand_growth/`（プロンプト設計）や AIKA、canon、safety には手を入れていない。
