## §1 このシステムは何か（誰の目から見てもわかる説明）

FLATUP GYM（千葉県成田市・「世界一優しい格闘技ジム」）には、AIが2体います。

| AI | 立場 | 仕事 |
|---|---|---|
| **AIKA** | 守り | 公式LINEでお客様に返信する受付AI |
| **openQLOW** | 攻め | オーナー向けの営業・経営支援AI |

**この2つを混同しないこと。**

お客様がLINEで「レディースは何時ですか？」と聞くと、こう流れます。

```
お客様のLINE
   ↓
LINE公式アカウント（Messaging API）
   ↓
VPS上の flatup-aika.service（Flask） … line.flatupnarita.jp
   ↓
line_webhook.py がプロンプトを組み立てる
   ↓  ここで読み込む「脳みそ」＝
   ├─ 1_AIKA人格_本番.md   （AIKAの性格）
   ├─ FAQ.md               （事実。人格ファイルより優先される）
   └─ DONT_SAY.md          （言ってはいけないこと）
   ↓
Claude API が文章を作る
   ↓
お客様に返信
```

そして、その「脳みそ」に書く**事実の唯一の正本**が、

```
flatup1/openqlow  →  src/shared/canon.ts
```

です。料金・時間・クラス名は、**ここ1か所だけ**が真。他のファイルは全部「引き写す側」。

**つまり「AIKAが嘘をつく」の原因はほぼ全部、canon.ts と他ファイルのズレです。**

⚠️ 重要：**リポジトリを直しただけでは、お客様の見え方は変わりません。**
本番AIKAはVPS上で動いているので、`deploy_aika_release.sh --apply` で反映して初めて変わります。

## §3 発言から読み取れる要求（対話式）

**Q. JINが最終的に欲しいものは何ですか？**

> 最適化とはユーザーに対しての返信がおかしくないこと

→ お客様がLINEで質問したとき、**AIKAが嘘の時間・嘘の料金を答えない状態**。これがゴールです。
コードの美しさ、アーキテクチャ刷新、新機能は**求められていません**。

**Q. どこを直せば「返信がおかしくない」状態になりますか？**

> その証本データはリポジトリなので修正と最適化を口返して

（「証本」＝**正本**、「口返して」＝**繰り返して** と読みます）

→ AIKAの返信は**リポジトリに置かれた正本データ**から作られる。だから直す対象はリポジトリ。
そして一度きりではなく、**ズレを見つけては直すことを繰り返す**。

**Q. リポジトリはどこにありますか？**

> AIKAにはAIKAのリポジトい　OPEN QLOWにも適したリポジトリがあるハス　探して最適化したい

→ 探した結果、3つありました（§4）。

**Q. 進め方の条件は？**

> 最短最速最低工数で実践したい　最低価格で最大限に効果を出し出い　コスパタイパを意識して

→ 大きな作り直しをしない。**「効果が大きい ÷ 工数が小さい」が高い順**に着手。

**Q. 報告の仕方に条件はありますか？（4回以上くり返し要求あり）**

> 中学生にもわかるように教えて
> 残りの作業を可視化して
> 必ず採点してから残りの作業がどの程度あって何をやっているのかを説明して
> 次の一手を教えて

→ **報告は毎回この順番で固定**：

```
① 採点（点数で言う）
② 残作業の可視化（表・進捗バー）
③ 次の一手（1つだけ、コピペできる形で）
```

専門用語は禁止。中学生に通じる言葉に置き換える。

**Q. どこまでAIがやってよいですか？**

> PRマージOK、VPS反映して
> 100点になるまで修正と検証をつづけて

→ 修正・テスト・PRは進めてよい。ただし**本番反映・commit・push・PRはJINの承認後**（§9）。
「100点になるまでつづけて」は**継続的に自走してよい**という許可です。

**Q. JINはターミナルが得意ですか？**

→ **いいえ。** コマンドは**1行・コピペ1回で完結する形**にすること。
- `#` で始まるコメント行を混ぜない（zshで `command not found` になる）
- 長い出力を求めない（`less` に閉じ込められて戻れなくなる事故が4回発生）

### 4-3. ⚠️ 最重要の落とし穴：プロンプトに旧値を書くな

**やってはいけない書き方（実際にあった）：**

```
- グローブ＋レガースのセットを9,900円と案内しない。正本は11,000円。
```

これは「9,900円」という**旧値をAIの目の前に置いてしまっている**ので、逆に漏れます。

**正しい書き方：**

```
- グローブ＋レガースのセットは11,000円。これ以外の金額を案内しない。
```

→ **禁止したい旧値そのものを書かない。正しい値だけを言い切る。**
この原則を破ると「直したはずなのに旧値が出る」が再発します。
