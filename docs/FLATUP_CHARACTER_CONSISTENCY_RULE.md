# FLATUP ANIMATION 正本ルール — キャラクターの一貫性
## 「主人公は、最初から最後まで同じ人」

> このルールは Bible(`FLATUP_ANIMATION_BIBLE.md`)と同格の**絶対ルール**です。
> 破ると物語が破綻します。制作するAI・人間の全員がこれに従ってください。

---

## 第1条 — 主人公を途中で入れ替えない

**1本のアニメの中で、主人公は1人だけ。**

❌ **やってはいけない例**(第1話の初稿で実際に起きた破綻):
```
入口でためらう少年 → (突然)女の子マスコットがパンチ → また少年が帰り道
```
見ている人は「これは誰の話?」となり、感情移入が切れます。

✅ **正しい形**:
```
入口でためらう少年 → 少年がグローブをはめる → 少年がパンチ → 少年が帰る
```

**判断基準**: そのカットに映っているのは、**さっきまでと同じ人**か?
違うなら、そのカットは別の話(別エピソード)にする。

---

## 第2条 — 主人公のタイプごとに、別のエピソードにする

FLATUP GYM には様々な人が通っています。**全員を1本に詰め込まない。**
主人公のタイプごとに、独立したエピソードを作ります。

| # | 主人公 | 心の動き(そのタイプ固有の不安) | 象徴的な瞬間 |
|---|---|---|---|
| **EP01** | **少年**(4〜6歳・母と来る) | こわい → やってみる → また来たい | 母の手を離して、はじめの一歩 |
| **EP02** | **少女**(小学生・自分で来る) | 恥ずかしい → 夢中になる → 誰かに教える | 下級生に「こうやるんだよ」 |
| **EP03** | **大人の女性**(30-40代・初心者) | 場違いかも → 続けられた → 自分が変わる | 鏡に映る自分の姿勢が変わる |
| **EP04** | **おじさん**(50代〜・運動から遠ざかっていた) | 今さら遅い → 昔より動ける → 若い子と笑う | 息が上がっても、笑っている |
| **EP05** | **道具たち**(語り手が主役の回) | — | 誰もいない夜に、その日を思い出す |

### 各エピソードの共通構造(骨格は同じ)

```
【導入】夜のジム、道具たちが「今日いちばん頑張った人」を思い出す
   ↓
【回想】その人の一日
   1. 不安 …………… そのタイプ固有の「怖さ・ためらい」
   2. 誰かの一言 …… 急かさない言葉をもらう
   3. やってみる …… 小さな挑戦
   4. ひとりじゃない … 周りの人の存在
   5. 変化 ………… 「また来たい」と思う瞬間
   ↓
【締め】夜のジムへ戻る → 道具たちの答え
   ↓
【結び】安心できる場所 → 体験予約(CTA)
```

**骨格は共通、中身は主人公ごとに違う。** これでシリーズとして統一感が出ます。

## 第3条 — 見た目の設定を、必ず文書に固定してから作る

新しいエピソードを作るときは、**まずキャラクター設定書を書く**。
書いてから絵を生成する。逆にしない。

設定書に必ず書くこと:
- 年齢感 / 髪型・髪色 / 目の形と色 / 表情の基本
- 服装(上・下・靴)を具体的に(色・形)
- 小物(グローブの色など。**象徴になる物**は特に)
- 心の変化(5段階)

**参考**: `FLATUP_EP01_CHARACTER_SHEET.md`(少年の設定書)

---

## 第4条 — 絵と言葉を必ず一致させる

語られている内容と、映っている絵を一致させる。

| 語り | 映すべき絵 |
|---|---|
| 道具たちの問いかけ | 夜のジム・道具たち |
| 「あの子は…」と誰かの話 | **その子が映っている絵** |
| 主人公の心の中 | 主人公の顔・手・背中 |

❌ 「中学生のあの子が優しかった」と言いながら、道具の絵のまま
✅ 「中学生のあの子が優しかった」→ 年上の子が小さい子に教える絵

---

## 第5条 — 実装での守り方(girl-power-op)

シーンに `image` を指定して、その場面の絵を出す:

```js
{ type: 'toolstalk', sec: 5.6, image: 'entranceShy', zoom: 'in',
  lines: ['はじめての日は、ドアの前で足がとまった。'] }
```

**マスコットのポーズ画像を使うシーン**(`smallpunch` / `fall` / `punch` /
`help` / `jump` など)は、**マスコットが主人公の回だけ**で使う。
少年・少女・大人が主人公の回では使わない(別人が出てしまうため)。

CTAも同じ。`image` を指定すれば、その物語の絵で締められる:
```js
{ type: 'cta', image: 'goingHome', title: '…', button: '500円体験を予約する' }
```

## 第6条 — AI画像生成のとき

設定書の「必須指定」をプロンプトに毎回貼る。生成後、必ず確認する:

- [ ] 髪型・髪色は同じか
- [ ] 服の色・形は同じか
- [ ] 年齢感は同じか
- [ ] 象徴の小物(グローブの色など)は同じか
- [ ] 舞台(白い床・ピンクと黄色のサンドバッグ)は同じか

**1つでも違ったら、その絵は使わない。作り直す。**

---

## なぜこのルールが必要か

FLATUP GYM が伝えたいのは「あなたにもできる」という**共感**です。
共感は、**見ている人が主人公に自分を重ねられて**はじめて生まれます。

主人公がころころ変わると、重ねる相手が分からなくなり、共感が消えます。
だから — **1本につき、主人公は1人。**

> はじめの一歩を、笑わない。／ 世界一、初心者にやさしい格闘技ジム FLAT UP GYM
