# 経費・確定申告・エネルギー支援金

レシートを1行で放り込むだけで、確定申告の集計と千葉市エネルギー支援金の申請準備が同時に進む仕組み。

```bash
npm run keihi -- help
```

送信も提出もしません。出るのは**下書きと集計だけ**で、申告と申請は人が行います。

---

## ⚠️ 最初に確かめること（これが全部の前提）

**千葉市中小企業者エネルギー価格等高騰対策支援金（第4弾）は、千葉市内の事業者が対象です。**

> 千葉市内に本店がある法人、または千葉市内に**住所もしくは主たる事業所**を有する個人事業者

FLATUP GYM の所在地は成田市土屋516-4。**このままだと対象外の可能性が高い**です。
ただし個人事業者は「市内に住所」でも要件を満たすと読めるため、代表者の住所が千葉市内なら該当する余地があります。

**作業を始める前に、まず事務局に電話して対象かどうかを確認してください。**

- 事務局: 043-201-6800（平日 9:00〜17:00）
- 公式サイト: https://chushoenergy4.city.chiba.jp/

対象外だった場合でも、経費帳と確定申告の集計はそのまま使えます。別制度に切り替えるときは
`data/subsidy_program.json` に制度の内容を書けば、同じコマンドで判定できます。

## 成田市に同じ給付金はあるか（2026-08-02 時点の調査）

**結論: ありません。** 成田市に、千葉市と同じ「光熱費が一定額を超えたら定額を給付する」事業者向け制度は見つかりませんでした。

| 調べた先 | 結果 |
| --- | --- |
| 成田市の物価高騰対策 | 交付金は**全市民向けデジタルポイント（1人4,000円）**に充当。事業者向けの光熱費給付は無し |
| なりた中小企業等事業復活支援給付金 | **終了**（令和4年9〜12月・法人20万円／個人10万円） |
| 成田市中小企業等緊急支援給付金 | **終了**（コロナ対応） |
| 千葉県の電気料金支援 | **特別高圧**で受電する事業者限定。ジムは対象外 |
| 成田市の現行の事業者補助 | 創業支援補助金（創業6か月以内が対象）、宿泊施設バリアフリー改修など。ジムの光熱費には使えない |

### 代わりに使えるもの

| 制度 | 内容 | 期限 |
| --- | --- | --- |
| **国の電気・ガス料金補助** | 申請不要。請求書から自動で値引き。2026年7〜9月は3か月合計で5,000円程度の拡充 | 手続き不要 |
| **小規模事業者持続化補助金（第20回）** | 補助率2/3・上限50万円。**本命**（下の節で詳述） | 受付 2026-11-05〜12-15 |
| **千葉県中小企業成長促進補助金（第4弾）** | 設備投資。小規模事業者枠は補助率1/2・**下限100万円**／上限500万円 | 2026-08-21 17:00 |
| **業務改善助成金** | 従業員の時給引上げ＋設備投資。募集開始 9/1 | 最低賃金の発効日前日か11月末の早いほう |

千葉県成長促進補助金は**下限100万円**なので、100万円以上の設備投資の予定が無ければ使えません。

問い合わせ: 成田市 経済部 商工振興企業立地課（成田市公式サイトに連絡先の記載あり）

> ⚠️ 上記は公表情報からの整理で、`.chiba.jp` 系の公式ページは調査環境から直接閲覧できませんでした。
> **申請前に必ず成田市・千葉県の公式サイトか窓口で最新の募集状況を確認してください。**

## 本命：小規模事業者持続化補助金（第20回）

```bash
npm run keihi -- jizokuka        # 区分別に補助額を計算し、申請メモを書き出す
npm run keihi -- jizokuka-plan   # 締切から逆算したスケジュールと提出書類
```

FLATUP GYM（サービス業・従業員1人・個人事業主）なら**確実に対象**です。

| 項目 | 内容 |
| --- | --- |
| 補助率 | **2/3**（赤字事業者は3/4） |
| 上限 | **50万円**（インボイス登録すれば+50万円、賃金引上げ特例で+150万円） |
| 対象 | 商業・サービス業で常時使用する従業員**5人以下** |
| 申請受付 | 2026-11-05 〜 **2026-12-15 17:00** |
| 様式4の発行締切 | **2026-12-04**（成田商工会議所が発行） |

つまり **税込75万円使えば50万円が返る**。

### ⚠️ 第20回でいちばん重要な変更点

**広報費（チラシ・看板）とウェブサイト関連費（HP・SNS広告・動画）は、その2つだけでは申請できません。**
機械装置等費や展示会等出展費と組み合わせる必要があります。
さらに、どちらも**補助金額の上限がそれぞれ30万円**です。

`jizokuka` コマンドはこの構成違反を検出して止めます。

```
🚫 このままでは申請できません。広報費・ウェブサイト関連費だけの構成です。
   機械装置等費や展示会等出展費と組み合わせてください（第20回からの変更点）。
```

### ジムでの組み方（例）

| 区分 | 中身 | 経費 | 補助 |
| --- | --- | ---: | ---: |
| 機械装置等費 | サンドバッグ・マット・器具 | 450,000 | 300,000 |
| 広報費 | チラシ・看板 | 300,000 | 200,000（上限30万以内） |
| ウェブサイト関連費 | HP・Instagram広告 | 300,000 | 200,000（上限30万以内） |
| **合計** | | **1,050,000** | **500,000**（全体上限） |

### 8月中にやること

1. **成田商工会議所に相談予約を入れる。** 様式4は商工会議所しか発行できず、秋は駆け込みで混みます。
2. **GビズIDプライムを取得する。** 電子申請に必須で、取得に2〜3週間かかることがあります。

この2つは9月以降だと間に合わないおそれがあるので、8月のうちに片付けます。

### インボイスは登録すべきか

**登録しないままで問題ありません。** 登録すれば持続化補助金の上限が50万→100万に増えますが、
その代わり課税事業者になって消費税の納税義務が生じます。ジムの客は一般の会員（BtoC）で、
相手からインボイスを求められないため、登録するメリットはほぼありません。
上限50万円のままで組むのが素直です。

> ⚠️ 金額・区分・上限は公表情報からの整理です。公式の公募要領は調査環境から参照できませんでした。
> **申請前に必ず[公募要領の原本](https://official.jizokukanb.com/)で検算してください。**

## 支援金のあらまし（公表情報にもとづく整理・原本は「申請の手引き」）

| 項目 | 内容 |
| --- | --- |
| 給付額 | **一律 110,000円**（第3弾までに10万円を受けた事業者には1万円を追加給付。追加分は申請不要とされています） |
| 申請受付 | 2026-05-08 〜 **2026-08-31**（オンラインは最終日23:59送信完了／郵送は消印有効） |
| 対象期間 | 2025年4月 〜 2026年3月 |
| 要件A | 対象期間の**任意の1か月**で、光熱費（電気・ガス／LPガス含む）＋燃料費（ガソリン・重油・軽油・灯油）が **30,000円以上** |
| 要件B | 対象期間の**連続3か月**で、原材料費＋光熱費＋燃料費が**月平均 500,000円以上** |

要件AとBはどちらかを満たせば足ります。ジムなら要件Aのほうが早いはずです。

**これは設備を買う補助金ではありません。** 見積書も省エネ効果計算も要りません。
必要なのは**過去の電気・ガス・燃料の請求書**だけです。

## 8月の進め方

```bash
npm run keihi -- plan
```

締切から逆算した日程と提出書類が出ます。要点は3つ。

1. **まず電話。** 所在地要件を満たすか確認する。ここが×なら以降は不要。
2. **過去の請求書を集めて登録する。** 2025年4月〜2026年3月分の電気・ガス・燃料。Web明細はPDFで保存。
3. **確定申告書の控えを早めに用意する。** 収受印か e-Tax 受信通知が要ります。手元に無いと取得に時間がかかるので、ここが一番の詰まりどころです。

## 使い方

### レシートを入れる

一行でそのまま打てます。日付・金額・勘定科目・消費税区分は自動で判定します。

```bash
npm run keihi -- add "8/3 コーナン 12800 サンドバッグ用マット"
npm run keihi -- add "今日 ダイソー 1,200円 消毒液 現金"
npm run keihi -- add "2026-01-10 東京電力 35800 電気代"
```

書ける追加情報:

| 書き方 | 意味 |
| --- | --- |
| `按分80%` | 事業按分80%（家事共用のもの） |
| `T1234567890123` | インボイス登録番号 |
| `耐用13` | 減価償却の耐用年数（30万円以上の資産に必要） |
| `レシートなし` | 証憑なし。あとで `check` に出ます |
| `現金` `クレカ` `口座振替` | 支払方法 |

### カード・銀行明細を取り込む

```bash
npm run keihi -- import ~/Downloads/card_202607.csv --method クレジット
```

列名（利用日／ご利用金額／お取引内容 …）を自動で見つけます。勘定科目は推定なので、あとで `check` で確認してください。

### 確定申告の準備

```bash
npm run keihi -- check          # 申告前に潰すべき不備を全部出す
npm run keihi -- month          # 今月の科目別まとめ
npm run keihi -- year 2026      # 年間まとめ＋減価償却費（決算書の並び）
npm run keihi -- csv --year 2026 # 会計ソフト取込用の仕訳CSV
```

`year` は青色申告決算書の経費欄と同じ並びで出るので、上から順に転記できます。

### 支援金の要件判定

```bash
npm run keihi -- grant --applicant "FLATUP GYM" --address "成田市土屋516-4 2F"
```

対象期間の各月について光熱費＋燃料費を集計し、**要件を満たす月**と**証拠にすべき請求書**を教えます。
同時に申請メモの下書き（Markdown）を `data/keihi/` に書き出します。

## 仕組みが判断していること

| 判断 | ルール |
| --- | --- |
| 勘定科目 | 支払先・摘要のキーワードで推定。当たらなければ消耗品費 |
| 消費税区分 | 飲食料品・新聞は8%軽減、保険・印紙は非課税、それ以外は10% |
| 資産か経費か | 10万円未満は経費／10万〜30万円は少額減価償却資産の特例／30万円以上は減価償却 |
| 減価償却 | 定額法。取得年は月割、最終年は備忘価額1円を残す |
| 支援金の光熱費 | 電気・ガス・LPガス。**水道は含めない**（制度の定義に合わせています） |
| 支援金の燃料費 | ガソリン・軽油・灯油・重油。勘定科目ではなく語で判定（給油は旅費交通費に入るため） |

推定はすべて下書きです。`fix` で直せます。

```bash
npm run keihi -- fix 3 --account 修繕費 --ratio 80 --note "更衣室の扉修理"
```

## データの置き場所

| ファイル | 中身 |
| --- | --- |
| `data/expenses.json` | 経費帳の本体 |
| `data/subsidy_program.json` | 支援金の定義（無ければ千葉市・第4弾の内容を使用） |
| `data/keihi/` | 書き出したCSVと申請メモ |

`OPENQLOW_DATA_DIR` / `OPENQLOW_KEIHI_OUT` で変更できます。
