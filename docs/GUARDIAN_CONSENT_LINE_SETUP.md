## なぜコードではないのか

- `openqlow` の webhook は `JIN_LINE_USER_ID` 以外を無視する（`src/line_bot/webhook.ts`）。
  お客様のメッセージは届かないため、ここに実装しても機能しない。
- `AGENTS.md` ルール3「AIKAは守りの顧客対応。openQLOWは攻めの営業・経営支援。混同しない」。
  お客様向けの入会同意は AIKA 側の責務。

### 現行からの変更点

| 変更 | 理由 |
|---|---|
| 「キャンペーン入会」→「**入会金無料キャンペーン**」 | 自分が対象か分かるようにする |
| 「翌月末」を強調、「当月中に急にはできません」を先頭へ | 一番誤解されやすい点を先に伝える |
| **退会届の提出が必要**を追加 | `src/shared/cancellation_rules.md` にあるのに現行文面から抜けていた |
| 退会と休会を1文にまとめず整理 | 休会は原則3ヶ月という別ルールがあるため |
| 同意文から**金額を削除** | 金額が変わったとき、過去の同意記録と食い違わないようにする |

## おまけ：あいさつ返信も100点にできます

現行のあいさつ返信は98点でした。2語だけ変えると100点（perfect）になります。

**現行**（98点）

```
ありがとうございます😊初めての方も、ご自身のペースで始められます。どの種目に興味がありますか？
```

**修正案**（100点 perfect）

```
ありがとうございます😊 初心者の方も、ご自身のペースで安心して始められます。どの種目に興味がありますか？
```

「初めての方」→「**初心者**の方」、「始められます」→「**安心して**始められます」。この2語がFLATUPらしさの判定語だからです。

## 品質スコアについて（重要な注意）

文面は `port/aika/response_quality.ts` の4観点100点スコアラーで採点しています。
この文書の文面はすべて **100/100 perfect** です。

ただし **満点は「安全」の証明ではありません**。このスコアラーが見ているのは
共感・自然さ・非重複・やさしさという**話し方**であって、**書かれている事実が
正しいかどうかは一切見ていません**。

実際、現行の【1/2】は98点（good）でしたが、その中身は
`src/shared/cancellation_rules.md` の「断定表現を使わない」方針に反していました。
点数を安心材料にせず、正本との突き合わせは必ず別途行ってください。

## 管理番号の形式に関する注意

管理番号は **`FG-MC-2026.08.06.0001`（ドット区切り）** です。ハイフン区切りにしないでください。

`FG-MC-20260806-0001` の形式は、返信前の品質ゲートが**電話番号と誤検出**して
送信を止めてしまいます（実測で reject を確認）。ドット区切りなら通ります。
