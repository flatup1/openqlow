# 未成年の保護者同意フロー｜LINE応答メッセージ 設定書

作成: Claude（2026-08-06）／**未承認・設定は未実施**

LINE公式アカウント（AIKA @jfl0054o）の **応答メッセージ** に設定する内容。
コードではなく管理画面での手作業。この文書のとおりに貼れば完成する。

## なぜコードではないのか

- `openqlow` の webhook は `JIN_LINE_USER_ID` 以外を無視する（`src/line_bot/webhook.ts`）。
  お客様のメッセージは届かないため、ここに実装しても機能しない。
- `AGENTS.md` ルール3「AIKAは守りの顧客対応。openQLOWは攻めの営業・経営支援。混同しない」。
  お客様向けの入会同意は AIKA 側の責務。

## 全体の流れ

```
お客様が「入会手続き」と入力
        ↓
  [1] おやくそく画像（既存・変更なし）
  [2] 年代をたずねるカード          ← 新規
        ├─「成人（18歳以上）」→ [4] へ（今までどおり）
        └─「小学生 / 中学生 / 高校生」
                ↓
        [3] 未成年の方へ・保護者同意カード   ← 新規
                ↓ ボタンを押すと同意文がトークに残る
        [4] 【1/2】重要事項の確認（文面を修正）
                ↓ ボタンを押すと同意文がトークに残る
        [5] 【2/2】会費ペイ登録（既存・変更なし）
```

## [2] 年代をたずねるカード（新規）

**キーワード**: `入会手続き`

**本文**

```
ご入会のお手続きを始めます。
まず、ご入会される方の年代をお選びください。
```

**ボタン4つ**（押すと「送信するテキスト」がお客様の発言として送られ、次の応答を呼ぶ）

| ボタンの表示 | 送信するテキスト |
|---|---|
| 小学生 | `入会手続き 小学生` |
| 中学生 | `入会手続き 中学生` |
| 高校生 | `入会手続き 高校生` |
| 成人（18歳以上） | `入会手続き 成人` |

## [3] 未成年の方へ・保護者同意カード（新規）

**キーワード**: `入会手続き 小学生` / `入会手続き 中学生` / `入会手続き 高校生`（3つとも同じ内容を返す）

**本文**

```
【保護者の方へ】未成年の方のご入会について

未成年の方のご入会には、保護者の方のご同意が必要です。
次の4点をご確認ください。

1. キックボクシングは相手と接触する競技です。
   打撲・捻挫・骨折などのけがが起こる可能性があります。

2. 当ジムは安全管理に努めていますが、
   競技の性質上、けがのリスクをゼロにすることはできません。

3. 会員ご本人および保護者の方は、
   インストラクターの指示とジムのルールに従ってください。

4. 体調やお怪我、練習の様子について、
   保護者の方へご連絡・ご相談をお願いする場合があります。

ご不明な点は、同意される前にお気軽にご相談ください。

次にすること：下のボタンを押してください。
```

**ボタン1つ**

| ボタンの表示 | 送信するテキスト |
|---|---|
| 確認して保護者として同意する | `私は保護者として、けがのリスク・指示に従うこと・保護者への連絡について確認し、未成年者の入会に同意します。` |

> この送信テキストがそのままトークに残り、**同意の記録**になる。

## [4] 【1/2】重要事項の確認（文面を修正）

**キーワード**: `入会手続き 成人` と、[3] の同意文（`私は保護者として…同意します。`）の**両方**で同じ内容を返す。

**本文（修正版）**

```
【1/2】重要事項の確認

ご入会ありがとうございます。
ご登録の前に、次の2点だけご確認ください。
ご不明な点があれば、同意される前にお気軽にご相談ください。

1. 退会・休会のタイミング
退会・休会は、当月中に急にお手続きすることはできません。
お申し出いただいた月の「翌月末」での対応となり、
それまでの月会費は通常どおり発生します。
※お手続きには所定の退会届のご提出が必要です。

2. 入会金無料キャンペーンでご入会の方へ
キャンペーンを適用してご入会いただいた方が、
入会から1年未満で退会される場合、
違約金（入会金相当10,000円）が発生します。

次にすること：下のボタンを1つ選んでください。
```

**ボタン1つ**

| ボタンの表示 | 送信するテキスト |
|---|---|
| 確認して同意する | `私は、入会者本人または保護者として、「退会・休会は翌月末での対応となること」「入会金無料キャンペーンでの入会は、1年未満の退会で違約金が発生すること」の2点を確認し、同意しました。` |

### 現行からの変更点

| 変更 | 理由 |
|---|---|
| 「キャンペーン入会」→「**入会金無料キャンペーン**」 | 自分が対象か分かるようにする |
| 「翌月末」を強調、「当月中に急にはできません」を先頭へ | 一番誤解されやすい点を先に伝える |
| **退会届の提出が必要**を追加 | `src/shared/cancellation_rules.md` にあるのに現行文面から抜けていた |
| 退会と休会を1文にまとめず整理 | 休会は原則3ヶ月という別ルールがあるため |
| 同意文から**金額を削除** | 金額が変わったとき、過去の同意記録と食い違わないようにする |
