# Googleビジネスプロフィール 写真棚卸し基準 v1.0

作成日: 2026-08-28 / 状態: **基準確定。削除は未実施。新写真の受領待ち。**

## 結論

新写真を先に載せる。旧写真はその後で消す。順番を逆にしない。
削除は1回ごとにオーナーへ確認してから実行する。

## 1. 判定基準（オーナー承認済み 2026-08-28）

| 区分 | 基準 | 扱い |
|---|---|---|
| 残す | 白い内装／ピンク・黄色の器具／新しい壁画／新ジムで撮影 | 保持。先頭に固定を狙う |
| 消す | 赤黒い旧内装／暗いリング／男性中心／旧ジムで撮影 | 削除候補 |
| 先頭 | 白い壁・ピンクと黄色のサンドバッグ前の集合写真（現「写真2」） | 先頭に置く |

判断に迷う写真は消さずに「保留」に入れる。保留は必ず人が見る。

## 2. 動画・第三者投稿の扱い（オーナー承認済み 2026-08-28）

- **旧ジムの動画も削除対象**。写真と同じ基準で扱う。
- **第三者・利用者が投稿した旧ジム写真**は、オーナー側で削除できない。
  該当分は **Googleへ削除申請してよい**。申請前に対象URLを一覧化してオーナーへ提示する。

## 3. 掲載同意（オーナー承認済み 2026-08-28）

女性・子ども・高齢者が写る素材について、広告・Web・Google掲載の許可は **取得済み**（オーナー申告）。
未成年が写る素材は、保護者同意の記録が残っているものだけを使う。記録が確認できない素材は保留に回す。

## 4. 保留にする典型例

- 内装が写っていない寄りの写真（顔・グローブのアップなど）
- 屋外・看板・駐車場など、内装で新旧を判定できないもの
- 新旧が混在しているもの
- 掲載同意の記録が確認できないもの

## 5. 削除前に必ずやること

1. 全写真の一覧をスクリーンショットまたはCSVで保存する（削除は取り消せない）
2. 元データが手元にあるか確認する。手元にない写真は先にダウンロードする
3. 新写真を公開し、表示されたことを確認する
4. 削除対象の枚数と「残す写真」の一覧をオーナーに提示する
5. **オーナーが「削除してよい」と答えてから削除する。毎回確認する。**

## 6. 実行順序

新写真の受領 → アップロード → 表示確認 → 削除対象の提示 → **オーナー確認** → 削除 → 第三者投稿の削除申請

## 7. 次のアクション

- [ ] オーナーが新ジムの写真・動画を提供する（本チャットに貼り付け）

- [ ] 受領後、1枚ずつ「残す／消す／保留」に仕分けして提示する
