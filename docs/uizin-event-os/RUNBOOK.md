# UIZIN Event OS — 当日までの手順書（RUNBOOK）

最終更新: 2026-10-01 / 起案: Claude / 承認: 未（オーナー承認前）

---

## 0. 結論

- **本番の前に、本物の機材で「練習モード」のリハーサルと「わざと壊す練習」を必ず1回通す。** ソフトは自動テストに合格しているが、実機ではまだ確かめていない。
- **配信の開始・公開範囲・結果を Sheets に戻すことは、JIN が決めて人が押す。** Event OS は自動で配信を始めない。
- 迷ったら **🛟 安全運転**。OBS が落ちたら **通常モードで起動**。

---

## 1. 2週間前

- [ ] YouTube のチャンネルでライブ配信を有効にする（初回は使えるまで最大24時間）
- [ ] YouTube Studio で **使い回せる配信キー** を1本作り、OBS に1回だけ設定する（キーは誰にも見せない・どこにも貼らない）
- [ ] ジム所有の Apple ID を Mac とメインの iPhone にそろえるか決める（ROADMAP Q10）
- [ ] 大会用 Mac に Node.js 22 以上を入れる。`node --version` で確認
- [ ] OBS の版を決める（Mac の macOS に合う版）。**自動更新を OFF**
- [ ] OBS：ツール → WebSocket サーバー設定 → **「WebSocket サーバーを有効にする」** をチェック（認証は ON のまま。表示されたパスワードを `~/UIZIN-EventOS/secrets.env` に書く）
- [ ] OBS：シーン（`WAIT` `FIGHTER` `FIGHT` `WINNER` `SAFE` `CAM`）とテロップ部品（`EOS_` で始まる5つ）を作る（`tools/uizin-event-os/README.md` §2.2）
- [ ] OBS：録画形式を **Hybrid MP4**、「配信時に自動で録画」は OFF
- [ ] Event OS を体験モード（`--demo`）で一度動かし、画面の流れを確かめる（体験モードの記録は `~/UIZIN-EventOS/demo/` に入り、本番の記録には混ざらない）

## 2. 1週間前（リハーサル）

- [ ] 本物の OBS・iPhone 2台・会場専用ルーターをつなぎ、Event OS を **練習モード** にする（管理モード）
- [ ] 開始前チェックが全部 ✅／👤 になることを確かめる
- [ ] 架空の試合データ（`tools/uizin-event-os/samples/demo_card.csv`）で最後まで回す
- [ ] **小学生UIテスト**：初めての人に「画面の『次』を読んで押してね」だけ伝えて3試合（ACCEPTANCE_TESTS.md §3）
- [ ] **わざと壊す練習**（ACCEPTANCE_TESTS.md §4）を実機で1回ずつ：
  - [ ] サブの iPhone のケーブルを抜く／アプリを裏に回す → メインに戻る
  - [ ] メインのケーブルを抜く → ❌ が最優先で出る
  - [ ] ルーターの外向きの線を抜く → 進行・録画は続く
  - [ ] OBS を強制終了して起動し直す → **セーフモードを聞かれたら通常モード** → 自動でつながる → 「録画を始める」
  - [ ] iPad の Wi-Fi を切る → Mac 本体の画面で続ける
  - [ ] Event OS を止めて起動し直す → 同じ状態に戻る
- [ ] **限定公開** で 30〜60分配信し、YouTube のアーカイブと Mac の録画が両方残ることを確かめる。途中で回線を1分切る
- [ ] iPhone の熱・電池を2時間見る（給電しながら・ケースを外す・日陰）
- [ ] ここから本番まで **OBS・macOS・iOS・アプリを更新しない**

## 3. 前日

- [ ] Google Sheets で試合データを作る（表示名と配信可否だけ。本名・年齢・学校・連絡先は入れない）
- [ ] **ファイル → ダウンロード → CSV** で保存（「ウェブに公開」は使わない）
- [ ] Event OS を **本番モード** にして、運営モードで CSV を読み込む。❌ が出たら行番号の所を直す
- [ ] 配信しない試合の数を確かめ、**👤 配信しない試合を確認した** を押す
- [ ] 入場の順番（赤→青／青→赤）を設定で確かめる（`flow.entranceOrder`）
- [ ] 入場曲を配信に乗せない準備（会場マイクの入力名を `audio.muteDuringEntrance` に書く 等）
- [ ] YouTube Studio で当日の配信枠を作る：**公開範囲**・**自動停止 OFF**・**子ども向けの申告**・遅延は「通常」を JIN が確認
- [ ] Mac の空き容量・iPhone の充電・予備のケーブルと電源タップ

## 4. 当日（開場前）

1. Mac を電源とルーター（有線）につなぐ。カメラをつなぐ
2. OBS を起動 → Event OS を起動（`start.command`）
3. 運営モードで **開始前チェック** を見る。❌ を直し、👤 の項目を確かめて押す
4. 「🔊 音のチェック」で配信に乗る音が出ているか確かめる
5. iPad は起動画面の URL を開く（合言葉つき）
6. **「▶ 大会を始める」**（運営）→ 録画が自動で始まる。上のランプが「● 録画中」になったか見る
7. 配信の時間になったら、運営モードで **「▶ 配信を始める」を長押し → 確認**（JIN の判断で）

## 5. 大会中

- スタッフは画面の **「次」を読んで、大きいボタンを押すだけ**
- 休憩のたびに：iPhone の熱と電池、Mac の空き容量、ランプ（● 録画中）
- 配信が「つなぎ直し中」でも **試合は続けてよい**。60秒を超えたら、回線が戻ってから「🔁 配信をやり直す」（運営）

### 困ったとき

| こんなとき | すること |
|---|---|
| 何かおかしい | **🛟 安全運転**（メインカメラだけ・録画は続ける・配信には触らない。配信しない試合の間はカメラも映さない）。落ち着いたら「✅ 通常に戻す」 |
| 「❌ 録画が止まっています」 | 「● 録画を始める」 |
| 「❌ 録画が一時停止しています」 | 「● 録画を再開する」（OBS の一時停止ボタンは押さない） |
| 「❌ 配信しない試合なのに、カメラの場面になっています」 | すぐに「🔁 自動に戻す」（または 🛟）。カメラの映らない画面に戻る |
| 「❌ 操作の記録を保存できません」 | Mac の空き容量を作る（不要なファイルを消す・別のディスクへ移す）。進行と OBS の録画は続けてよい |
| 「❌ メインカメラが映っていません」 | ケーブルと電源。サブが映っていれば自動でサブになっている |
| 「✋ 手動モード」 | OBS を直接さわった印。落ち着いたら「🔁 自動に戻す」 |
| 「OBS とつながっていません」 | OBS が開いているか。落ちていたら起動し直し、**セーフモードを聞かれたら通常モード** |
| 「OBS のパスワードが違います」 | 運営の人を呼ぶ（`secrets.env` を直して Event OS を起動し直す） |
| 間違えて進めた | 「↩ 戻る」（試合をまたぐときは運営モード） |
| 勝者を間違えた | 運営モードの「試合の一覧」で直す |
| iPad がつながらない | Mac 本体の画面で続ける |
| Event OS が止まった | OBS の映像と録画は続いている。起動し直せば同じ状態に戻る（場面が違えば手動モードで知らせる） |
| 配信の画面に「Failed to connect」 | 録画は続いている。OK を押して、回線が戻ったら「配信をやり直す」 |

## 6. 大会後

1. 最後の試合の後「🎌 大会を終える」
2. 運営モードで **「■ 配信を終える」を長押し → 確認**、YouTube Studio で配信枠を終える
3. 運営モードで **「■ 録画を止める」を長押し → 確認**
4. 「📦 書き出し」→ `~/UIZIN-EventOS/data/exports/` にチャプター・結果・切り抜き用ファイルができる
5. YouTube の概要欄にチャプターを貼る（試合番号だけ）。**公開・投稿は JIN の承認後**
6. 結果を Sheets に戻すのは **JIN が確認してから** 手で
7. 録画と `~/UIZIN-EventOS/` をバックアップ。**リポジトリには入れない**（選手の表示名を含む）

## 7. 人の承認が要るもの（approval_matrix.md）

| 操作 | 誰が決める |
|---|---|
| 配信を始める・公開範囲・子ども向けの申告 | JIN |
| 配信しない試合・未成年の表示名・同意の扱い | JIN |
| 入場曲を配信に乗せるか | JIN（必要なら専門家） |
| 結果を Sheets に戻す・SNS に投稿する・切り抜きを公開する | JIN |
| ❌ が残ったまま大会を始める | 管理モードの人（記録に残る） |
