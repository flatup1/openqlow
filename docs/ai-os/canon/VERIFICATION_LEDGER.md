# 正本の出典台帳（VERIFICATION_LEDGER）

`src/shared/canon.ts` の各値が **どこ由来で、いつ確認したか** を記録します。

## なぜ必要か

2026-08-15、回数券の料金が実際と違っていたことが判明しました（誤: 6回券15,000円 / 12回券30,000円、正: 5回券14,000円 / 10回券24,000円）。公式サイト（2026-07-18 参照）由来の値でしたが、実運用と一致していませんでした。

**ドリフト検出では捕まりませんでした。** 検出器が見るのは `canon.ts` と同期ビューの内部一貫性であり、外部の事実との一致ではありません。両方が揃って同じ誤りを持てば、機械はいくら回しても気づけません。

決め手はオーナー提供の LINE 画面 1 枚でした。つまり **外部との突合は人間にしかできない**。ならばせめて「どの値が疑わしいか」を機械可読にしておく、というのがこの台帳です。

| 記号 | 出典 | 扱い |

| **C** | 公式サイト・Vault の記載 | **要注意**。回数券の誤りはここ由来 |
| **?** | 出典不明・当初の指示のみ | **要確認**。顧客案内前に裏取りが必要 |

1. **`businessHours` の平日夜（18:00〜21:00）** — 公式サイト由来。回数券が同じ経路で誤っていたため、実際の対応時間の確認が必要

## 運用ルール

- `canon.ts` にフィールドを追加したら、**必ずこの台帳にも行を足す**（`canon.test.ts` が欠落を検出して落ちます）。
- 出典 `C` / `?` の値は、顧客案内に使う前に裏取りする。
- オーナー確認が取れたら出典を `A` に更新し、確認日を書き換える。
- 「未確認だから黙る」は正しい判断。**未確認の値を推測で埋めない。**
