## 1. 出発点 — 「1枚の絵から動画を作りたい」

**JIN:**
> 「キャラクター画像1枚から、アニメOP風の動画を作りたい」

**AI の理解と実行:**
`girl-power-op/` を新設。AIサービスに依存せず、ローカル計算だけで動く方式にした。

- `index.html` … Canvas に「**t秒の絵**」を描く純粋関数 `draw(t)`。タイマーを使わないので、状態のズレやリセット漏れのバグが構造的に起きない
- `render.js` … Playwright で Chromium を自動操縦し、1/30秒ごとにスクリーンショット → ffmpeg で MP4 に
- BGM も Web Audio の `OfflineAudioContext` で**自前合成**（著作権フリー）

→ PR #42 でマージ済み。

**JIN:**

## 4. 「複数枚の画像を繋げて、実際のアニメにできる？」

**JIN:**
> 「これをさらに改造して複数枚の画像を繋げて実際のアニメを作るようにできる？」

**AI の実行:**
物語をプログラムから切り離し、**データファイル（`story.js`）だけを書き換えれば別のアニメになる**構造にした。

```js
// story.js — プログラムを触らずに物語だけを編集できる
window.STORY = [
  { type: 'entrance', sec: 3.75, text: 'ようこそ!' },
  { type: 'finale',   sec: 4.5,  title: 'はじめの一歩を、笑わない。', subtitle: 'FLATUP GYM' },
];
```

- `index.html?story=op` … 旧デモ版
- `index.html?story=ep01` … 第1話（少年編）
- `index.html?story=ep02` … 第2話（少女編）
- 指定なし … `story.flatup.js`（サイト埋め込み用の短い版）

→ PR #50（縦型1080×1920）、PR #51（ポーズ切替＋シナリオエンジン＋埋め込みループ）でマージ済み。

## 5. 「夜中になると防具たちが話し始めるシーンを作りたい」

**JIN:**
> 「これらの防具の画像うまくミックスさせてお話するシーンを作りたい 夜中になると話し始めるやつ」

**JIN の指定した会話内容（原文）:**
> 「今日1番頑張った子は
> あの子たち
> ミット　帰りに挨拶できるようになった2年生の双子
> サンドバッグ　中学生の男の子は小さいことスパーリングする時に膝をついてあげていつも撫でるようにやっているよ　とても優しいよね
> グローブ　高学年の女の子は下級生の子に注意しながらもちゃんとやりなさいって優しくおしえてたよね
> みんな頑張ってたよね
> みたいなテイストにして」

**AI の実行:**
`toolstalk` という新しいシーン型を実装。

| 指定できるもの | 意味 |
|---|---|
| `sc.image` | そのカットで映す絵 |
| `sc.zoom` | `'in'` / `'out'` / `'still'` |
| `sc.focusY` | 画面のどの高さを中心に見せるか |
| `sc.title` | 画面上の見出し（ピル型ラベル） |
| `sc.lines` | セリフ。文字列 or `{speaker, text}` |
| `sc.lineGap` | セリフが出る間隔（秒） |

話者の名札の色: **ミット=黄 / グローブ=ピンク / サンドバッグ=オレンジ**。
静かなシーン（`QUIET` 指定）では BGM が自動でドラム無しのオルゴール風に切り替わる。

## 13. 絶対に守るルール（このリポジトリの憲法）

`CLAUDE.md` / `AGENTS.md` / `COORDINATION.md` に定義。**他AIもこれに従うこと。**

```
・日本語、結論ファースト、短く、中学生にも分かる表現を使う。
・AIKAは守りの顧客対応、openQLOWは攻めの営業・経営支援として混同しない。
・既存実装、未コミット差分、原本を保持し、削除や全面上書きをしない。
・下書き・分析・テストは進めてよい。
　送信、予約確定、料金判断、返金、退会、休会、外部書き込み、公開、課金、
　本番反映、commit、push、PRは人間承認後。
・秘密情報や顧客個人情報を表示・保存・コミットしない。
・変更後は ./scripts/validate-ai-os.sh と関連テストを実行する。
```

**事実（料金・営業時間・クラス）の唯一の正本は `src/shared/canon.ts`。**
ここに無い数字を、勝手に書かない。分からなければ「未確認」と書いて止める。
