# UIZIN 大会当日 受付〜計量 書類一式（2026年9月23日）

大会当日の **受付 → 精算確認 → 書類 → 計量 → ✓ → 青シール** をそのまま運用できる4点セット。
運用ルールの全文は [`UIZIN_大会当日オペレーション_引き継ぎ.md`](./UIZIN_大会当日オペレーション_引き継ぎ.md)。

## すぐ印刷する

`print/` の **PDF をそのまま印刷**する。設定は共通。

- 用紙 **A4** ／ 余白 **なし**（または既定）／ 倍率 **100%・実際のサイズ**
- **「背景のグラフィック」を ON**（黒の見出し帯と青シールが出る）

| 記号 | ファイル | 何枚刷るか |
|---|---|---|
| A | `print/A_メディカル_誓約_保護者同意.pdf` | 選手1名につき1枚（88名なら95枚程度） |
| B | `print/B_計量チェックリスト.pdf` | 2〜3枚（計量台・受付卓・控え） |
| C | `print/C_計量完了シール_あお1-88.pdf` | 3枚（青1-48／青49-88＋予備／減点シール）→ 切り分ける |
| D | `print/D_受付スタッフ5ステップ.pdf` | 3〜5枚（受付卓・計量台・入口） |

白黒プリンターでも全て読める。青シールだけは、青い紙に印刷するか枠を青ペンでなぞると識別しやすい。

## 名簿・開催日を差し替える

計量チェックリストの**選手名と契約体重は空欄**にしてある（最終対戦カードが正のため）。

1. `roster.csv` に **最終対戦カードの契約体重**を入れる（例 `1,山田 太郎,FLATUP GYM,32.0kg`）
2. 大会名・開催日・2点減点の色を変えるなら `build.mjs` 先頭の `CONFIG` を直す
3. ビルドする

```bash
node docs/uizin-2026/build.mjs          # print/*.html を作り直す
```

PDFも作り直す場合（Chrome / Chromium が必要）:

```bash
cd docs/uizin-2026/print
for f in *.html; do
  chromium --headless --no-pdf-header-footer --print-to-pdf="${f%.html}.pdf" "file://$PWD/$f"
done
```

## 変えてはいけない基準

- ＋500g以内は**減点なし**（着衣計量の許容範囲）。オーバー扱いにしない
- ＋2kg以上は**失格ではなく要相談**
- 契約体重は**最終対戦カードの数値**（申込時の自己申告体重は使わない）
- 「支払い済み」「受付済み」「計量済み」は**別の状態**
