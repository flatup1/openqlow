13. 当日の受付から計量までの実際の導線

書類単体を作るだけではなく、大会当日に受付スタッフが迷わず運用できることまで考えて設計する。

STEP 1｜選手名を確認

受付に来た選手の

  • 選手名
  • 所属ジム

を確認する。同姓同名や兄弟・姉妹がいる可能性もあるため、名前だけで判断せず、必要に応じて所属ジムも確認する。

STEP 2｜参加費の精算状況を確認

ここは非常に重要。まだ参加費の精算が済んでいない選手がいる可能性がある。
未精算の選手は、そのままメディカルチェックや計量へ進ませず、まず参加費の精算を済ませてもらう。

未精算者 → 先に精算 → 精算完了 → メディカルチェック・誓約書・保護者同意 → 計量

未精算者リストは主催者が別途用意する予定。
したがって、今回作る書類自体に支払い管理を大量に入れる必要はない。
受付スタッフが「未精算の場合は先に精算」と理解できれば十分。

14. 誓約書・同意書・メディカルチェックを提出してから計量

計量だけを先に行わない運用にする。基本的には次の順。

  1. 精算確認
  2. メディカルチェック
  3. 誓約内容確認
  4. 保護者同意・署名
  5. 書類提出
  6. 計量

つまり、必要な書類の確認・提出と引き換えに計量へ進むイメージ。
未成年選手の場合、保護者署名がない状態のまま試合へ進めない。

15. 計量終了後のシール管理

計量が終わった選手について、「この選手は計量が終わっている」ことを一目で判別できるようにする。
そのため、計量終了後に選手へシールを貼る、または渡す運用を考えている。

主催者が希望しているのは青色の番号付きシール。番号はあお1 〜 あお88を想定。

  • あお1
  • あお2
  • あお3
  • …
  • あお88

この番号によって、誰が受付・計量を終了したのかを管理しやすくする。

シールは、服／選手用カード／手首等のどこに使用するかはまだ最終決定していない。
使用場所をAI側で勝手に確定しないこと。 必要なら主催者へ確認する。

16. 計量オーバー時の識別

計量オーバーの場合、スタッフが一目で分かる識別も必要。現在決まっているペナルティは以下。

契約体重との差対応
＋500g以内OK・減点なし
＋501g〜999g1点減点
＋1.0kg〜1.999kg2点減点
＋2kg以上要相談

重要

「＋500g以内」は、キッズ大会・着衣計量であることを考慮した許容範囲。
したがって、500g以内を体重オーバー扱いにしない。

17. 黄色シールについて

これまでの運用案として、減点がある選手を黄色で分かるようにするという案がある。
特に ＋501g〜999g → 1点減点 について、黄色シール＝減点1 として識別する案が出ている。

ただし、2点減点を何色・どの方法で表示するかについては最終確定していない。
AI側で「赤シールにする」「黄色シール2枚にする」などを勝手に決めないこと。
必要であれば、

「2点減点の選手は、どのように識別しますか？」

と主催者へ1問だけ確認する。

18. 計量チェックリストに使う体重

計量チェックリストへ記載する「契約体重」は、申込時の自己申告体重ではない。
最終対戦カードに設定された契約体重を使用する。

例：

  • 選手の申込体重：31.2kg
  • 対戦カードの契約体重：32.0kg

の場合、計量表には 32.0kg を掲載する。つまり対戦カードに記載されている体重が正。

19. 88名の選手名簿について

大会参加者は約88名。計量チェックリストには全選手分を掲載する。
主催者が希望している表示は非常にシンプル。

No.選手名契約体重✓
1山田 太郎30kg□
2鈴木 花子35kg□

基本的には、名前 → 契約体重 → レ点だけで判断できればOK。

20. 「レ点」が最重要

計量チェックリストについて、主催者は繰り返し「レ点でチェックを打つだけのもの」を希望している。
そのため、次のものを計量表に追加しない。

  • 長い備考
  • 生年月日
  • 電話番号
  • 保護者名
  • 住所
  • 試合順
  • 細かい選手プロフィール

当日のスタッフが計量完了 → ✓ とするだけで管理できることを最優先する。

21. 実測体重について

主催者の第一希望は、数値を毎回細かく記録する表ではなく、チェック中心。
したがって、実測体重欄を付ける場合でも小さくする。または、A4一枚への収まりを優先して削除して構わない。

基本形は 選手名 / 契約体重 / ✓。

22. 計量で迷った場合

スタッフが「これは500g以内？」「減点？」「2kg以上？」など判断に迷った場合は、スタッフ個人で勝手に決定しない。
主催者・責任者へ確認する。

特に＋2kg以上については自動失格とはせず要相談。
安全面・対戦相手との体格差等を確認して、最終的に主催者側で判断する。

23. メディカルチェックで問題があった場合

メディカルチェックで

  • 強い体調不良
  • 発熱
  • 大きなケガ
  • 試合に支障がある痛み
  • その他安全上気になる状態

が確認された場合、受付スタッフが「大丈夫そうだからOK」と自己判断しない。
主催者・レフェリー等へ確認する。 大会では安全を最優先とする。

24. 保護者への説明を簡単にする

受付スタッフが長い説明をしなくても済むように、誓約書自体を見れば内容が分かる設計にする。
受付スタッフの説明は

「体調をご確認いただいて、内容を読んで保護者の方のご署名をお願いします」

程度で済むことが理想。書類を読めば、ケガの可能性／大会ルール／判定／写真・動画／保護者同意が理解できるようにする。

25. 肖像権に関して特に強調したいこと

この大会では、試合だけでなくイベント全体を撮影する可能性がある。
そのため「自分の子どもだけ絶対に映さないでください」という個別対応が難しい場合がある。

大会参加にあたり、大会会場内で撮影された写真・映像が大会記録、SNS、Web、YouTube、広報等に利用される可能性があることを理解したうえで参加してもらう内容にする。

ただし「肖像権を永久にすべて放棄する」など、必要以上に広い権利放棄表現は使用しない。
目的はあくまで大会運営・大会記録・広報に必要な範囲の同意。

26. 判定について特に強調したいこと

判定については、単純に「文句禁止」と書くのではなく、公平で安全な大会運営のためという理由が伝わる文章にする。

対象となるのは、レフェリーの判断／ジャッジの判定／ダウン判定／減点／試合停止／安全面を理由とする停止／勝敗／大会運営上の最終判断。

これらについて、主催者・レフェリー・ジャッジの最終判断に従うことを保護者同意に含める。
原則として、試合終了後に判定を変更するための異議・不服申し立ては受け付けないという意味が明確になるようにする。

27. 「怪我の責任」について主催者の意図

主催者として最も避けたいのは、大会後に「怪我をしたから全部主催者の責任だ」という認識になってしまうこと。

キックボクシングは打撃競技なので、安全対策を行っても、ケガの可能性をゼロにはできない。
そのことを保護者が理解し、競技に伴う通常のリスクを理解した上で参加させることを確認する。

ただし、主催者側の故意・重大な過失等まで無条件に免責する文章にはしない。

28. 当日スタッフ用の超簡単な受付手順も最後に作る

A4書類2枚を完成させた後、可能であれば最後に「受付スタッフ用・5ステップ」を作成する。内容はおおむね次の流れ。

  1. 名前確認
  2. 精算確認
  3. メディカル・誓約・保護者署名確認
  4. 計量
  5. 計量済みチェック・シール

スタッフがスマホで見ても分かるように、非常に短くする。

29. 当日運用で絶対に混同しないこと

以下は別々に管理する。

状態意味
支払い済み参加費を払った
受付済み必要書類の確認が終わった
計量済み体重確認が終わった

この3つは同じ意味ではない。
例えば「支払い済みだから計量も終わっている」とは判断しない。

30. 計量完了の定義

計量済みと判断するのは、次まで完了した時点。

  1. 精算確認済み
  2. 必要書類提出済み
  3. 計量実施済み
  4. 必要な場合は減点処理を確認
  5. 計量表に✓

その後、計量完了を示すシールを使用する。

31. 名簿の最新版について

計量表を実際に作る場合は、古いエントリー表をそのまま使わない。
大会直前まで、欠場／追加／対戦変更／契約体重変更が発生している。

したがって最終対戦カードを基準にする。
主催者から最新版の名簿・対戦カードが渡された場合は、必ずそちらを優先する。

32. 三枝ルイト選手について

主催者から「ルイトは後で追加します」という指示がある。
したがって、現時点のリストに存在しない場合でも、勝手に「欠場」「参加しない」と判断しない。
最終名簿作成時に主催者へ確認する。

33. 印刷時の重要条件

大会前日であり、作業時間が限られている。
したがって、特殊な印刷業者へ発注しなければ使えないデザインにはしない。
家庭用・コンビニプリンターですぐ印刷できることを前提とする。

  • A4
  • 白背景
  • 白黒印刷対応
  • インクを大量消費しない
  • 太字・罫線中心
  • 文字が小さすぎない
  • 余白を確保
  • コピーしても読める

34. AIに禁止すること

  • 勝手に計量基準を変更する
  • 500g以内を減点対象にする
  • 2kg以上を勝手に失格扱いする
  • 保護者署名に加えて選手本人の署名を必須にする
  • 大量のメディカル質問を追加する
  • 長大な法律文書にする
  • 「主催者はいかなる場合も一切責任を負いません」と断定する
  • 未確定事項をAIの判断だけでルール化する
  • 計量表へ不要な個人情報を大量に追加する
  • 最終対戦カードではなく古い申込体重を契約体重として使う
  • 受付、支払い、計量を同じ状態として扱う

35. 分からないことがあった場合

主催者からの明確な希望は「分からないことがあれば私に質問してください」。
ただし、何でも質問して作業を止めない。質問するのは結果を大きく変える重要事項だけ。

質問例：

2点減点の選手を識別するシールの色は決めますか？
計量済みの青番号シールは選手のどこへ貼りますか？

一方、フォント／罫線／見出しサイズ／チェックボックス形状などはAI側で最適化して進める。

37.【付録A】作成済みの成果物と印刷手順

37-1. ファイルの場所

すべて docs/uizin-2026/ にある。print/ の中に HTML（編集・印刷用）と PDF（そのまま印刷用） が両方入っている。

記号ファイル枚数
Aprint/A_メディカル_誓約_保護者同意.pdfA4縦 1枚（選手1名につき1枚＝88枚＋予備）
Bprint/B_計量チェックリスト.pdfA4縦 1枚（88名を2列44行で掲載）
Cprint/C_計量完了シール_あお1-88.pdfA4 3枚（青1〜48／青49〜88＋予備／減点シール）
Dprint/D_受付スタッフ5ステップ.pdfA4縦 1枚（受付卓に1枚。スマホでも読める）

37-2. 印刷設定（コンビニ・家庭用プリンター共通）

  1. PDFをそのまま印刷する。
  2. 用紙：A4
  3. 余白：なし（または「既定」）、倍率：100%／実際のサイズ
  4. 「背景のグラフィック」をON（黒の見出し帯と青シールが出るため）
  5. 白黒プリンターでもすべて読める設計。青シールだけは、青い紙に白黒印刷するか、枠を青ペンでなぞると識別しやすい。

HTMLから印刷する場合も同じ。ブラウザで開いて Ctrl+P（Mac は Cmd+P）。

37-3. 何枚刷るか

記号枚数の目安
A選手数＋予備（88名なら 95枚程度）
B2〜3枚（計量台と受付卓に1枚ずつ、控え1枚）
C3枚（青1-48／青49-88／減点シール）。切り分けて使う
D3〜5枚（受付卓・計量台・入口）

37-4. 書類Aとチェックリストのつながり

書類Aの一番下にスタッフ記入欄がある。ここに
「精算確認 □ / 書類確認 □ / 計量実施 □ / 判定（減点なし・1点・2点・要相談）/ あお◯番 / 担当者」
を記入する。書類Aを見れば、その選手がどこまで終わったかが1枚で分かる。
計量チェックリスト（B）は§20の希望どおり「名前・契約体重・✓」だけに保ち、詳細はAに寄せている。

38.【付録B】最終対戦カードが届いたときの差し替え手順

計量チェックリスト（B）の選手名と契約体重は空欄で出力してある（§31：古いエントリー表を使わないため）。
最終対戦カードが確定したら、次のどちらかで埋める。

方法1：手書き（いますぐ使う場合）

印刷して、選手名と契約体重を手書きする。表は88行そろっている。

方法2：差し替えて印刷し直す（推奨）

  1. docs/uizin-2026/roster.csv を開く（Excel・メモ帳どちらでも可）。
  2. No,選手名,所属ジム,契約体重 の列に、最終対戦カードの契約体重を入れる。

例：1,山田 太郎,FLATUP GYM,32.0kg

  1. 次を実行すると、HTMLが作り直される。
node docs/uizin-2026/build.mjs
  1. print/ のHTMLをブラウザで開いて印刷する（PDFを作り直す場合は docs/uizin-2026/README.md 参照）。

三枝ルイト選手（§32）：現時点のリストに名前がなくても欠場と判断しない。最終名簿作成時に主催者へ確認し、空欄行または追加行に入れる。

大会名・開催日を変えたいとき

docs/uizin-2026/build.mjs の先頭 CONFIG の1箇所だけ直して、上のコマンドを実行する。

const CONFIG = {
  eventName: 'UIZIN',
  eventDate: '2026年9月23日',
  athletes: 88,
  stickerPrefix: 'あお',
  deduct2Color: null, // ← 2点減点の色が決まったら '#E8380D' のように入れる
};

39.【付録C】未確定のまま残していること（AIが決めなかったこと）

§15・§17・§35にあるとおり、次の2点はAI側で確定させていない。
書類は、決まっていない状態のまま当日使える形にしてある。

#未確定事項現在の作り方決まったら
12点減点の識別方法・色減点シート（Cの3枚目）に「減点2」を枠のみで印刷。黄色＝減点1だけ確定として印刷済みCONFIG.deduct2Color に色を入れて再ビルド、3枚目だけ刷り直す
2青シールを選手のどこへ貼るか（服／選手用カード／手首など）シート上部に「貼付場所は主催者の指示に従う：＿＿＿」の記入欄を置いた当日その欄に書き込むだけでよい

主催者へ確認する質問は、この2つに絞る。

1. 2点減点の選手は、どのように識別しますか？（黄色＝減点1は確定）
2. 計量済みの青番号シールは、選手のどこへ貼りますか？

   ↓
