## 2. 100名までの逆算

残り期間: 約2ヶ月（9月残り約26日＋10月）／必要純増: 約20名

**目標（保守的）**

- 月間純増目標: 10名（退会を差し引いた純増）
- 体験→入会CVR: **仮に30〜40%と置く（未計測）**。実測がこれより低ければ体験数を増やす
- 必要体験人数: 月間25〜35名程度
- 必要LINE追加・予約リード: 月間50〜80名程度（予約率を**仮に**40〜50%と置く）

**週次・日次**

- 週間純増目標: 約2.5名
- 週間体験目標: 6〜9名
- 日次: 体験予約を毎日最低1件確保する意識

CVR・退会率は計測開始後に即修正する。未計測の数字を前提に過剰な目標は立てない。

## 3. 最大ボトルネック（優先順）

1. **体験予約までの導線が分断されている** — SNS・広告・Google・ホームページ・LINEがつながっておらず離脱が多い
2. **数字の計測不足** — 流入元・LINE追加・予約・来店・入会・CPA・体験→入会率・退会率が一元管理されていない。改善判断ができない
3. **優先順位の分散** — AI・動画・Web開発など「できること」が多く、100名達成に直結しない作業に時間が流れやすい

## 4. 今すぐ実行する施策（5個・これ以外は増やさない）

### 施策1: ファネル計測の完全整備（最優先・基盤）

- 内容: Google Analytics / Meta広告 / LINE公式 / 体験予約記録を突き合わせる。流入を「広告経由」「オーガニック」「紹介」に分ける。体験予約→来店→入会を毎日記録する
- 既存の道具を使う（新規開発しない）:
  - 体験→入会: LINEで `体験予約 <名前>` → `体験完了 <名前> 入会 <流入元>` → `体験集計`（実装: `src/commands/trial_kpi.ts`、流入元は LINE / Google / SNS / 紹介 / その他 / 不明）
  - 在籍・純増: §7 の台帳テンプレを Vault にコピーして手書き
  - 週次点検: `docs/weekly_sales_funnel.md`（月曜10分）
- 期待獲得人数: 直接0（以降の全施策の精度が上がる。間接的に+5〜10名）
- 費用: 0〜1万円 ／ 実装時間: 1〜2日 ／ 担当: JIN（AIは下書きまで）
- 締切: **9月6日**
- KPI: 全ファネルの数字が毎日見える状態
- 中止判断: 9月10日時点で数字が取れなければ即座に手作業へ切り替えて続行

### 施策2: 既存LINE約1,400人への再活性化＋紹介促進

- 内容: 過去体験者・友だち向けに「秋の初心者歓迎キャンペーン」。**値下げはしない**。限定枠・女性/キッズ優先・紹介特典のみ。紹介は双方に軽微な特典
- **注意**: 特典は原則 canon の `referralBenefit`（FLATUPバンテージ）を使う。タオル等に変える場合は既存紹介者との不公平をJINが判断してからcanon更新
- 期待獲得人数: 5〜8名（純増）／ 費用: 1〜3万円（特典実費）／ 実装時間: 3日
- 担当: AIKA（下書き）＋JIN（確認・送信）
- 締切: 9月10日 配信開始
- KPI: 配信後7日以内の体験予約数・入会数
- 中止判断: 予約5件未満ならメッセージ内容を修正して再送
- 承認: 一斉配信は送信前にオーナー承認（AIは下書きまで）

### 施策3: Google口コミ＋マップ最適化＋地域検索強化

- 内容: 体験・入会後の適切なタイミングでの口コミ依頼導線を徹底（既存の強化）。写真・最新スケジュール・「初心者/女性/キッズ」キーワードを最新化
- 期待獲得人数: 3〜5名 ／ 費用: 0円 ／ 実装時間: 2日 ／ 担当: JIN
- 締切: 9月8日
- KPI: 口コミ件数 +5件、マップ経由の問い合わせ増
- 中止判断: 2週間で問い合わせが増えなければ依頼文言を変更
- 注意: 口コミ依頼は乱発しない（週2人まで／`docs/weekly_sales_funnel.md` §5）

### 施策4: 少額 Meta / Instagram 広告テスト（勝ちクリエイティブ特定）

- 内容: 1日1,000〜3,000円から。ターゲットは「成田周辺・30〜40代女性・キッズ親・運動初心者」。訴求は「怖くない・明るい・女性オーナー・500円体験」。CTR→LINE追加→予約まで追跡できるものだけ採用
- **広告文面はcanon準拠**（入会金の表記は §0 が確定するまで書かない。アクセスは「成田駅からバス＋徒歩5分」）
- 期待獲得人数: 4〜7名
- 費用: 最初の2週間で3〜5万円テスト → 勝ちパターンだけ増額
- 実装時間: 広告セット作成1日＋運用継続 ／ 担当: JIN（AIはクリエイティブ下書き）
- 締切: 9月7日 テスト開始
- KPI: CPA（体験予約単価）・LINE追加単価
- 中止判断: 体験1件あたり5,000円を超えたら即停止・修正
- 承認: 出稿・増額はオーナー承認（課金・公開のため）

### 施策5: 体験後フォローの半自動化＋タグ管理

- 内容: 「体験予約済み / 体験済み未入会 / 口コミ候補 / 2週間未来店」のタグをLINEで運用。AI下書き→人間確認→送信を厳守。二重案内・文脈無視を防ぐ
- 使う道具: `npm run trial-followup`、`npm run inquiry`（いずれも下書き生成のみ）
- 期待獲得人数: 既存リードから2〜4名
- 費用: 0円 ／ 実装時間: 3日 ／ 担当: AIKA＋JIN
- 締切: 9月9日 運用開始
- KPI: 体験→入会CVRの向上
- 中止判断: 誤返信が続く場合は手動比率を上げる

**この5つ以外の新規開発（大規模WebOS拡張・大量アニメ制作など）は11月1日以降に回す。**
