# 23_FOUR_WEEK_EXPERIMENTS — 4週間の改善実験

作成: 2026-07-19（Fable 5正本化セッション）
状態: **ドラフト（JIN承認待ち）**

---

## ルール

- **1週にひとつだけ変える。** 同時に2つ変えたら、何が効いたか分からなくなる。
- 評価は**投稿数・広告本数ではなく、売上導線のどこが改善したか**で行う。
- 費用と作業量が少ない順に並べてある。上から順にやる。
- 効果が出なかった実験は**やめる**。続けない。
- 送信・公開はすべてJIN。openQLOWは下書きと集計まで。

---

## 第1週｜返信を24時間以内にする

**費用**: 0円　**作業量**: 1日5分

**やること**
毎日1回 `npm run crm -- followups` を実行し、24時間以上動きのない見込み客をゼロにする。返信の下書きはAIKAが出す。JINは確認して送るだけ。

**変えるのはこれだけ**。文面も、広告も、投稿も、今週は一切変えない。

**測る数字**
- 24時間以上未返信の件数（週の合計）→ **0件を目標**
- 問い合わせ → 体験予約の転換率

**成功の判定**
未返信が0件になり、かつ問い合わせ→予約の転換率が前週より上がっていれば成功。

**なぜ最初にこれか**
どんなに良い広告を出しても、返信が遅ければすべて漏れる。**費用ゼロで効果が最も大きい**のは、既に来ている問い合わせを取りこぼさないこと。

**記録欄**
```
実施週: ____   未返信件数 ____ 件（前週 ____ 件）
問い合わせ→予約 ____ %（前週 ____ %）
続ける / やめる: ____
```

## 第2週｜返信に日程候補を2つ添える

**費用**: 0円　**作業量**: 返信1通あたり10秒

**やること**
体験の案内をするとき、必ず日程候補を2つ書く。お客様が「選ぶだけ」の状態にする。

例（AIKAの文面制約：3文・200文字以内・記号なし）:
```
ご希望ありがとうございます。直近ですと火曜18:00か土曜13:00がご案内しやすいのですが、いかがでしょうか。ご都合が合わなければ別の日もお出ししますのでお知らせください😊
```

**注意**: 候補を出すことは日時の**確定ではない**。最終確定は必ずJINが行う（`confirm_reservation` は人間の領域）。

**測る数字**
- 体験予約数 ÷ 問い合わせ数
- 予約 → 実施の到達率

**成功の判定**
問い合わせ→予約の転換率が上がる。到達率が下がっていないこと（候補を出したせいで曖昧になっていないか）。

**記録欄**
```
実施週: ____   問い合わせ→予約 ____ %（前週 ____ %）
予約→実施 ____ %（前週 ____ %）
続ける / やめる: ____
```

## 第3週｜体験後72時間の型を作る

**費用**: 0円　**作業量**: 体験1人あたり3分

**やること**
体験に来た人全員に、同じ型で接触する。

| タイミング | 内容 | 生成 |
|---|---|---|
| 当日中 | お礼だけ。営業しない | `npm run trial-followup` |
| 翌日 | 良かった点を1つ具体的に触れる | 同上 |
| 3日後 | 入会案内を1通だけ。断りやすい一文を必ず入れる | 同上 |

3日後を過ぎたら追わない。押し込みはブランドに反する。

**測る数字**
- 体験 → 入会の転換率
- 体験済み・未入会の滞留件数

**成功の判定**
転換率が上がり、滞留件数が減る。**転換率が上がっても失注理由に「しつこい」が出たら失敗**として扱う。

**記録欄**
```
実施週: ____   体験→入会 ____ %（前週 ____ %）
滞留件数 ____ 件（前週 ____ 件）
失注理由に押し売り系の記載: あり / なし
続ける / やめる: ____
```

## 第4週｜口コミ依頼を入会直後に1通送る

**費用**: 0円　**作業量**: 1人あたり2分

**やること**
`npm run crm -- followups` の「口コミ依頼候補」（入会済み）を見て、**入会直後の良い時期**に1通だけ依頼する。候補は3人までに絞る。2回目の依頼はしない。

**測る数字**
- 依頼送信数
- 増えた口コミ件数（Googleで手で数える）
- 翌週以降の紹介経由の問い合わせ数

**成功の判定**
口コミが1件でも増えれば成功。紹介経由の問い合わせは翌週以降に遅れて出るため、**第5週まで観察する**。

**なぜ最後か**
口コミと紹介は、前の3週で「良い体験」が積み上がっていないと発生しない。順番を逆にすると、満足していない人に依頼することになって逆効果になる。

**記録欄**
```
実施週: ____   依頼送信 ____ 件 / 口コミ増加 ____ 件
翌週の紹介経由の問い合わせ ____ 件
続ける / やめる: ____
```

## 4週間が終わったら

### 振り返りの手順（20分）

1. 4週分の記録欄を並べる。
2. **導線のどこが太くなったか**を1つだけ特定する（問い合わせ→予約 / 予約→実施 / 体験→入会 / 口コミ→紹介）。
3. 効果があった実験は**定常運用にする**（`21_OPENQLOW_WEEKLY_SOP.md` の毎日5分か月曜の手順に組み込む）。
4. 効果がなかった実験は**やめる**。理由を1行だけ書いて終わる。

### 次の4週で検討してよいこと（費用が発生する側）

前の4週で導線が詰まっていないことを確認してから進む。詰まったまま出稿すると、費用をかけて取りこぼしを増やすことになる。

| 実験案 | 費用 | 先に満たすべき条件 |
|---|---|---|
| 紹介の道具を配る（転送できる1通） | 0円 | 口コミが増え始めていること |
| 来館の空いた会員への声かけを定例化 | 0円 | 退会率が把握できていること |
| セグメント別の広告文を1本テスト | 少額 | 問い合わせ→予約が7割以上 |
| LP・HPの改善（`npm run site-audit`） | 0円〜 | 広告からの流入がある場合のみ |

### この4週で**やらないこと**

- 値下げ・キャンペーンの新設（安売りは禁止事項。判断はJINのみ）
- 動画・アニメ・リールの本数を増やすこと（本数は導線の指標にならない）
- 複数の実験を同時に走らせること
- 数字が1週悪かっただけで実験を止めること（最低2週は見る）
