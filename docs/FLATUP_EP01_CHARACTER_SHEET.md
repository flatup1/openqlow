# FLATUP GYM BRAND FILM 第1話 キャラクター設定
## 「今日いちばん頑張った子は誰?」

> 追加カットをAIで生成するとき、**この設定と完全に一致させる**こと。
> 見た目がぶれると物語が破綻する(同じ子だと分からなくなる)。

---

## ★ 主人公:少年(名前は作中で呼ばない)

はじめてジムに来た、お母さんに手を引かれる男の子。

| 項目 | 設定 |
|---|---|
| 年齢感 | 4〜6歳(未就学〜小学校低学年) |
| 髪 | 短めの茶色。少し柔らかく、前髪が自然に分かれる |
| 目 | 大きく丸い茶色の瞳。まつげは控えめ |
| 表情の基本 | 不安げに眉が下がる → 終盤で少しだけ笑う |
| 服(上) | ベージュ〜生成りの半袖Tシャツ(無地) |
| 服(下) | 紺のショートパンツ |
| 足元 | 白ソックス + グレーのスニーカー |
| 小物 | ピンクの子ども用ボクシンググローブ(少し大きめ) |

**このグローブが「自分には大きすぎる挑戦」の象徴。物語が進んでも小さくならない。**

### 心の変化(この物語の軸)
```
怖い（入口で足がとまる）
  → ゆっくりでいい（グローブをはめてもらう）
  → やってみる（はじめてのミット打ち）
  → ひとりじゃない（仲間がいる）
  → また来たい（帰り道）
```

## ★ お母さん

急かさない。責めない。ただ、となりで見ている人。

| 項目 | 設定 |
|---|---|
| 年齢感 | 30代前半 |
| 髪 | 黒〜こげ茶のポニーテール。ほつれ毛が少しある |
| 服 | グレーのパーカー(フード付き) + 濃いグレーのレギンス |
| 足元 | 白〜オフホワイトのスニーカー |
| 小物 | ベージュのトートバッグ(肩掛け) |
| 表情 | やわらかい微笑み。見守るときは手を組む |

**セリフは最小限。「だいじょうぶ。ゆっくりでいいよ。」が唯一の言葉。**

## ★ 道具たち(語り手)

夜のジムで、その日を思い出して語り合う。**主人公ではなく、語り手**。

| キャラ | 色 | 名札の色 | 性格 |
|---|---|---|---|
| ミット | 黒×赤の楕円 | 黄 | 落ち着いた年長者。問いを立てる |
| グローブ | ピンクの小さな双子 | ピンク | やさしい相づち役 |
| サンドバッグ | ピンク / 黄の大きい2本 | オレンジ | 無口だが、よく見ている |

デザイン: 大きな丸い目・小さな笑み。怖い顔にしない。過度な擬人化(手足を増やす等)もしない。

## ★ 舞台:FLAT UP GYM

| 項目 | 設定 |
|---|---|
| 内装 | 白い床・白い壁・木の温かみ・観葉植物 |

| マット | 緑のトレーニングマット |
| 照明 | 夜=あたたかい電球色 / 昼=自然光 |

## ★ AI画像生成のとき必ず入れる指定

```
warm cinematic 3D animated film style, soft lighting,
a 5-year-old boy with short brown hair and large round brown eyes,
beige t-shirt, navy shorts, grey sneakers, pink boxing gloves,
his mother in a grey hoodie with a ponytail and beige tote bag,
bright clean gym with white floor, wooden accents, green plants,
pink and yellow punching bags,
gentle expression, no aggression, family-friendly
```

**禁止**: 怖い表情 / 攻撃的な構図 / 試合・勝敗の演出 / 既存アニメ作品の模倣 /
主人公を別のキャラ(マスコットの女の子など)に入れ替えること。
