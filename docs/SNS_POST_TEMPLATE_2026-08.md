## 2. 型のしくみ

### なぜ効くのか

読者の「難しそう」という思い込みを、**最初と最後の2回で挟んで壊す**構造です。

```
1. 結論を先に断言        → スクロールを止める
2. 昔と今を対比          → 「今は違う」と気づかせる
3. 中身を具体的に並べる  → 「全部入り」を示す
4. 想定シーンを列挙      → 「これ自分だ」と拾う
5. ハードルを下げて締める → 一歩目を踏ませる
```

### 空テンプレ（次回はここを埋めるだけ）

```
【1. 断言】
{{ 対象の行動 }}は、昔より{{ ずっとやさしく }}なりました。

【2. 対比】
昔は{{ 過去の重いイメージ }}が必要でした。
でも今は、{{ 今の条件 }}があれば大丈夫です。

【3. 中身】
{{ 事実を3〜4つ、名詞で並べる }}

【4. 自分ごと化】
{{ 想定読者のシーンを3〜4つ列挙 }}——そんな方に向いています。

【5. ハードル下げ】
やってみると、思っていたほど{{ 難しくない／怖くない }}と分かります。

【CTA】{{ 次の一歩を1つだけ }}
```

### 埋めるときのルール

| 項目 | ルール |
|---|---|
| 断言（1） | 「日本一」「絶対」「必ず」は使わない。比べる相手は「昔のイメージ」だけ |
| 対比（2） | 他ジムを下げない |
| 中身（3） | `src/shared/canon.ts` にある事実だけ。数字を直書きしない |
| 自分ごと化（4） | 初心者／女性／キッズ・保護者／シニア・再挑戦の男性から選ぶ |
| CTA（5） | **1投稿につき1つだけ** |
| 料金 | **「初回体験500円」は1投稿に1回まで**（連呼すると安売りに見える） |
| 曜日 | **書かない**。体験可能日は性別で違うため、「ご希望の曜日をお知らせください」に寄せる |
| 絵文字 | 1投稿に1〜2個まで（`brand_voice.md`） |

### なぜ1日ずつずらすのか

同じ文章を同じ日に全媒体へ流すと、同じ人に3回見えて「宣伝がしつこい」と感じられます。1日ずらすだけでこれを避けられます。作業時間は変わりません。

### 2週目以降

同じ型のまま、§2の【4. 自分ごと化】だけを差し替えます。

## 7. JIN確認事項（残り1件）

### 7-1. 写真の肖像同意（所要5分）

`flatup-webos/app/hero.jpg` に写る**お子さんの保護者同意**が取れているかの確認。

- すでに公式サイトのトップに掲載されているため、同意済みの可能性が高いです（ただしこれは**推測**です）
- 確認が取れない場合は、§3の代替案（グローブだけ／靴箱だけの写真）に差し替えれば、同意確認なしで進められます

> 同意関連の運用は `docs/GUARDIAN_CONSENT_LINE_SETUP.md` を参照。
