## 0. この型が効く理由

読者の「難しそう」という思い込みを、**冒頭と末尾の2回で挟んで壊す**構造。

```
1. 結論を先に断言        → スクロールを止める
2. 昔と今を対比          → 「今は違う」と気づかせる
3. 中身を具体的に並べる  → 「全部入り」を示す
4. 想定シーンを列挙      → 「これ自分だ」と拾う
5. ハードルを下げて締める → 一歩目を踏ませる
```

FLATUPの弱点は「格闘技＝怖い・きつい・経験者だけ」という思い込み。
この型は、その思い込みを正面から扱えるので相性が良い。

## 1. 空テンプレ（穴埋め用）

```
【1. 断言】
{{ 対象の行動 }}は、昔より{{ ずっとやさしく }}なりました。

【2. 対比】
昔は{{ 過去の重いイメージ }}が必要でした。
でも今は、{{ 今の条件 }}があれば大丈夫です。

【3. 中身】
{{ 工程・内容を3〜4つ、名詞で並べる }}

【4. 自分ごと化】
{{ 想定読者のシーンを3〜4つ列挙 }}——そんな方に向いています。

【5. ハードル下げ】
やってみると、思っていたほど{{ 難しくない／怖くない }}と分かります。

【CTA】{{ 次の一歩を1つだけ }}
```

### 埋めるときの注意

| 項目 | ルール |
|---|---|
| 断言（1） | 「日本一」「絶対」「必ず」は使わない。比較は自社の過去比までにする |
| 対比（2） | 他ジムを下げない。下げるのは「昔のイメージ」だけ |
| 中身（3） | canonにある事実だけ。数字は `src/shared/canon.ts` から引く |
| 自分ごと化（4） | 初心者／女性／キッズ・保護者／シニア・再挑戦の男性から選ぶ |
| CTA（5） | 1投稿につき1つだけ。押し売りしない |

| クラス一覧 | OK | `canon.classes` と一致 |
