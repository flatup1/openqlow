# 退会対応マニュアル（スタッフ用・1枚）

**この紙のとおりに押すだけ。退会日は計算しないでください。システムが決めます。**

---

## 毎朝これだけ

```
npm run crm -- withdrawal alerts
```

「⚠ 会費ペイ未処理 ◯件」と出たら、その人の処理が終わっていません。**0件になるまで残ります。**

---

## お客様から「辞めたい」と言われたら

### ステップ1　相談を記録する

```
npm run crm -- withdrawal open --member <会員番号> --name <お名前> --channel LINE
```

`--channel` は聞いた場所：`LINE` / `電話` / `メール` / `来館`

> LINEで来た場合は自動で記録されるので、この操作は不要です。

### ステップ2　手続きを案内する

```
npm run crm -- withdrawal guide <番号>
```

文面が出るのでコピーして送ってください。送ったら:

```
npm run crm -- withdrawal guide <番号> --sent
```

**伝えること（文面に入っています）**
- 退会は「正式なお手続きをした日の翌月末」
- LINE・電話・メールだけでは受付にならない
- 退会届の記入 と カードキーの返却 の2つが必要

### ステップ3　ご来館されたら

退会届を受け取ったら:
```
npm run crm -- withdrawal form <番号>
```

カードキーを受け取ったら:
```
npm run crm -- withdrawal key <番号>
```

**この2つが揃った瞬間、システムが退会日を自動で決めます。** あなたは計算しません。

### ステップ4　退会日をお伝えする

```
npm run crm -- withdrawal notice <番号>
```

正式受付日・退会予定日・最終在籍月が入った文面が出ます。送ったら `--sent` を付けて実行。

### ステップ5　会費ペイを止める

会費ペイの画面で停止操作をしてから:

```
npm run crm -- withdrawal payment-done <番号>
```

**これを押すまで、毎朝の警告に出続けます。**

### ステップ6　退会日が来たら

```
npm run crm -- withdrawal close <番号>
```

## 困ったときは押さないで、オーナーへ

次の言葉が出たら、**自分で判断せずに**オーナーへ回してください。

- 返金してほしい / 日割りにして / 即日で辞めたい
- 聞いていない / 納得できない
- 弁護士 / 消費生活センター / 口コミに書く
- 入院 / 海外へ引っ越し
- カードキーをなくした
- ご本人以外（ご家族）からの連絡

```
npm run crm -- withdrawal owner-review <番号> --reason "返金を求められている"
```

## よくある質問

**Q. 退会日はいつになりますか？**
A. 退会届とカードキーが**両方そろった日**の翌月末です。8月20日にそろったら9月30日。

**Q. 退会届だけ先にもらいました。退会日は？**
A. **まだ決まりません。** カードキーが返ってくるまで受付は成立しません。

**Q. 8月31日に退会届、9月1日にカードキー。どっちが受付日？**
A. **遅いほうの9月1日**です。だから退会日は10月31日になります。

**Q. LINEで「退会します」と来ました。受付になりますか？**
A. **なりません。** 相談として記録されるだけです。ご来館いただいてください。

**Q. 日付を間違えて登録しました。**
A. スタッフでは直せません。オーナーに元の日付（退会届日・カードキー返却日）を直してもらうと、退会日は自動で計算し直されます。

**Q. 自分の名前を記録に残したい**
A. 端末に `OPENQLOW_STAFF_NAME=あなたの名前` を設定すると、誰が押したか履歴に残ります。

## お客様対応で大事なこと

引き止めません。**気持ちよく辞めていただくと、戻ってきてくださることがあります。**

- 「ありがとうございました」を必ず伝える
- 退会予定日まではいつもどおり使えることを伝える
- 責める言い方をしない（文面はそうなっています）
