## 4. 意図的に入れた制約（外す前に必ず読む）

次の3点は、素材にあった内容を**意図的に変更または除外**したもの。理由がある。

### 4-1. 特定作品名・スタジオ名をプロンプトに書かない（公開時）

素材には `ufotable style, Demon Slayer anime aesthetic`、`more intense than the Frieza fight` といった指定があった。

- **社内検証では使ってよい**
- **公開する映像では描写指定に置き換える**（言い換え辞書を高強度ガイド §3 に収録）

理由: (1) 生成サービスの利用規約で特定IPを狙った生成が制限される場合がある (2) 商用ブランド映像として公開すると権利面の指摘を受けうる (3) フィルタで弾かれて生成が安定しない。

### 4-2. 強度A / 強度B の分類

素材には「唾が飛ぶ」「血管が浮き出る」「相手が吹き飛ぶ」「痛みの表情」といった表現があった。

- **強度A（使用可）**: 残像・速度線・空間歪み・インパクトフレーム・粒子・カメラの追随遅れ。打撃対象はサンドバッグ／ミット／シャドーのみ
- **強度B（FLATUP名義では不採用）**: 人物への打撃、被弾、痛みの表情、唾・血管の誇張

理由: `docs/FLATUP_ANIMATION_BIBLE.md` の約束「怒鳴らない・笑わない・比べない」と中心メッセージ「はじめの一歩を、笑わない」に正面から反する。初心者が怖いと感じた時点で集客導線として逆効果になる。

**強度Aでも迫力は出せる。** 力の大きさは「相手の痛み」ではなく **環境の反応**（埃・チェーン・照明の揺れ）で見せる、というのが解。実例プロンプト3本はこの方針で書いてある。

強度BをFLATUPの外側で使う判断は、JINのもの。承認ゲートに項目として入れてある。

### 4-3. 実写素材の同意を最優先セクションにした

実技動画をモーション参照に使う＝誰かの体が写った映像を外部AIにアップロードすること。

- 未成年会員は保護者同意が必須（`docs/GUARDIAN_CONSENT_LINE_SETUP.md` の運用）
- 第三者のSNS動画は使用不可
- アップロード先の学習利用オプトアウトを確認する
- 無料プランは学習利用が前提の場合があるため、会員の映像を上げない
- 元動画と生成物は **Gitに入れない**
- **迷ったらJIN本人の映像を使う**（最も速く、最も安全）

## 6. 次にやること（優先順）

1. **強度Aの実例を1本生成して検証する** — `FLATUP_ANIME_HIGH_INTENSITY_ACTION_GUIDE.md` §9-1（夜のジム、溜め→瞬間移動→サンドバッグへの一撃）。確認するのは次の4点:
   - 溜めが本動作より明らかに長いか（2〜4秒 : 0.1〜0.5秒）
   - 残像が段階的に薄くなっているか
   - 打撃の瞬間にスローとインパクトフレームが入っているか
   - 粒子が体を隠していないか
2. **崩れた箇所だけプロンプトを強化して再生成** — 全体を書き直さない。これがガイドの基本方針。
3. **採用できたプロンプトをガイドに追記** — 技名だけ差し替え可能な形にする
4. **教則動画を1技分作る** — `FLATUP_ANIME_MARTIAL_ARTS_TUTORIAL_GUIDE.md` §6-3（構え・ガード）が最も安全で、初心者向けの導線に直結する
5. **実写モーション参照を試す場合** — まずJIN本人の映像で。会員の映像は同意取得後、オーナー承認後

## 7. 承認ゲート（AIだけで進めてはいけないこと）

`docs/ai-os/canon/approval_matrix.md` に従う。

- 有料クレジットの購入・課金プランへの変更
- SNS、LP、YouTube等への公開・投稿
- ブランド映像への採用
- 強度Bの使用判断
- **会員（特に未成年）が写った映像の撮影・外部サービスへのアップロード**
- 作品名を含むスタイル指定の公開利用
- commit / push / PR

AIは、プロンプト作成、試作生成、社内確認までは進めてよい。
