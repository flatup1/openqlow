## 30秒版・シーン構成（基本構成）

### 全体フロー

```
S1（試合後） 4s  → S4-5（心の気づき） 8s  → S6（翌日の実行） 5s  → S7（エンディング） 6s + 3s テロップ
```

---

## シーン別詳細（30秒版ベース）

### S1｜試合直後・ミディアム

**尺**: 4秒  
**アクション**: レンがガッツポーズで喜ぶ ↔ ユズキが俯いたまま

**撮影指示**
- カット1（2s）: レンのガッツポーズ（満面の笑み）
- カット2（2s）: 同じフレーム内、背景奥でユズキが静かに去る

**表情指示**
- レン: 満面の笑み、高揚感
- ユズキ: 俯いて無表情（静寂感）

**BGM**: 高揚感のあるリズム（でも少しズレた響き）

**効果音**: 歓声、拍手

---

### S4-5（統合）｜象徴世界での気づき

**尺**: 8秒  
**アクション**: レンの迷い → フラットちゃんの問い → 気づき

**分割**
- S4a（3s）: レンが戸惑った表情で立つ、フラットちゃんが問いかけ
- S4b（2s）: レンが「見てなかった」と気づく
- S5（3s）: ★核ショット - レンの表情が緊張から決意に変わる

**表情指示**
- S4a: レン＝戸惑い、フラットちゃん＝優しさ
- S4b: レン＝はっとした表情
- S5: レン＝決意の顔（本話最重要カット）

**BGM**: 静かな温かい響き → 朝日のように上向く

**効果音**: 静寂、静かな呼吸

**撮影指示**
- 背景は色のない静かな空間（象徴世界）
- S5 のレンの表情変化は**スローモーション気味**に

---

### S6｜翌日・ジム

**尺**: 5秒  
**アクション**: レンがユズキに声をかけ、ユズキが嬉しそうに反応

**分割**
- S6a（2.5s）: レンがユズキに近づき、話しかける
- S6b（2.5s）: ユズキが驚いた顔から嬉しそうな表情に変わる

**表情指示**
- S6a: レン＝照れながらも真剣、ユズキ＝最初驚く
- S6b: ユズキ＝嬉しそうな笑顔に変わる

**BGM**: 温かく前向き

**効果音**: 練習前の静かな空気、軽いBGM

**撮影指示**
- ジムの夕方の光（温かい）
- レンとユズキのミディアム2ショット
- 目線が合う瞬間を強調

---

### S7｜夜のジム・エンディング

**尺**: 6秒（本編） + 3秒（テロップ）

**分割**
- S7a（3s）: フラットちゃんとミットの円座での言葉
- S7b（3s）: レンとユズキが並んで練習する後ろ姿のシルエット
- テロップ（3s）: メッセージ＋ロゴ

**表情指示**
- フラットちゃん: 温かい笑顔
- ミット: 頷く仕草

**BGM**: 温かく余韻を残す

**テロップ内容**
```
勝った人が、偉いんじゃない。
勝っても、相手を見てあげられる人が、優しい強さを持ってる。

今日も、小さな優しい強さを。

怒鳴らない。比べない。置いていかない。
FLAT UP GYM
```

**撮影指示**
- 夜のジム全景（星型フロア、青い月光）
- フラットちゃん + ミット（円座）
- 手前にレン + ユズキの後ろ姿シルエット

## 15秒版への圧縮（参考）

```
S1（2s） + S4-5（4s） + S6（3s） + S7（3s+3s テロップ）= 15s
```

**削減ポイント**
- S1: ユズキの描写を最小限に
- S4-5: 心の気づきの途中段階をカット
- S6: リアクションを短縮

---

## 45秒版への拡張（参考）

```
S1-2（6s） + S3（3s） + S4-5（12s） + S6（7s） + S7（9s+3s テロップ）= 45s
```

**追加要素**
- S1-2を分離（ユズキが去る場面を詳しく）
- S3を挿入（夜のジムの会話）
- S4-5の間延びを活かす（気づきのプロセスを丹念に）
- S6を拡張（会話の詳細）

## タイミング・リズム設計

### 「見えていない痛み」の間の使い方

```
S1 終盤（1.5s）: レンが喜んでいる
    ↓
    【1s の間】: 喜びと悲しみが並存
    ↓
S2 開始（0.5s）: ユズキが去る
```

この**間の質感**が重要。  
同じ画面に喜びと悲しみが共存する瞬間を、テンポよく見せず、**ゆったり**見せる。

### 気づきのプロセスの間

```
S4b「見てなかったかも」（0.5s 短い返答）
    ↓
    【1s の間】: 静寂が満ちる
    ↓
S5「表情が変わる」（3s 核ショット、やや長め）
```

このプロセスで、単なる「返答」ではなく「人格的な変化」を見せる。

## オーディオ設計

### BGM トランジション

| シーン | BGM | 意図 |
|---|---|---|
| S1 | 高揚感のあるリズム（少しズレた響き） | 無邪気さと違和感 |
| S4 | 静かに温度が上がる | 重圧感から解放へ |
| S5 | 朝日のように上向く | 決意の瞬間 |
| S6 | 温かく前向き | 関係が戻る |
| S7 | 温かく余韻を残す | 結びの余韻 |

### 効果音

- **S1**: 歓声、拍手（リアル）
- **S2**: 静か（無言を強調）
- **S4-5**: 静寂 + 静かな呼吸（内面性）
- **S6**: 練習前の空気感（日常が戻る）
- **S7**: 静か + 柔らかいBGM
