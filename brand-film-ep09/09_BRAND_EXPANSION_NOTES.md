# EP09「かった、から、こそ。」— HP・LINE転用ノート

**前提**: 本パッケージの段階では HP と LINE ボットの実装変更は行わない。広告の検証結果が出てから転用する。

---

## 1. 転用の順序

1. 公開 → 検証（`08_TESTING_METRICS.md`）
2. 反応の良かった言葉・シーン・感情構造を特定
3. **先にブランド正本を更新**（HP や LINE を先にいじらない）
4. 正本に基づいて LINE・HP・SNS・接客文面へ一貫展開

**媒体より先に正本**。順序を破ると、HP だけ新しくなって LINE が旧来の格闘技寄りのまま残り、ブランド体験が分裂する。

## 3. ホームページへ転用するときの注意

- 勝った要素だけを持ち込む。反応のなかったコピーを HP で復活させない
- ヒーロー領域の第一候補: **C06-B の静止画 + 勝ちコピー**（動画より軽い）
- 動画をヒーローに置く場合、読み込み速度・自動再生ミュート・モバイル通信量を必ず検証する
- **予約・料金などの実用情報を消さない**。世界観のために導線を壊さない
- EP09 は「勝ち負け三部作」の完結編。HP で単体掲載する場合は EP07・EP08 の文脈がなくても伝わるか確認する

---

## 4. LINEボット（AIKA）へ転用するときの注意

- ボットの人格を「夜のマスコット」にしない。転用するのは**価値観と言葉遣いのみ**
- 転用する原則: 売り込まない / 急かさない / 不安を否定しない / 初心者目線 / 強さより安全・楽しさ・続けやすさ
- **EP09 固有の注意**: 「勝ち負け」の話題は保護者の地雷になりやすい。AIKA の返信テンプレに「勝てる」「強くなれる」を入れない
- 詩的なコピーをそのまま会話で連発しない（不自然になる）
- `AGENTS.md` の LINE 運用規則（3〜5行・押し売りしない・送信は人間承認）と矛盾しないこと

---

## 5. SNS・接客文面への展開

- 投稿文・DM返信・店頭の声かけまで「共感 → 安心 → FLATUP → 優しい導線」の順序を統一
- **禁止表現**（媒体を問わず）: 「強い子に育てる」「いじめ対策」「今始めないと」「試合で勝てる」
- EP09 の文脈で特に危険な言い回し: 「勝てる子に育てます」「試合実績多数」→ 使わない
