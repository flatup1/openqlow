## シーン別詳細（30秒版ベース）

### S1｜練習フロア・夕方（新入りの孤立）

**尺**: 4秒  
**アクション**: ダイが輪の外で一人立ち尽くす

**撮影指示**
- カット1（2s）: ダイが緊張して立っている
- カット2（2s）: 背景で他の子どもたちが賑やかに練習

**表情指示**
- ダイ: 極度の緊張・固まった表情
- 背景のキャラたち: 自然な練習風景（ダイには見えていない）

**BGM**: 少し不安げなピアノ

**効果音**: 賑やかな練習音 vs. ダイの周りだけ静か

**子に伝える**: 初めての場所は、誰でも怖い

---

### S2｜練習フロア・夕方（迷い）

**尺**: 2秒  
**アクション**: ユウが気づくが、声をかけずに立ち去る

**撮影指示**
- カット1（1s）: ユウがダイに気づく
- カット2（1s）: ユウが踏み出しかけ、引っ込める→自分の練習に戻る

**表情指示**
- ユウ: 気にはなるが、迷いの表情
- 内心の台詞：「……なんて言えばいいんだろう」

**BGM**: 変わらず（不安感は続く）

**効果音**: 静かなためらいの気配

**子に伝える**: 優しくしようとするときも、こわいことがある

---

### S3｜夜のジム・深夜（フラットちゃんの告白）

**尺**: 3秒  
**アクション**: フラットちゃんが「私も最初はこわかった」と話す

**撮影指示**
- カット1（3s）: フラットちゃん + 道具たちの円座

**表情指示**
- フラットちゃん: 少し照れた懐かしそうな表情
- 道具たち: 驚きと共感

**BGM**: 温かいピアノ（内省的）

**効果音**: 静かな衣擦れ

**子に伝える**: 優しいお姉さんも、最初はドキドキしてたんだ

---

### S4｜象徴世界（勇気への転換・第1段階）

**尺**: 3秒  
**アクション**: フラットちゃんが「声をかけようとしてたよね」と問いかけ

**撮影指示**
- カット1（3s）: ユウ + フラットちゃんのミディアム（灰色空間）

**表情指示**
- ユウ: 最初は困った表情 → 気づきに変わる
- フラットちゃん: 責めずに、静かに問い続ける

**BGM**: 静かに温度が上がる

**効果音**: 静寂、静かな呼吸

**子に伝える**: 親切にしたいのに、こわくなること、あるよね

---

### S5｜象徴世界・心の技レッスン（★核ショット）

**尺**: 6秒  
**アクション**: ユウの表情が迷いから軽くなる、勇気が芽生える

**撮影指示**
- カット1（6s）: ユウ + フラットちゃんの象徴世界

**表情指示**
- ユウ: 
  - 0-2s: 困惑（「もし嫌がられたら」の恐れ）
  - 2-4s: はっとした表情（理由の自覚）
  - 4-6s: ふっと表情が軽くなる（「完璧でなくていい」の許可）
- フラットちゃん: 温かく見守る、微笑む

**BGM**: 静かな響き → 朝日のように柔らかく上向く

**効果音**: 静寂から、環境音が徐々に入る

**スローモーション気味**: 表情の変化を強調

**子に伝える**: 短い一言でいい。急がなくていい

**🔴 核ショット（ここが本話の最重要）**
- ユウが「完璧な言葉は不要」という許可を得る
- 親切心にも勇気がいることを肯定される
- 「動く」ことへの心理的ハードルが下がる瞬間

---

### S6｜練習フロア・翌日（実行と喜び）

**尺**: 5秒  
**アクション**: ユウが「一緒に準備運動する？」と声をかけ、ダイが喜ぶ

**撮影指示**
- カット1（2.5s）: ユウが少し緊張しながらダイに近づく
- カット2（2.5s）: ダイの表情が驚き → 喜びに変わる

**表情指示**
- ユウ: 緊張しつつも真剣
- ダイ: 驚き → ほっとした笑顔

**BGM**: 温かく前向き

**効果音**: 静かな安堵の空気、足音

**子に伝える**: 短い一言が、誰かをほっとさせることがある

**重要**: 「一緒にやる？」という短さが強調される

---

### S7｜夜のジム・エンディング

**尺**: 6秒（本編） + 6秒（テロップ）

**分割**
- S7a（3s）: フラットちゃんと道具たちの言葉
- S7b（3s）: ユウとダイが並んで準備運動する後ろ姿シルエット
- テロップ（6s）: メッセージ + ロゴ

**表情指示**
- フラットちゃん: 満足げな微笑み
- 道具たち: 見守る姿勢

**BGM**: 温かく余韻を残す

**テロップ内容**
```
完璧な言葉じゃなくていい。
「一緒にやる？」それだけで、じゅうぶん。

今日も、小さな優しい強さを。

怒鳴らない。比べない。置いていかない。
FLAT UP GYM
```

**撮影指示**
- 夜のジム全景（星型フロア、黄緑月光）
- フラットちゃん + 道具たち（円座）
- 手前にユウ + ダイの後ろ姿シルエット

S1-2（2s） + S4-5（4s） + S6（2s） + S7（3s+3s テロップ）= 15s

**削減ポイント**
- S3（フラットちゃんの独白）をカット
- S4: 問いかけを短縮
- S5: 核ショットを 3s に短縮
- S6: 反応を最小限に

## 45秒版への拡張（参考）

```
S1-2（6s） + S3（4s） + S4-5（12s） + S6（8s） + S7（9s+3s テロップ）= 45s
```

**追加要素**
- S1-2 を分離（ダイの孤立 → ユウの迷いを詳しく）
- S3 を独立シーン化（フラットちゃんの独白をじっくり）
- S4-5 の間延びを活かす（勇気へのプロセスを丹念に）
- S6 を拡張（近づく動作、言葉、反応をすべて見せる）

## タイミング・リズム設計

### 「勇気が必要」の間の使い方

```
S1-2 終盤（1s）: ユウが迷っている
    ↓
    【1s の間】: 勇気と怖さが葛藤している
    ↓
S3 開始（0.5s）: フラットちゃんが話し始める
```

この**間の質感**が重要。  
「動けない」ことへの同情ではなく、「動く勇気の必要性」を感じさせる。

### 勇気への転換の間

```
S5「完璧な言葉じゃなくていい」（2s 許可）
    ↓
    【1s の間】: ユウの心に「やってみよう」が芽生える
    ↓
S6「一緒にやる？」（2s 実行、短い会話）
```

このプロセスで、単なる「励まし」ではなく「行動への変化」を見せる。
