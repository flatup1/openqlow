### C07 → C08 の切り返し（EP11 の要）

ユウが近づく（C07）→ ダイの顔が変わる（C08）の間に**フレームを空けない**。0 フレーム接続で、「声をかけた瞬間に相手の世界が変わる」ことを見せる。

## 2. グレーディング

| LUT | 適用カット | 内容 |
|---|---|---|
| **EP11-A グリーン＋ベージュ** | C02, C03, C07, C08, C09 | 希望と親しみ。G+6% / 全体をわずかに明るく |
| **EP11-B グレーブルー** | C01 | ダイの孤立。彩度 -25%、B 寄り。**他カットより 1 段暗く** |
| **EP11-C グレー→ウォームグリーン** | C04, C05, C06 | 象徴世界。開始グレー → 終端ウォームグリーン |
| 夜（C10） | — | EP11-A に黄緑月光を混ぜる |

### 核ショット（C06）の特別処理

- 明度 **+5%**
- 0:10–0:13 グレー → 0:13–0:16 ウォームグリーンへ線形補間
- **表情が「軽くなる」話なので、光も軽くする**。コントラストは上げない

### 孤立の可視化（EP11 固有）

C01 のダイは**周囲より 1 段暗く**する。ただし「暗い＝かわいそう」に振り切らない。彩度を落とすだけに留め、影を足さない。影を足すと悲劇になる。

## 3. エンドカード（0:24–0:30）

```
完璧な言葉じゃなくていい。
「一緒にやる？」それだけで、じゅうぶん。

今日も、小さな優しい強さを。

怒鳴らない。比べない。置いていかない。
FLAT UP GYM
```

### A/B 用の差し替え

| 版 | 1〜2行目 |
|---|---|
| **A（基準）** | 上記そのまま |
| **B** | `canon.ts` の `BRAND.tagline` |
| **C** | 「『一緒にやる？』それだけで、じゅうぶん。」のみ |

**C 案が有力**。本話のコピーは短いほうが強い可能性がある。

## 4. 音

| 時間 | 内容 |
|---|---|
| 0:00–0:02 | **ダイの周りだけ環境音を絞る**（孤立の音響表現）。BGM は静かなピアノ |
| 0:02–0:06 | 練習音が戻る。BGM は変わらず |
| 0:06–0:10 | 夜の静けさ。BGM が温かいピアノへ |
| 0:10–0:16 | **核ショット**。BGM が上向く。SE なし |
| 0:16–0:18 | **足音のみ**（ユウが近づく）。BGM を一瞬薄くする |
| 0:18–0:21.5 | 練習音と明るい空気。BGM 温かく前向き |
| 0:21.5–0:24 | 夜の静けさ。BGM が余韻へ |
| 0:24–0:30 | ピアノの最後の1音の残響のみ |

**設計意図**: 0:16 の足音だけを残す設計が、「勇気を出して近づく」の緊張を音で表す。
