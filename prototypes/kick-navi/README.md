# キックボクシングナビ（試作）

食べログ型のキックボクシングジム検索・口コミ・体験予約サイトの試作です。1ファイルのHTMLで、ブラウザで `index.html` を開くと動きます。

- 掲載ジム・口コミ・ユーザーはすべて架空のサンプルです。予約や投稿はどこにも送信されません（ブラウザ内にだけ保存）。
- 口コミとポイントは「運営の確認後」に反映します。確認済みの口コミが3件以上あるジムだけを評価ランキングに載せます。運営者がFLATUP GYMを経営していることを開示しています。
- 公開版（非公開リンク）：https://claude.ai/artifact/TfoyqEVzxLfMtoBzb87FNW （この `index.html` はその版 1792210792-3149 の保存です）
- 公開・課金・外部への送信・ポイントの代金・規約は、オーナーの承認と専門家の確認が必要です。
