### 🔴 C01 と C07 の対比（本話の要）

同じ技を、**同じカメラアングル・同じ画角**で撮る。違うのは動きの滑らかさだけ。
- 編集時に C01 と C07 を並べて確認し、**構図が一致していなければ再生成する**
- 対比が視認できなければ、本話の主題（成長の実感）が伝わらない

### 過去映像（C05）の作り方

- 現在のミオ（V1）の上に、半年前のミオ（V2）を **30% 透過**で重ねる
- 過去映像は**グレースケール + 薄い紫フィルター**（RGB 210,190,220）
- 過去映像だけ **フレームレートを 12fps に間引く**（記憶の質感を出す）

## 2. グレーディング

| LUT | 適用カット | 内容 |
|---|---|---|
| **EP13-A 黄金夕光** | C07, C08, C09 | 成長と希望。R+8% / G+4% |

| 夜（C03, C10） | — | EP13-A に青月光を混ぜる |

### 核ショット（C05）の特別処理

- 明度 **+5%**
- 0:08.5–0:10.5 グレー → 0:10.5–0:12.5 ウォームゴールド → 0:12.5–0:14.5 定常
- **6秒間、光が上がり続ける**。途中で止めない
- ミオの表情が「驚き → 納得」に変わるタイミング（約 0:11.5）で、光量の上昇が最も速くなるようカーブを調整する

### 対比の維持（EP13 固有）

C01 で**ノアだけをわずかに明るく**する（差は 5% 以内）。ミオの主観を表す演出だが、やり過ぎるとノアが「特別扱いされた子」に見える。5% を超えない。

## 4. 音

| 時間 | 内容 |
|---|---|
| 0:00–0:03 | 拍手・練習音。BGM は少し切ないピアノ |
| 0:03–0:05 | **音を落とす**（やる気を失う静けさ） |
| 0:05–0:08.5 | 夜の静けさ。BGM が温かいピアノへ |
| 0:08.5–0:14.5 | **核ショット**。BGM が朝日のように上向く。**過去映像の部分だけ音をこもらせる**（記憶の質感） |
| 0:14.5–0:19.5 | 練習音が戻る。BGM 温かく前向き |
| 0:19.5–0:21.5 | ノアの声。BGM は変わらず |
| 0:21.5–0:24 | 夜の静けさ。BGM が余韻へ |
| 0:24–0:30 | ピアノの最後の1音の残響のみ |

**設計意図**: 0:00 の拍手はノアに向いている。ミオには向いていない。**拍手の定位を画面右（ノア側）に寄せる**ことで、ミオの疎外感を音で表す。
