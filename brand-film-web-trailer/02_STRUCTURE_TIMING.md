## 緩急の原則

```
静 → 加速 → 衝突 → 超スロー → 再加速 → 決め → 笑顔
```

01–02で静けさを作るほど、06–07の衝撃が効く。**08で一度落とすのが「決め」の条件**。ここを削ると、ただうるさい映像になる。
