# JMJ やさしい格闘技教材アニメ（試作）

結論: Blender の Python だけで、マネキン・舞台・光・文字・動きを一から作る。外部のモデルや素材は使わない。

- 状態: **試作（下書き）**。動きは一般的な形で、コーチの確認はまだ。
- 公開・投稿はオーナー承認後。投稿前に `flatup-content-qc` を通す。

## 入っているもの

| ファイル | 中身 |
|---|---|
| `jmj_lesson01.py` | レッスン1「構え → ジャブ」を組み立てるスクリプト |
| `preview_lesson01_jab.mp4` | 確認用の動画（5秒・縦長・540×960） |

## 動かし方

```bash
# 1コマだけ書き出す（44 = ジャブをのばした所）
blender -b --python jmj_lesson01.py -- --still out.png --frame 44

# 全150コマを連番画像で書き出す → ffmpeg で動画にする
blender -b --python jmj_lesson01.py -- --anim frames --scale 100 --samples 48
ffmpeg -framerate 30 -i frames/f_%04d.png -c:v libx264 -pix_fmt yuv420p out.mp4
```

- `--scale 50` で半分の大きさ（確認用）、`--scale 100` で 1080×1920（本番）。
- Blender の画面の中で実行すると、今のシーンの `JMJ_Lesson01` コレクションに組み立てる。

## 直し方

| 直したい所 | スクリプトの場所 |
|---|---|
| 差し色 | `ACCENT` |
| 構え・ジャブの形 | `STANCE` / `JAB`（手足の位置を世界座標で書く） |
| 速さ・回数 | `TIMELINE`（フレーム, ポーズ）。30fps |
| 文字 | `build()` の `add_text(...)` |
| 光・カメラ | `build_stage()` |

骨組みは、手と足を「目印（`ik_hand` / `ik_foot`）」で動かす作り。ひじ・ひざの向きは `pole_elbow` / `pole_knee` で決める。

## 画風のルール

- 色はグレー＋差し色1色。主役の光は上からのスポットライト1つ。
- 顔のない丸いマネキン。こわくない、やさしい見た目にする。
- 「ゆっくり → ふつうの速さ」の順に見せる。

## 組み立てる順番
