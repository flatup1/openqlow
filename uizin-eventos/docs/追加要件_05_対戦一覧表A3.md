# 追加要件 05：A3 対戦一覧表（掲示用）の出力

## 結論（3行）
- 主催者が決めた対戦カードを、見やすい一覧表にして、A3の紙（3〜4枚くらい）に印刷します。PDFにもできます。**自動の組み合わせは、ここには入れません。**
- 新しい画面 `/private/sheet/?event=…`（「対戦一覧表（A3）」）を作りました。準備の画面の「A3の対戦一覧表をつくる」から開きます。
- 一覧表は、**保存した大会から作る「読むだけ」の画面**です。直すところ（相手・順番・欠場）は、これまでどおり準備の画面で直して「保存する」を押します。

## 目的と、いまの困りごと
- いまは、対戦カードが準備の画面と当日の画面にしかなく、会場の壁に貼れる形がありません。
- 会長さんが決めた「だれとだれが戦うか」「試合の順番」を、選手・保護者・スタッフが、ひと目で見られるようにします。
- 組み合わせ・順番・載せる項目は、**会長さんが最終決定**します。こちらは、入力・編集・印刷のしやすさを整えます（オーナー確定 2026-10-21）。

## いまの状態（コードの事実）
- 保存データ：`core/privateTournament.ts` の `LocalTournament`（選手 `fighters`、試合 `bouts`＝赤の管理番号・青の管理番号・体重の区分・ルール）。写真は選手ごとの `photoDataUrl`。
- 準備の画面（`app/private/page.tsx`）に、試合の追加・消す・「↑ 上へ」「↓ 下へ」・おすすめ・保存がある。当日の画面（`app/private/live/`）に印刷用の規則（`.live-list-noprint`）がある。
- 保存データ（`LocalFighter`）に入っているのは、氏名・所属ジム・学年・年齢・身長・体重・戦績・意気込み・入場曲・写真・クラス／区分／階級・欠場だけ。電話・メール・住所・郵便番号・保護者名・連絡先・生年月日・同意者名・申込日時・受付番号の列は、名簿を取り込むときに外す（`PRIVATE_HEADERS`）。健康のことは、いまの申込には無い（追加要件06で別のフォームにする）。

## 要件（番号つき）
### 必ず
1. 一覧表は、試合順（準備画面・当日画面と同じ番号）に並べる。
2. 1試合に、次を載せる：試合番号／クラス・区分・階級・体重の区分など、試合を見分ける文字／両選手の氏名／所属ジム／小さな顔写真。
3. 左に赤、右に青。色だけでなく「▲ 赤」「■ 青」の言葉でも分ける（白黒印刷でも読める）。
4. 写真がない選手は、文字だけで出せる。写真の場所は、空の枠で残し、名前の位置をそろえる。
5. 各ページに、大会名・試合番号の範囲（例：第1〜8試合）・ページ番号（例：1 / 3 ページ）を出す。
6. 1試合の情報は、ページをまたがない。
7. 1ページの試合数を選べる。ページ数が分かる（例：全12試合 → A3 3枚）。「A3を3枚にする」「A3を4枚にする」「自動（4枚くらい）」がある。
8. 印刷の前に、画面のプレビューで確かめられる（印刷と同じ形・同じ改ページ）。
9. 印刷はブラウザの印刷の画面（送り先を「PDFに保存」にするとPDF）。用紙は A3 の縦／横を、画面から指定する。
10. 対戦相手の変更・欠場・試合順の入れかえを、一覧表に反映して、もう一度出せる。氏名・所属・写真は、登録済みの情報を使い、もう一度入力しない。
11. 電話番号・生年月日・健康のこと・誓約書の同意記録・メールは、一覧表に**絶対に出さない**（データにあっても通さない）。年齢・身長・体重・戦績・意気込み・学年は、**はじめは出さない**（安全のための初期値。会長が「載せる」と決めたら、載せる項目として足せる。→ オーナーに決めてもらうこと 6）。
### できれば
12. 載せるもの（写真・所属ジム・クラス/区分/階級・ルール）を、会長さんが選べる。氏名はいつも載る。
13. 印刷の前に、確かめごと（未定の試合・欠場・名前なし・同じ人・2試合に入る人・写真なしの人数）を、言葉で出す（止めない）。

## 画面・シートのイメージ
- 上：大会名、最後に読み込んだ時刻（秒まで）、「最新の内容を読み込む」（押すと、緑の「読み込みました」か、赤の「読み込めませんでした」が出る）、「この画面を閉じる（準備の画面にもどる）」（準備の画面から開いたタブは閉じる。閉じられないときは準備の画面へ移る。高さ48px）。
- 設定：紙の向き（縦／横）、1ページの試合数（− ＋ 数字、3枚・4枚・自動。押した設定は、「押した状態」が分かる）、載せるもの（4つのチェック。「名前・所属ジム・顔写真は、会場に貼る紙に載ります。載せてよいかは、会長が決めます」の注意つき）。数の欄は、打っている途中（「1」→「12」）で数にもどさない。上限・下限では「＋」「－」が灰色になり、理由が出る。「A3を3枚／4枚にする」は、いまの試合数と上限でその枚数にできないとき、灰色になって理由と、「横にすると○枚になる」が出る。
- 印刷の前の確かめごと（薄い黄の ⚠）。緑の「✓ どの試合も、赤と青が決まっています。そのまま印刷できます。」は、印刷できる状態（写真の準備が終わった後）のときだけ。写真の準備中は、緑は出さず、灰色の文で待つ。
- 黄色の「👉 次はここ：印刷の画面を開く」と、「印刷する（PDFにもできます）」。写真をととのえている間は、灰色で「🔒 …あと○人」。
- プレビュー：紙1枚ずつ（実物の約○%）。紙は縦 297×420mm／横 420×297mm。縦は1列、横は2列（左の列を上から下へ、つづけて右の列）。
- 1試合：左（赤）＝写真・「▲ 赤」・氏名・所属ジム・クラス/区分/階級、まん中＝「第 N 試合」と試合を見分ける文字（ルールは選んだときだけ）、右（青）＝反対向き。文字は、枠の高さに入る大きさと行数に自動で合わせる（氏名はまず1行に入れる。入らなければ小さく→2行）。まん中の列は、せまいとき「第N試合」を1行にして、それでも入らない「ルール」「契約体重など」は、切って見せず、省く（省いた試合は、印刷の前の黄色い文で知らせる）。
- 欠場の選手：氏名に取り消し線、「▲ 赤 欠場」のように、赤／青の行に「欠場」の札。写真と、選手のクラス／区分／階級は出さない。選手が決まっていない側は「未定」。

## 保存するもの・見せないもの（個人情報の扱い）
- 一覧表は**何も保存しない**（保存データを読むだけ）。設定（向き・載せるもの・1ページの試合数）は、このブラウザの `localStorage`（キー `tos-sheet:<大会番号>`）だけに覚える。
- 一覧表のデータは、`core/boutSheet.ts` が、載せてよい項目（氏名・所属ジム・写真・クラス/区分/階級の札・試合番号・体重の区分・ルール）だけを1つずつ取り出して作る（白リスト）。ほかの項目は触らない。テストで、データに電話・メール・生年月日・健康・同意などを入れても出ないことを確かめている。
- 写真は、印刷用に小さく（長辺360px）作った複製を使う（PDFが重くならない）。もとの写真は変えない。外へは何も送らない（ブラウザの中だけ）。
- 欠場は、選手に付ける `absent: true` だけ（名簿の取り込みで消さない）。保存の検査は、真偽値だけを通す。

## 受け入れ条件（テストできる文）
- 12試合・1ページ4試合 → 3ページ。各ページに大会名・範囲・「N / 3 ページ」がある（`scripts/test-bout-sheet.mjs` A）。
- 1280・390・320px で横にはみ出さない。画面の文字は17px以上、ボタンは48px以上（A）。
- 30試合を縦8／横12で本物のPDFにすると、A3（841.9×1190.6pt／逆）で、予定のページ数ちょうど（余分な白いページなし）。どの試合も自分のページの中に収まる（C）。
- 電話・メール・生年月日・健康・同意・年齢・身長・体重・戦績・意気込みが、画面にもHTMLにも出ない（D）。
- 写真なしでも文字だけで出る。名前の位置がそろう（E）。
- 欠場は取り消し線＋「欠場」、未定は「未定」。確かめごとに出る。黄色の「次はここ」は1つ（F）。
- 別の画面で保存した新しい順番・相手・欠場が、読み直さなくても入れかわる。「最新の内容を読み込む」でも入れかわる（G）。
- 大きな写真は小さい複製になり、もとの保存は変わらない。印刷は1回だけ呼ばれ、ファイル名の元になるタイトルが付く（H）。写真をととのえている間は、印刷ボタンが灰色（理由つき）で、黄色の「次はここ」も緑の✓も出ず、押しても印刷されない（H2）。
- 対戦カードなし／この大会がない：黄色の「次はここ：準備の画面へもどる」が1つ出る。大会がないときは、設定を覚えない（I）。長い名前・長いジム名・3けたの試合番号・1ページ14試合でも、枠から文字がはみ出ない（J と `tests/boutSheet.test.ts` の寸法の計算）。
- 横24試合の詰まった一覧表（クラス・英字の名前・長いルール・欠場）でも、枠をこえず、ふつうの名前・ジム・クラスは切れない。入らない文字は省いて、言葉で知らせる（N）。
- 設定（向き・載せるもの・数／3枚／4枚／自動）は、大会ごとにこのブラウザに覚え、読み直しても同じ。数を打つとき「1」→「12」ができる。上限・下限と、押せない3枚／4枚には理由が出る（B・M）。
- 「この画面を閉じる」は、準備の画面から開いたタブを閉じる。直接開いたときは、準備の画面へ移る（K・O）。
- 準備の画面の「欠場にする」→ 保存 → 一覧表に「欠場」。「欠場をやめる」でキーごと消える。選手を直しても欠場は残る。当日の画面（1試合ずつ・一覧）にも「欠場です」の赤い行（K・L）。

## 作ったあと、会長に確かめること（推測で決めていません）
- 試合の組み合わせは、あとで変わることがあります。貼り出した紙の下に、「組み合わせは変わることがあります」と入れるか（入れる場合の文面は、会長が決める）。
- 学年・体重（kg）を、一覧表に載せるか。はじめは載せていません（要件11）。
- 氏名の書き方（姓名の間の空白、ふりがな、ニックネーム）。いまは、申込の氏名をそのまま載せています。
- 何枚に収めたいか（3枚か4枚か、紙の数の目標）。いまは、「自動」＝4枚くらい、「3枚／4枚」ボタンで選べます。
- 選手の名前・所属ジム・顔写真を、会場の壁に貼り出してよいか（公開の範囲）。保護者の同意の取り方も含めて、会長が決める事項です。

## オーナーに決めてもらうこと
1. **紙の向きのおすすめ**：いまは縦（1列）がおすすめ、横は2列。掲示のしかた（A3を横に何枚並べるか）で変えます。→ おすすめ：縦。壁の寸法を教えてください。
2. **ヘッダーに日付・会場を入れるか**：いまは大会名・範囲・ページ番号だけ。→ おすすめ：入れない（会長が決める項目を増やさない）。
3. **ルールを載せるか**：いまは、はじめは載せない（長いため）。チェックで載せられる。→ おすすめ：そのまま。
4. **「競技」の見分け**：いまは「クラス・区分・階級・体重の区分」で見分ける。「キックボクシング」などの競技名の項目は、データにない。→ 要るなら、名前の付け方を決めてください。
5. **欠場の見せ方**：いまは「欠場」の札と取り消し線。相手の側に「相手未定」と出すか。→ おすすめ：出さない（会長が組み直す）。

## まだ確かめていないこと（できた、とは言えない所）
- 本物のパソコンでの印刷：いまのテストは、このコンテナのブラウザ（Chromium）だけです。Windows の Edge／Chrome、Mac の Safari で、A3の用紙・縦横・PDFが、プレビューどおりになるかは、まだ確かめていません。
- 本物のA3プリンター・コンビニの印刷：紙の端、色の出方、写真の見え方は、実物でしか分かりません（試し刷りを、1枚ほしい）。
- 本物の選手の写真・名前の長さ：テストは、作りものの名前と写真です。
- 会長（浦田さん）が、迷わず使えるか：15分の試しは、まだ。
- 「A3を3枚／4枚にする」「自動」は、試合数によっては、その枚数にならない（画面に理由が出ます）。

## 作る順番と大きさ（小・中・大）、ほかの要件との関係
- 大きさ：中（画面1つ＋決まり＋欠場）。できあがり。
- 追加要件 01〜04 とは別。04（花道プロフィール）が決まったら、花道の一覧表（別の紙）を作るかを、そのとき決める。02・03（誓約書・同意記録）は、一覧表には出さない。
