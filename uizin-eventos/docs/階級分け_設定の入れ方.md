# 階級分け・ロゴの「設定」の入れ方（1ページ）

## 結論
新しい大会のシートで、「設定」タブの **「階級分け」を「あり」にする** だけです。
区分（中学生男子など）と階級（-37kgなど）の表は、**はじめから入っています**（千葉県キックボクシング協会 Vol.7（2026年12月20日大会）の要項と同じです）。直したいときだけ書き換えます。
ロゴを出したいときは、**「ロゴ」を「あり」** にします。

選手は、申し込みのときに、先に **出場区分** を選び、つづけて **階級** を選びます（小学生以下は階級がありません）。階級は「-37kg（37kg以下）」のように、記号と言葉の両方で出ます。
（選手の画面では「出場区分」と出ます。会長さんの画面（準備・当日・対戦一覧表・「選手の受付をつくる」）と、Googleの列見出しでは、同じものが「区分」と出ます。owner の修正願 2026-10-22。選手に見える所だけ、言葉をそろえました。）

## 手順
1. 新しいひな形をコピーしたシートを開く。（古いコピーには、階級分けの行がありません。そのときは、新しいひな形をもう一度コピーします）
2. 左下の「設定」タブを押す。
3. 表の下のほうで、A列に「階級分け」と書いてある行を探す。その行の **B列のマス（B21）** を押し、▼から **「あり」** を選ぶ。
4. 下の表と同じか、見るだけで確かめる。区分を使わないときは、その行ごと消します（右クリック →「行を削除」）。
5. ロゴを出すときは、A列に「ロゴ」と書いてある行（B22）の ▼から **「あり」** を選ぶ。
6. シートのメニュー「Tournament OS」→「① 最初の設定」を押す。（古いコードのときは、新しいコードに入れかえたあと、もう一度押します）
7. アプリの画面「選手の受付をつくる」の、手順2（URLをはって、つなぐ）で「もう一度確かめる」を押す。「シートから読み取れた内容」の「階級分け」に「✓ あり（7区分）。申し込みページに出ます」と出れば完成です。

## 書き方
- **A列の「階級：」のあと** が、選手に見える区分の名前です。1つの区分が1行です。
- **B列** には、その区分で選べる階級を、「、」か「,」で区切って書きます。
  - `-37` ＝ 37kg以下（選ぶ画面では「-37kg（37kg以下）」と出ます）
  - `+60` ＝ 60kgをこえる（「+60kg（60kgをこえる）」）
  - `無差別` ＝ 体重の決まりなし
  - 「全角の数字」「kg」を付けても読めます（例：－37kg）。
- **「なし」** と書くと、その区分では階級を選ばせません（小学生以下は、体重が近い人どうしで組みます）。
- 区分を **増やす** ときは、いちばん下の行に「階級：○○」と書いて、B列に階級を書きます（12区分まで）。
- 区分を **減らす** ときは、その行を削除します。①を押しても、消した行はもどりません。（区分の行は、消すと下の行の番号が上がります。区分の行は、番号ではなく、A列の名前で探してください。）
- 文字数の上限：区分の名前20文字、階級1つ16文字、1つの区分に階級20こ。「=」「+」「-」「@」で区分の名前を始めないでください。
- 数字だけ（「37」）は、以下なのか、こえるなのかが分からないので、止まります。「-37」か「+37」と書きます。
- 「階級分け」を「なし」にすると、区分の行は何を書いても無視されます。

## 気をつけること
- 申込が始まったあとで、区分や階級の名前を変えないでください。名簿に古い名前と新しい名前が混ざります。
- 体重が階級をこえていても、止めたり、警告を出したりしません（計量は、会場で人が見ます）。
- 試合の準備画面で、赤と青の区分や階級がちがうときだけ、赤い注意（⚠）が出ます。止めません。決めるのは、主催者です。
- 直すところは、ここに赤い文で出ます：「シートの「設定」タブを直してください。」。どの行がどう悪いかも、文に出ます。直したら「もう一度確かめる」を押します。
- ロゴは、千葉県キックボクシング協会（CKA）のものです。ほかの団体が使う大会では「なし」のままにしてください（はじめから「なし」です）。

## 花道の追加情報（使うときだけ）
- 花道の区分（名前に「花道」が入っている区分。はじめから入っているのは、「階級：花道・女子（40歳以上）」と「階級：花道・男子（40歳以上）」）を選んだ選手にだけ、アナウンスで使う追加の質問（12項目）を出すときの設定です。
- 使うときは、「設定」タブの、いちばん下の行（A列が **「花道の追加情報」** の行）のB列を、▼から **「あり」** にします。はじめは「なし」です。区分の行を増やしたり消したりすると、この行の番号が動くので、**番号ではなく、A列の名前で探します**。
- 「階級分け」が「あり」で、区分の名前に「花道」が入った行が1つはある、ときだけ使えます。そうでないと、「設定」タブを直してください、と赤い文が出ます（A列が「花道の追加情報」の行のB列を直す、と書いてあります）。
- 「あり」にして「① 最初の設定」を押すと、シートに「花道プロフィール」と「テスト花道プロフィール」のタブができます。答えは、このタブにだけ入ります（申込原本・OS取込用・名簿のZIPには入りません）。「なし」のときは、このタブはできません。
- 「なし」（はじめの値）のときや、古いコピー（この行が無いシート）は、これまでと同じです。選手の画面にも、シートの列にも、何も増えません。
- 申し込みが始まったあとで「あり」にしたときは、選手に渡すURLを作り直して、送り直します（前のURLには、花道の質問が出ません）。
- 項目と、必須／任意の決めかたは、`docs/追加要件_04_花道用プロフィールの別枠.md` を見ます。
- 花道の区分を選んだ人には、クラス（A／B）を選ばせません（クラス分けが「あり」のとき）。かわりに、いちばん下の行（A列が「花道のルール」の行）のB列の1行が、灰色で出ます。古いコピーには、この行が無いので、シートを開き直すか「① 最初の設定」を押すと、足されます。くわしくは `docs/クラス区分_設定の入れ方.md` と、`追加要件_04` の「9.」。

## 誓約書（使うときだけ）
- 申し込みの最後に、誓約書の□（✔を入れる欄）を出すときの設定です。選手が全部の□に✔を入れないと、先へ進めません。署名（手書きの名前）はありません。保護者の同意は✔だけ。ジム責任者の同意は、お名前・携帯電話・「許可をとっている」の✔です（2026-10-22 の owner の決定。`追加要件_02` の末尾の決定ログが1か所の元です）。
- 使うときは、「設定」タブの、A列が **「誓約書」** の行のB列を、▼から **「あり」** にします。はじめは「なし」です。そのすぐ下の3行（「保護者の同意」「ジム責任者の同意」「誓約書の文の確認」）は、はじめから入っています。区分の行を増やしたり消したりすると、行の番号が動くので、**番号ではなく、A列の名前で探します**。
- 順番：①「誓約書」を「あり」→ ②「① 最初の設定」を押す（「誓約書」「誓約記録」「テスト誓約記録」のタブができる）→ ③「誓約書」タブの文を、原本と見比べる → ④「誓約書の文の確認」を「済み」にする → ⑤「選手の受付をつくる」の画面で「もう一度確かめる」を押し、新しいURLを送る。
- **文は、owner が原本から貼った文字です（2026-10-22）。** AIは、誓約・同意の文を書いていません・直していません。「誓約書」タブをはじめて作るときだけ、その文が入ります（すでにタブがあれば、1マスも触りません）。会長さんが原本と見比べて、直します。とくに、3番の項目の「帰属することし」は、貼られた文字のままです。
- 「誓約書の文の確認」が「まだ」のあいだは、本番の申し込みは、申し込みページもGoogleの受付も断ります（テスト用のURLは動きます）。「選手の受付をつくる」の画面には、赤い✕で「本番のURLは選手に送らないでください」と出ます。
- 「誓約書」タブの文を直したら、**必ず新しいURLを作って送り直します**（前のURLでは申し込めません）。
- 「なし」（はじめの値）のときや、古いコピー（この行が無いシート）は、これまでと同じです。選手の画面にも、シートのタブにも、何も増えません。
- 項目の数・長さの上限：項目は8個まで、1項目120文字まで、全部で700文字までです。超えると、「選手の受付をつくる」の画面に赤い文が出ます。
- 選手が✔した記録は、「誓約記録」タブ（テストは「テスト誓約記録」）に残ります。ジム責任者の名前と電話が入るので、人に見せません。申込原本・OS取込用・名簿のZIP・A3・当日の画面には出ません。

## 試合の準備画面と、ほかのジム用の入力画面
- 「選手の受付をつくる」画面から試合の準備画面へ進むと、シートの区分と階級も一緒に渡ります。「1人ずつ入れる」と「直す」で、区分と階級を選べます。
- 「ほかのジム用の入力画面」にも、申し込みページと同じ「出場区分」と階級の選び方が出ます（見出し・ラベル・赤い文・灰色の文も「出場区分」）。作ったZIPには「クラス」「区分」「階級」の列が入ります。列の見出しは、今までどおり「区分」のままです（階級分けを使わない大会は、今までと同じ列のままです）。
- 取り込むファイルの「階級」は、「-37」「37kg以下」「−37ｋｇ」など、書き方がちがっても、シートの形（37kg以下）にそろえます。「区分」「階級」の列が無い古いファイルを取り込んでも、今の区分・階級は消えません。

## ひな形シートを新しくする（オーナー用。大会ごとではなく、プログラムを変えたときだけ）
やり方は「クラス区分_設定の入れ方.md」の「ひな形シートを新しくする」と同じです。`Tournament_OS_Google受付_v3.gs` と `appsscript.json` を新しいものに入れかえ、`const RECEPTION_BUILD = '3.20261024.2';` を確かめます。**ひな形のシートでは、「① 最初の設定」を押しません**（コピーしたシートで押します）。
**古いひな形は、「設定」タブに古いはじめの値（学年・年齢・意気込みが「任意」、古いA/B文）が残ります。** 入れかえたあとで、「クラス区分_設定の入れ方.md」の手順5（「設定」タブを消して作り直す、または B10〜B29 に新しい値を貼る）を必ず行います。そのあと、コピーしたシートの「設定」タブの下に、「階級分け」から「階級：花道・男子」までの9行と、いちばん下の「花道の追加情報」の1行があり、B10〜B12が「必須」になっていることを見ます。

**公開の前の注意：ひな形の入れかえが、もう1回要ります。** 花道の追加の質問（下の「花道の追加情報」）は、build `3.20261022.7` から使えます。いまのひな形が `3.20261019.6` のままだと、配ったコピーに「花道の追加情報」の行が入らず、申し込みページに花道の質問が出ません。くわしい戦績（キック・他の格闘技・タイトル）は、build `3.20261024.1` から使えます。新しい申し込みページ（`/apply/`）を公開する前に、次の順で進めます。
1. ひな形に、新しい `Tournament_OS_Google受付_v3.gs` を貼り、「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」を押す（上と同じ手順）。
2. 上の `RECEPTION_BUILD` が `3.20261024.2` になっていることを見る（くわしい戦績は `3.20261024.1` から、行を足す・見出しの点検は `3.20261024.2` から。花道・誓約書は `3.20261022.7` から使えます）。**ひな形のシートでは、「① 最初の設定」を押さない。**
3. 新しいコピーを、テスト用のアカウントで作り、「設定」タブのいちばん下に「花道の追加情報」（はじめは「なし」）があることを見る。「あり」にして「① 最初の設定」を押すと、「花道プロフィール」と「テスト花道プロフィール」のタブができることも見る。
4. すでに配ったコピー（古いひな形から作ったシート）は、そのまま使えます。花道の質問を使いたい大会だけ、新しいコピーを作るか、そのシートの Apps Script を新しい版に入れかえます（古い版のシートには「花道の追加情報」の行が無く、「選手の受付をつくる」の画面は「なし（追加の質問は出しません）」と読みます。黄色の注意は出ません。選手のURLにも、花道の印は付きません）。
5. 「花道の追加情報」を「あり」にしたあと（または、「あり」にしてから設定を直したあと）は、「選手の受付をつくる」の画面で「もう一度確かめる」を押し、**選手に渡すURLを作り直して、送り直します**（前のURLには、花道の質問が出ません）。
6. 誓約書（上の「誓約書（使うときだけ）」）と「花道のルール」も、同じひな形の入れかえ（build `3.20261022.7`）で使えるようになります。新しいコピーの「設定」タブのいちばん下の近くに、「誓約書」「保護者の同意」「ジム責任者の同意」「誓約書の文の確認」「花道のルール」の5行があることを見ます。「誓約書」を「あり」にして「① 最初の設定」を押すと、「誓約書」「誓約記録」「テスト誓約記録」のタブができることも見ます。配った古いコピーは、そのまま使えます（行が無いシートは、誓約書「なし」と同じに動きます）。
