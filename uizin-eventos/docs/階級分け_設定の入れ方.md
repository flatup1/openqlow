# 階級分け・ロゴの「設定」の入れ方（1ページ）

## 結論
新しい大会のシートで、「設定」タブの **「階級分け」を「あり」にする** だけです。
区分（中学生男子など）と階級（-37kgなど）の表は、**はじめから入っています**（千葉県キックボクシング協会 Vol.6 の要項と同じです）。直したいときだけ書き換えます。
ロゴを出したいときは、**「ロゴ」を「あり」** にします。

選手は、申し込みのときに、先に **区分** を選び、つづけて **階級** を選びます（小学生以下は階級がありません）。階級は「-37kg（37kg以下）」のように、記号と言葉の両方で出ます。

## 手順
1. 新しいひな形をコピーしたシートを開く。（古いコピーには、階級分けの行がありません。そのときは、新しいひな形をもう一度コピーします）
2. 左下の「設定」タブを押す。
3. 表の下のほうで、A列に「階級分け」と書いてある行を探す。その行の **B列のマス（B21）** を押し、▼から **「あり」** を選ぶ。
4. 下の表と同じか、見るだけで確かめる。区分を使わないときは、その行ごと消します（右クリック →「行を削除」）。
5. ロゴを出すときは、A列に「ロゴ」と書いてある行（B22）の ▼から **「あり」** を選ぶ。
6. シートのメニュー「Tournament OS」→「① 最初の設定」を押す。（古いコードのときは、新しいコードに入れかえたあと、もう一度押します）
7. アプリの画面「選手の受付をつくる」の、手順2（URLをはって、つなぐ）で「もう一度確かめる」を押す。「シートから読み取れた内容」の「階級分け」に「✓ あり（7区分）。申し込みページに出ます」と出れば完成です。

## はじめから入っている表（B列に入れる文）
シートに入っている文と、まったく同じ文です。見て、同じなら、直さなくて大丈夫です。

| 項目（A列） | 入れる文（B列） |
|---|---|
| 階級分け | なし（使うときだけ「あり」にします） |
| ロゴ | なし（使うときだけ「あり」にします） |
| 階級：小学生以下 | なし |
| 階級：中学生女子 | -37、-40、-43、-46、-49、-52、-55、-58 |
| 階級：中学生男子 | -37、-40、-43、-46、-49、-52、-55、-58 |
| 階級：高校生・一般女子 | -40、-43、-46、-50、-53、-56、-59、-62、-65 |
| 階級：高校生・一般男子 | -50、-53、-56、-59、-62、-65、-68、-71、-74、-77、-80、-85、無差別 |
| 階級：花道・女子（40歳以上） | -40、-45、-50、-55、-60、+60 |
| 階級：花道・男子（40歳以上） | -55、-60、-65、-70、-75、-80、-85、無差別 |

## 書き方
- **A列の「階級：」のあと** が、選手に見える区分の名前です。1つの区分が1行です。
- **B列** には、その区分で選べる階級を、「、」か「,」で区切って書きます。
  - `-37` ＝ 37kg以下（選ぶ画面では「-37kg（37kg以下）」と出ます）
  - `+60` ＝ 60kgをこえる（「+60kg（60kgをこえる）」）
  - `無差別` ＝ 体重の決まりなし
  - 「全角の数字」「kg」を付けても読めます（例：－37kg）。
- **「なし」** と書くと、その区分では階級を選ばせません（小学生以下は、体重が近い人どうしで組みます）。
- 区分を **増やす** ときは、いちばん下の行に「階級：○○」と書いて、B列に階級を書きます（12区分まで）。
- 区分を **減らす** ときは、その行を削除します。①を押しても、消した行はもどりません。（区分の行は、消すと下の行の番号が上がります。区分の行は、番号ではなく、A列の名前で探してください。）
- 文字数の上限：区分の名前20文字、階級1つ16文字、1つの区分に階級20こ。「=」「+」「-」「@」で区分の名前を始めないでください。
- 数字だけ（「37」）は、以下なのか、こえるなのかが分からないので、止まります。「-37」か「+37」と書きます。
- 「階級分け」を「なし」にすると、区分の行は何を書いても無視されます。

## 気をつけること
- 申込が始まったあとで、区分や階級の名前を変えないでください。名簿に古い名前と新しい名前が混ざります。
- 体重が階級をこえていても、止めたり、警告を出したりしません（計量は、会場で人が見ます）。
- 試合の準備画面で、赤と青の区分や階級がちがうときだけ、赤い注意（⚠）が出ます。止めません。決めるのは、主催者です。
- 直すところは、ここに赤い文で出ます：「シートの「設定」タブを直してください。」。どの行がどう悪いかも、文に出ます。直したら「もう一度確かめる」を押します。
- ロゴは、千葉県キックボクシング協会（CKA）のものです。ほかの団体が使う大会では「なし」のままにしてください（はじめから「なし」です）。

## 試合の準備画面と、ほかのジム用の入力画面
- 「選手の受付をつくる」画面から試合の準備画面へ進むと、シートの区分と階級も一緒に渡ります。「1人ずつ入れる」と「直す」で、区分と階級を選べます。
- 「ほかのジム用の入力画面」にも、同じ区分と階級の選び方が出ます。作ったZIPには「クラス」「区分」「階級」の列が入ります（階級分けを使わない大会は、今までと同じ列のままです）。
- 取り込むファイルの「階級」は、「-37」「37kg以下」「−37ｋｇ」など、書き方がちがっても、シートの形（37kg以下）にそろえます。「区分」「階級」の列が無い古いファイルを取り込んでも、今の区分・階級は消えません。

## ひな形シートを新しくする（オーナー用。大会ごとではなく、プログラムを変えたときだけ）
やり方は「クラス区分_設定の入れ方.md」の「ひな形シートを新しくする」と同じです。`Tournament_OS_Google受付_v3.gs` と `appsscript.json` を新しいものに入れかえ、`const RECEPTION_BUILD = '3.20261019.6';` を確かめます。**ひな形のシートでは、「① 最初の設定」を押しません**（コピーしたシートで押します）。
**古いひな形は、「設定」タブに古いはじめの値（学年・年齢・意気込みが「任意」、古いA/B文）が残ります。** 入れかえたあとで、「クラス区分_設定の入れ方.md」の手順5（「設定」タブを消して作り直す、または B10〜B29 に新しい値を貼る）を必ず行います。そのあと、コピーしたシートの「設定」タブの下に、「階級分け」から「階級：花道・男子」までの9行があり、B10〜B12が「必須」になっていることを見ます。
