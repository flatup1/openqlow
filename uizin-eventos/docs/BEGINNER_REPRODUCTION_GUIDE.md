# 60代・パソコン初心者向け Tournament OS 再現説明書

この説明書は、パソコン操作に慣れていない格闘技ジムの会長でも、Codex または Claude Code に1つのリンクを渡して Tournament OS を再現できるようにしたものです。

難しいプログラム操作はAIに任せます。人が行う作業は、基本的に「リンクをコピーしてAIへ貼る」「ログイン画面で許可する」「最後の画面を確認する」の3つです。

## 最初に知っておくこと

- 元の UIZIN 本番版を直接書き換えません。
- 最初は自分のパソコンの中だけで動かします。
- GitHubへのpushやインターネット公開は、あなたが「公開して」と許可するまで行いません。
- 電話番号、メールアドレス、住所、保護者名が入った申込原本は使いません。
- Tournament OSには、公開してよい進行表だけを接続します。

## 用意するもの

1. インターネットにつながったMacまたはWindowsパソコン
2. GitHubアカウント
3. CodexまたはClaude Code
4. Node.js 22以上
5. 公開する場合だけCloudflareアカウント
6. 個人の連絡先を除いた大会進行表

Node.jsやGitが入っているか分からなくても大丈夫です。AIが確認し、不足していれば説明します。

## いちばん簡単な再現方法

### 1. 次のリンクをコピーする

```text
https://raw.githubusercontent.com/flatup1/openqlow/claude/uizin-eventos-v1-6f2l8p/uizin-eventos/docs/AI_REPRODUCTION_PROMPT.md
```

### 2. CodexまたはClaude Codeへ送る

新しい作業を開き、次の一文を送ってください。

```text
このリンクの説明を読んで、Tournament OSをこのパソコンで再現してください。
https://raw.githubusercontent.com/flatup1/openqlow/claude/uizin-eventos-v1-6f2l8p/uizin-eventos/docs/AI_REPRODUCTION_PROMPT.md
```

### 3. AIの作業が終わるまで待つ

AIは次の順番で作業します。

1. 必要な道具が入っているか確認
2. GitHubから最新版を取得
3. 元のUIZIN版に影響しない作業場所を作成
4. テストと画面の組み立てを実行
5. パソコン内で画面を開く
6. 問題があれば修正して再確認

### 4. ブラウザで確認する

AIから「確認用URL」が表示されたら、そのリンクを押します。通常は次のようなURLです。

```text
http://localhost:3000
```

`localhost` は自分のパソコンだけで見られる確認画面です。他人には公開されていません。

## 別大会を作るとき

AIへ次のように伝えます。

```text
このTournament OSで新しい格闘技大会を作りたいです。
元のUIZIN大会は残し、新しい大会IDで複製してください。
大会名：○○キック大会
開催日：2026年○月○日
会場：○○体育館
まだインターネットには公開しないでください。
```

AIが聞いてきたら、次の情報だけを答えます。

- 大会名
- 開催日
- 会場
- テーマカラー
- 個人の連絡先を除いた進行表

## 進行表に入れてよい情報

- 試合番号
- 赤・青の選手名
- 所属ジム
- 公開用プロフィール
- 意気込み
- 契約体重
- 公開許可のある顔写真URL
- 入場曲URL

## 入れてはいけない情報

- 電話番号
- メールアドレス
- 住所
- 保護者氏名
- 決済情報
- 公開許可のない写真
- 操作キーやパスワード

## インターネットへ公開するとき

ローカル画面を確認して問題がなければ、AIへ次のように伝えます。

```text
ローカル確認が終わりました。
変更内容、テスト結果、公開先、個人情報が含まれていないことを確認して報告してください。
私が最終確認するまで、まだ公開しないでください。
```

AIの報告を読み、公開してよい場合だけ次のように伝えます。

```text
確認しました。この内容をGitHubへpushし、Cloudflareへ公開してください。
既存大会は上書きせず、新しい大会IDと公開先を使ってください。
```

Cloudflareのログイン画面が開いた場合は、本人がログインして「Allow」または「許可」を押します。パスワードや確認コードをAIへ送らないでください。

## 当日の使い方

1. 本番URLをChromeまたはSafariで開く
2. 大会名と現在の試合番号を確認
3. 赤・青の選手名と写真を確認
4. 必要な側の入場曲を開く
5. 曲を停止する
6. 試合終了後に「次の試合」を押す

管理画面の設定変更や再取り込みは、必要なときだけ行います。

## 困ったときにAIへ送る文章

### 画面が開かない

```text
Tournament OSの画面が開きません。
現在の状態を壊さず、原因を調べてください。
削除、push、公開は勝手に行わないでください。
```

### 写真が表示されない

```text
選手写真が表示されません。
画像URL、画像形式、読み込みエラー、代替シルエットを確認し、ほかの選手に影響しない最小修正をしてください。
```

### 入場曲が開かない

```text
入場曲が開きません。
Apple Music、YouTube、未登録、無効URLを区別して確認してください。
別の選手の曲へ勝手に変更しないでください。
```

### 元に戻したい

```text
直前の変更を元に戻したいです。
まず変更内容と戻す対象を確認し、既存データを消さない安全な戻し方を提示してください。
まだ実行しないでください。
```

## 完成の確認

AIから次の結果が報告されたら、再現作業は完了です。

- テストがすべて成功
- ビルドが成功
- ローカル画面が開く
- 前の試合／次の試合が動く
- 写真がない場合もシルエットが出る
- 入場曲リンクが正しい選手の近くに出る
- 通信や画像のエラーで画面全体が真っ白にならない
- 個人の連絡先が公開データに含まれていない
- 既存UIZIN版を変更していない
