# クラス分けの「設定」の入れ方（1ページ）

## 結論
新しい大会のシートで、「設定」タブの **「クラス分け」を「あり」にする** だけです。
クラスの名前・条件・ルールは、**はじめから入っています**。直したいときだけ書き換えます。

## 手順
1. 新しいひな形をコピーしたシートを開く。（古いコピーには、クラスの行がありません）
2. 左下の「設定」タブを押す。
3. 表の下のほうにある「クラス分け」の右どなりの四角を押し、▼から **「あり」** を選ぶ。
4. 下の表と同じか、見るだけで確かめる。
5. シートのメニュー「Tournament OS」→「① 最初の設定」をもう一度押す。
6. この画面（セットアップ）で「もう一度確かめる」を押す。「✓ クラス分け：あり（Aクラス／Bクラス）」と出れば完成。

## この大会で入れる文（はじめから入っている文）
| 項目 | 入れる文 |
|---|---|
| クラス分け | あり |
| 上のクラスの名前 | Aクラス |
| 上のクラスの条件 | 戦績3勝以上（例：3勝0敗、4勝、5勝2敗） |
| 上のクラスのルール | 首相撲あり／膝蹴りあり／蹴り足キャッチ（ワンアタック：キャッチしたあと1回だけ攻撃できる） |
| 下のクラスの名前 | Bクラス |
| 下のクラスの条件 | アマチュア。戦績2勝以下（例：初出場、2勝1敗、1勝3敗） |
| 下のクラスのルール | パンチとキックのみ |
| 上のクラスにする勝ち数 | 3 |

- 勝った数だけで決めます。負け・引き分けは数えません。**3勝ちょうどは Aクラス** です。
- 文字数の上限：名前12文字、条件60文字、ルール80文字。「=」「+」「-」「@」で名前を始めないでください。
- 「勝ち数」を変えたら、**条件の文も同じように直してください**（文は自動では変わりません）。
- 「クラス分け」を「なし」にすると、クラスの行は何を書いても無視されます。

## 気をつけること
- 申込が始まったあとで、クラスの名前を変えないでください。名簿に古い名前と新しい名前が混ざります。
- クラスを決めるのは選手（保護者）です。申込画面は、戦績から「目安」を出すだけで、止めません。
- 直すところは、ここに文で出ます：「シートの「設定」タブを直してください。」
