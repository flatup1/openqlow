# クラス分けの「設定」の入れ方（1ページ）

## 結論
新しい大会のシートで、「設定」タブの **「クラス分け」を「あり」にする** だけです。
クラスの名前・条件・ルールは、**はじめから入っています**。直したいときだけ書き換えます。

## 手順
1. 新しいひな形をコピーしたシートを開く。（古いコピーには、クラスの行がありません。そのときは、新しいひな形をもう一度コピーします。「選手の受付をつくる」の画面にも、黄色の「⚠ 気をつけて」で出ます）
2. 左下の「設定」タブを押す。
3. 表の下のほうで、A13に「クラス分け」と書いてある行を探す。その行の **B13のマス** を押し、▼から **「あり」** を選ぶ。
4. 下の表と同じか、見るだけで確かめる。
5. シートのメニュー「Tournament OS」→「① 最初の設定」をもう一度押す。
6. アプリの画面「選手の受付をつくる」の、手順2（URLをはって、つなぐ）で「もう一度確かめる」を押す。「シートから読み取れた内容」の「クラス分け」に「✓ あり（Aクラス／Bクラス）。申込ページに出ます」と出れば完成。手順3（選手に渡すURLを作る）の画面にも、緑の「✓ クラス分け：あり（Aクラス／Bクラス）。申込ページに出ます。」が出ます。

## この大会で入れる文（はじめから入っている文）
シートに入っている文と、まったく同じ文です。見て、同じなら、直さなくて大丈夫です。
| 項目 | 入れる文 |
|---|---|
| クラス分け | あり |
| 上のクラスの名前 | Aクラス |
| 上のクラスの条件 | 3勝以上（例：3勝0敗、4勝、5勝2敗） |
| 上のクラスのルール | 首相撲あり／膝蹴りあり／蹴り足キャッチ（ワンアタック＝蹴り足をキャッチしたあと、1回だけ攻撃してよい） |
| 下のクラスの名前 | Bクラス |
| 下のクラスの条件 | アマチュア。2勝以下（例：初出場、2勝1敗、1勝3敗） |
| 下のクラスのルール | パンチとキックのみ |
| 上のクラスにする勝ち数 | 3 |

- 勝った数だけで決めます。負け・引き分けは数えません。**3勝ちょうどは Aクラス** です。
- 文字数の上限：名前12文字、条件60文字、ルール80文字。「=」「+」「-」「@」で名前を始めないでください。
- 「勝ち数」を変えたら、**条件の文も同じように直してください**（文は自動では変わりません）。
  - 条件の文に「3勝以上」「2勝以下」のような書き方があるとき、その数が勝ち数とちがうと、メニュー「① 最初の設定」が止まり、どの欄を直すか教えます（上の条件は「勝ち数」と同じ数の「勝以上」、下の条件は「勝ち数 − 1」の「勝以下」）。「経験者」のように数のない文は、調べません。
- 「クラス分け」を「なし」にすると、クラスの行は何を書いても無視されます。

## 気をつけること
- 申込が始まったあとで、クラスの名前を変えないでください。名簿に古い名前と新しい名前が混ざります。
- クラスを決めるのは選手（保護者）です。申込画面は、戦績から「目安」を出すだけで、止めません。
- 直すところは、ここに赤い文で出ます：「シートの「設定」タブを直してください。」。直すセル（B13〜B20）の番号も、文のうしろに出ます。直したら「もう一度確かめる」を押します。
- 「選手の受付をつくる」画面の手順1にも、同じ説明と見本（この大会のAクラス・Bクラス）が出ます。

## 試合の準備画面と、ほかのジム用の入力画面
- 「選手の受付をつくる」画面から試合の準備画面へ進むと、シートのクラス（名前・条件・ルール）も一緒に渡ります。「1人ずつ入れる」と「直す」で、2つのクラスを選べて、条件の文と戦績からの目安が、選ぶ欄のすぐ下に出ます。名前を変えたクラスでも、2つとも選べます。
- 「ほかのジム用の入力画面」にも、同じクラスの選び方が出ます。作ったZIPには「クラス」の列が入ります（クラスを使わない大会は、今までと同じ列のままです）。
- Excelのひな形「選手入力シート」にも、K列に「クラス」の列があります（▼から「Aクラス」「Bクラス」を選べます。クラスを使わない大会は、空のままで大丈夫です）。
- 取り込むファイルの「クラス」は、「Aクラス」「A」「ａクラス」「上」などを、シートの名前にそろえます。「クラス」の列が無い古いファイルを取り込んでも、今のクラスは消えません。空だった人のクラスは、あとのファイルで自動で足されます。

## ひな形シートを新しくする（オーナー用。大会ごとではなく、プログラムを変えたときだけ）
配る「ひな形」（コピー元のシート）が古いと、コピーした人のシートに、クラスの行が入りません。すると、申込ページに、クラスの選び方が出ません。ひな形は、次の順で入れかえます。
1. コピー元のシートを開く。
2. メニュー「拡張機能」→「Apps Script」を押す。
3. 中の文を、全部消す。新しい `Tournament_OS_Google受付_v3.gs` の中身を、そのまま貼る。「保存」を押す。
4. 左の歯車「プロジェクトの設定」を押し、「appsscript.json」を表示する欄にチェックを入れる。`appsscript.json` に、新しい `appsscript.json` の中身を貼る。（中には、必要な権限が書いてあります：シート・ドライブ・メニューの表示・メールアドレス・Apps Scriptのウェブアプリの住所。これで、許可の画面は、はじめの1回にまとまります。実際のGoogleでの確認は、まだです。権限を足したあとの最初の1回だけ、もう一度許可の画面が出ます）
5. シートを開き直す。「設定」タブに、足りない行（クラスの8行など）が、いちばん下に自動で足されます。いま書いてあるマスは、書き換わりません。そのあと、メニュー「Tournament OS」→「① 最初の設定」を押す。最初は、許可の画面が出ることがあります。そのときは、許可をして、もう一度「① 最初の設定」を押す。
6. Apps Script の画面の、上から2行目を見る。`const RECEPTION_BUILD = '3.20261010.5';` と書いてあれば、新しいプログラムです。（build は、プログラムの版の番号です。デプロイ用のコマンドも、同じ番号を画面に出します）
7. このシートの「コピーを作る」のリンクを、テスト用のアカウントで開く。コピーした「設定」タブの下に、「クラス分け」から「上のクラスにする勝ち数」までの8行があることを見る。
8. リンクの形は `https://docs.google.com/spreadsheets/d/（長い文字）/copy` です。これを、控えのファイル `~/template-link.backup.json` の `"copyUrl"` に入れる。
9. 公開のコマンド `npm run deploy:private` は、公開する `.gs` の build を画面に出します。ひな形の build（手順6）と同じか、見くらべてから「yes」と打つ。ちがうときは、手順1からやり直す。

（Googleの画面は、ときどき名前が変わります。ちがう名前のときは、近い名前のメニューを探してください。この手順は、本物のGoogleでの確認は、まだ終わっていません。）
