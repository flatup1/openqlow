# Tournament OS 会長本人テスト：手順と採点票

作成：2026-10-08／対象：D4「会長本人が説明なしで15分以内に、作成・再開・引継ぎを完了」（25点）

> **このテストをやるまで、D4は0点です。** 自動テストや、開発者本人の操作では、代わりになりません。

## 1. 決まっていること（オーナー回答）

| 項目 | 決定 |
|---|---|
| 15分の範囲 | **作成 → 再開 → 引継ぎ**（大会情報と名簿を入れ、対戦カードを保存し、閉じて開き直し、引継ぎファイルを作って別のパソコンで戻す） |
| テストする人 | **実際の会長さん本人** |
| 2台目のパソコン | **使える**（引継ぎファイルの復元を、本物で確かめる） |
| 公開 | 全部の検証が通ったら、`tournament-os-v3` へ公開してよい（pushは別に確認） |

## 2. 立ち会う人のルール（とても大事）

1. **しゃべらない。ヒントを出さない。** 聞かれても「画面を見てやってみてください」とだけ言う。
2. **ストップウォッチを使う。** 「始めてください」で開始。会長さんが「できた」と言ったら止める。
3. 手が止まった時間、押し間違い、読んで悩んだ場所を、**その場でメモ**する（下の記録表）。
4. 画面は**録画してよいか、会長さんに先に聞く**。（顔や個人情報は映さない。入れるのは架空のデータだけ）
5. **本物の選手の名前・電話番号・写真は使わない。** 架空名簿を使う。

## 3. 事前に立ち会う人が準備すること

- 会長さんの普段使いのパソコンと、ふだん使うブラウザ（Windows／Mac／Edge／Chrome／Safari のどれか、記録する）
- 架空名簿（6人）のCSV：デスクトップの `架空名簿6人.csv`
- 公開先のURL：`https://tournament-os-v3.pages.dev/private/?event=chairman-test-1`（**テストごとに、新しい event 名にする**）
- 2台目のパソコン（引継ぎの復元用）。同じURLを開けること。
- ストップウォッチ、記録表（下）

## 4. 会長さんに渡す指示（この紙だけ。これ以上は説明しない）

> 「この大会の準備を、あなたがやってください。やることは3つです。
> 1. 大会の名前と日にちを入れ、名簿のファイルを入れて、対戦カードを2試合作って、保存する。
> 2. 画面をいったん閉じて、もう一度開いて、続きから再開する。
> 3. 別のパソコンに引っ越せるように、予備のファイルを作り、そのファイルを2台目のパソコンで戻す。
> 分からないときは、画面を見て、自分で考えてやってください。」

## 7. 点数のつけ方（固定。テストの前に決めておく）

D4は25点。**6つの確認が、ヒントなしで完了した分だけ**取れる。

| 確認 | 配点 |
|---|---|
| 1〜2（作成：入力と名簿） | 7点 |
| 3（対戦カードの保存） | 5点 |
| 4（再開） | 6点 |
| 5〜6（引継ぎ：作成と、2台目で復元） | 7点 |

- **15分以内**で全部終われば、取れた点の **100%**。15〜20分は **60%**。20分を超えたら **30%**。
- ヒントを1回出すごとに、**マイナス2点**（下限0）。
- 途中でやめた場合は、完了した確認の点だけ（時間の割引は、その時点の経過時間で決める）。
- **会長さん1人の結果は、D4の暫定点**とする。複数人でテストした場合は、平均を使う。

## 8. テストのあとにやること

1. 記録表をもとに、止まった場所を、画面の直す候補としてまとめる。（読まないと進めなかった文は、見て分かる表示に置きかえる）
2. 直したら、自動テストと実画面の確認をやり直す。
3. 点数を更新する。**未実施の項目を、合格扱いにしない。**

## 9. このテストで確認できないこと（正直に）

- 本物のGoogle連携（ひな形のコピー、許可、公開、スマホ申込）は、このテストの範囲外（別の手順書）。
- 2台目のパソコンでの「同期」は、v3の機能ではない（名簿は、その時に使うパソコンの中にだけある）。「引継ぎファイルで戻す」だけが、この版の引っ越し方法。
- メールコード認証・下書き／公開中の区別は、v3には無い。
