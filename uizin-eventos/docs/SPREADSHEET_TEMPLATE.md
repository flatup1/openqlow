# 番組表スプレッドシートの作り方

v1 では **Google スプレッドシートが唯一のCMS** です。ここを直せば全画面が変わります。

## 準備

1. 新しいスプレッドシートを作る
2. シートを3枚作り、名前を **`event` / `matches` / `music`** にする（この名前でないと読み込めません）
3. 右上「共有」→ **「リンクを知っている全員」＋「閲覧者」** にする
   - 「制限付き」のままだと Worker から読めません
   - 編集権限は絶対に付けないでください
4. URL の `/d/` と `/edit` の間が **シートID**。これを Worker の `SHEET_ID` に入れる

> シートIDや操作キーはリポジトリにコミットしないでください。

---

## `event` シート（大会の設定）

| key | value |
|---|---|
| `title` | UIZIN 第1回 |
| `venue` | 成田市中台体育館 |
| `date` | 2026-11-03 |
| `start_at` | 13:00 |
| `hold_message` | しばらくお待ちください |

`key` / `value` の2列だけです。日本語見出し（`項目` / `値`）でも読めます。

---

## `matches` シート（対戦カード）

1行 = 1試合。**1行目は見出し**にしてください。

| 列 | 例 | 説明 |
|---|---|---|
| `no` | 1 | 試合番号。この順に進みます |
| `class` | ライト級 | クラス・階級 |
| `rule` | アマチュアMMA | ルール |
| `rounds` | 2 | ラウンド数 |
| `round_seconds` | 3:00 | 1ラウンドの長さ。`180` や `3分` でも可 |
| `break_seconds` | 60 | インターバルの長さ |
| `red_name` | 山田 太郎 | 赤コーナー 選手名 |
| `red_team` | FLAT UP GYM | 赤 所属 |
| `red_record` | 2戦2勝 | 赤 戦績など |
| `red_comment` | 必ず勝ちます | **赤 意気込み**（MC・表示画面に出ます） |
| `blue_name` 〜 `blue_comment` | | 青コーナーも同じ4列 |
| `note` | メインイベント | オペレーターへのメモ。表示画面には出ません |

日本語見出しでも読めます: `番号` / `クラス` / `ルール` / `ラウンド数` / `ラウンド秒` / `インターバル秒` /
`赤_名前` / `赤_所属` / `赤_戦績` / `赤_意気込み` / `青_名前` … / `備考`

**赤と青の選手名が両方空の行は捨てられます**（空行を気にせず作って大丈夫です）。

---

## `music` シート（Event Mix の曲順）

上から順に流す曲を並べます。**1行 = 1曲**。

| 列 | 例 | 説明 |
|---|---|---|
| `no` | 1 | 曲順 |
| `match_no` | 1 | ひもづく試合番号（無くてよい） |
| `kind` | walkout_red | 用途。下の表を参照 |
| `title` | 入場曲A | 曲名 |
| `artist` | — | アーティスト |
| `apple_music_url` | https://music.apple.com/jp/album/… | **第一優先** |
| `youtube_url` | https://www.youtube.com/watch?v=… | **第二優先**（Apple が無いときだけ使われます） |
| `seconds` | 60 | 尺。`1:00` や `1分` でも可。Event Mix の「あと何秒」に使います |
| `note` | | 備考 |

`kind` に使える値: `opening` / `walkout_red` / `walkout_blue` / `interval` / `result` / `ending` / `other`
日本語（`オープニング` / `赤入場` / `青入場` / `幕間` / `結果` / `エンディング`）でも読めます。

### 色の決まりかた

| 色 | 条件 | 大会を開始してよいか |
|---|---|---|
| 緑 | `apple_music_url` が正しく入っている | ○ |
| 黄 | Apple が無く YouTube だけ／`seconds` が未設定 | ○（進めてよい） |
| 赤 | URLが1つも無い／URLの形が違う／リンク切れを検出 | **×（直すまで開始しない）** |

---

## 取り込みかた

ダッシュボードの **「取り込み直す」** を押すだけです。

- 進行中に押しても、**現在の試合・走っているタイマーは触りません**（試合番号で追いかけます）
- 取り込みに失敗しても、**今動いている番組表はそのまま**残ります（大会は止まりません）
- Google に届かない日は、操作者だけが `/api/program/upload` に3枚のCSVを直接貼れます（保険）
