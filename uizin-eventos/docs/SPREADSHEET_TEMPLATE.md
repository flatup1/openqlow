# 番組表スプレッドシートの作り方

v1 では **Google スプレッドシートが唯一のCMS** です。ここを直せば全画面が変わります。

---

## ⚠️ 最初に必ず読むこと：申込スプレッドシートを EventOS に繋いではいけない

`UIZIN 2026 大会エントリー` のような**申込の原本**には、
連絡先メールアドレス・電話番号・保護者氏名が入っています。

EventOS は Worker がシートを読むために **「リンクを知っている全員／閲覧者」** を必要とします。
つまり、**申込の原本をそのまま繋ぐと、個人情報が誰でも読める状態になります。**

そのため、必ず**別のスプレッドシート**を用意してください。

| ファイル | 中身 | 共有設定 |
|---|---|---|
| `UIZIN 2026 大会エントリー`（原本） | 申込・連絡先・保護者情報 | **制限付きのまま。絶対に公開しない** |
| `UIZIN 2026 進行表（EventOS用）`（新規） | `event` / `matches` / `music` の3タブだけ | リンクを知っている全員／閲覧者 |

進行表に入れてよいのは、**当日、会場のモニターとMCが読み上げる情報だけ**です。

- 入れる: 選手名（リングネーム）／所属ジム／戦績・競技歴／意気込み／入場曲URL
- 入れない: メールアドレス／電話番号／保護者氏名／受付番号／顔写真URL／申込日時

> 取り込み時、EventOS は上の「入れる」列しか読みません（他の列は捨てます）。
> それでも原本を公開してはいけません。**シートの公開そのものが漏えい**だからです。

---

## 準備

1. 新しいスプレッドシートを作る（名前の例: `UIZIN 2026 進行表（EventOS用）`）
2. シートを3枚作り、名前を **`event` / `matches` / `music`** にする（この名前でないと読み込めません）
3. 右上「共有」→ **「リンクを知っている全員」＋「閲覧者」** にする
   - 「制限付き」のままだと Worker から読めません
   - 編集権限は絶対に付けないでください
4. URL の `/d/` と `/edit` の間が **シートID**。これを Worker の `SHEET_ID` に入れる

> シートIDや操作キーはリポジトリにコミットしないでください。

## `event` シート（大会の設定）

| key | value |
|---|---|
| `title` | UIZIN 第1回 |
| `venue` | 成田市中台体育館 |
| `date` | 2026-11-03 |
| `start_at` | 13:00 |
| `hold_message` | しばらくお待ちください |

`key` / `value` の2列だけです。日本語見出し（`項目` / `値`）でも読めます。

---

## `matches` シート（対戦カード）

1行 = 1試合。**1行目は見出し**にしてください。

| 列 | 例 | 説明 |
|---|---|---|
| `no` | 1 | 試合番号。この順に進みます |
| `class` | ライト級 | クラス・階級 |
| `rule` | アマチュアMMA | ルール |
| `rounds` | 2 | ラウンド数 |
| `round_seconds` | 3:00 | 1ラウンドの長さ。`180` や `3分` でも可 |
| `break_seconds` | 60 | インターバルの長さ |
| `red_name` | 山田 太郎 | 赤コーナー 選手名 |
| `red_team` | FLAT UP GYM | 赤 所属 |
| `red_record` | 2戦2勝 | 赤 戦績など |
| `red_comment` | 必ず勝ちます | **赤 意気込み**（MC・表示画面に出ます） |
| `blue_name` 〜 `blue_comment` | | 青コーナーも同じ4列 |
| `note` | メインイベント | オペレーターへのメモ。表示画面には出ません |

日本語見出しでも読めます: `番号` / `クラス` / `ルール` / `ラウンド数` / `ラウンド秒` / `インターバル秒` /
`赤_名前` / `赤_所属` / `赤_戦績` / `赤_意気込み` / `青_名前` … / `備考`

**赤と青の選手名が両方空の行は捨てられます**（空行を気にせず作って大丈夫です）。

---

## `music` シート（Event Mix の曲順）

上から順に流す曲を並べます。**1行 = 1曲**。

| 列 | 例 | 説明 |
|---|---|---|
| `no` | 1 | 曲順 |
| `match_no` | 1 | ひもづく試合番号（無くてよい） |
| `kind` | walkout_red | 用途。下の表を参照 |
| `title` | 入場曲A | 曲名 |
| `artist` | — | アーティスト |
| `apple_music_url` | https://music.apple.com/jp/album/… | **第一優先** |
| `youtube_url` | https://www.youtube.com/watch?v=… | **第二優先**（Apple が無いときだけ使われます） |
| `入場曲` | （上の2列の代わりに1列でも可） | 申込フォームの「入場曲URL」をそのまま貼れます。Apple / YouTube は**自動で振り分け**ます |
| `seconds` | 60 | 尺。`1:00` や `1分` でも可。Event Mix の「あと何秒」に使います |
| `note` | | 備考 |

`kind` に使える値: `opening` / `walkout_red` / `walkout_blue` / `interval` / `result` / `ending` / `other`
日本語（`オープニング` / `赤入場` / `青入場` / `幕間` / `結果` / `エンディング`）でも読めます。

### 入場曲の列は1つでよい

申込フォームは「入場曲URL（Apple Music推奨）」という**1つの欄**しか持っていません。
55人ぶんを Apple 列と YouTube 列に手で分けるのは、準備が止まる原因になります。

そこで、**`入場曲` という1列にそのまま貼れば、EventOS が自動で振り分けます。**

- `music.apple.com` のURL → Apple Music として緑
- `youtube.com` / `youtu.be` のURL → YouTube として黄
- それ以外（Amazon Music・LINE・Google の検索結果など）→ **赤**（サービス名を出して指摘します）
- 曲名とURLが同じセルに混ざっていても（例: `ターミネーター２ https://…`）URLだけ拾います

### 入場曲がない選手の書き方

**空欄と「なし」はまったく別の意味**として扱います。ここを間違えると赤がゼロになりません。

| 書き方 | 意味 | 色 |
|---|---|---|
| 空欄 | **まだ本人に確認できていない** | 赤（当日までに確認する） |
| `なし` / `無し` / `会場BGM` / `-` | 確認済みで、入場曲を使わない | 灰（対象外。開始を止めない） |

### 色の決まりかた

| 色 | 条件 | 大会を開始してよいか |
|---|---|---|
| 緑 | Apple Music のURL + 尺（秒数）あり | ○ |
| 黄 | YouTube のみ／`seconds` が未設定 | ○（進めてよい） |
| 灰 | 「なし」と明記（入場曲を使わない） | ○ |
| 赤 | URLが空欄／別サービスのURL／形が違う／リンク切れを検出 | **×（直すまで開始しない）** |

音源チェック画面は**直すべき順（赤 → 黄 → 灰 → 緑）**に並びます。上から潰してください。

## 取り込みかた

ダッシュボードの **「取り込み直す」** を押すだけです。

- 進行中に押しても、**現在の試合・走っているタイマーは触りません**（試合番号で追いかけます）
- 取り込みに失敗しても、**今動いている番組表はそのまま**残ります（大会は止まりません）
- Google に届かない日は、操作者だけが `/api/program/upload` に3枚のCSVを直接貼れます（保険）
