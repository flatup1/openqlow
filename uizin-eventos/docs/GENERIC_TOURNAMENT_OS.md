# 汎用格闘技大会 Tournament OS 構想

## 目的

現在の UIZIN EventOS を壊さず、別の格闘技大会でも大会データを差し替えるだけで再利用できるようにする。

最優先は次の3点とする。

1. 初めて触るスタッフでも迷わない
2. 大会中に誤操作・通信断・画像エラーが起きても止まりにくい
3. 選手の個人情報を公開画面やソースコードへ含めない

## 推奨する完成形

1つの Tournament OS で複数の大会を管理し、大会ごとに固有URLを持たせる。

```text
Tournament OS
├── UIZIN 2026
│   └── /events/uizin-2026/live
├── FLAT UP CUP
│   └── /events/flatup-cup/live
└── その他の格闘技大会
    └── /events/example/live
```

新しい大会は、過去大会を複製し、大会名・対戦カード・写真・意気込み・契約体重・入場曲を差し替えて作成する。

## 対象範囲

v1 は格闘技大会向けに限定する。スポーツ大会全般や音楽イベントへの対応は、格闘技大会向けの安定運用を確認した後に検討する。

## 大会ごとに変更できる項目

- 大会名
- 大会ID（URL用の短い英数字）
- ロゴ
- 開催日
- 会場
- 開始時刻
- テーマカラー
- 赤・青コーナーの表示名と色
- 停止中の案内文
- 対戦カード
- 選手プロフィール
- 顔写真
- 意気込み
- 契約体重
- 入場曲

## 共通データモデル

### 大会

- `eventId`
- `title`
- `logoUrl`
- `date`
- `venue`
- `startAt`
- `theme`
- `status`（準備中・公開中・終了）

### 選手

- `fighterId`
- `displayName`
- `team`
- `profile`
- `comment`
- `photoUrl`
- `walkoutMusic`

公開用データには、電話番号・メールアドレス・住所・保護者氏名などを含めない。

### 試合

- `matchId`
- `eventId`
- `order`
- `section`
- `className`
- `contractWeight`
- `rule`
- `redFighterId`
- `blueFighterId`
- `note`（運営だけに表示）

### 入場曲

- `provider`（Apple Music・YouTube・なし）
- `title`
- `artist`
- `url`
- `status`（使用可能・未確認・使用不可・なし）

## 画面の分離

### 本番運営画面

大会中に常時表示する。表示する操作は最小限にする。

- 赤・青の写真、名前、所属、プロフィール、意気込み
- 契約体重
- 入場曲名
- 入場曲を開く／停止する
- 前の試合
- 次の試合
- 現在の試合番号

### 管理画面

本番画面から分離し、権限を持つ運営者だけが使用する。

- 大会の作成・複製
- 大会設定の変更
- Google スプレッドシート取り込み
- 選手・試合・曲・写真の編集
- 公開前チェック
- 公開・終了状態の切り替え

### 閲覧画面

スタッフや会場モニターが閲覧するだけの画面。編集機能を置かない。

## データ更新方法

Google スプレッドシートと管理画面の両方に対応する。

- 大量登録・試合順変更：Google スプレッドシート
- 当日の小さな修正：管理画面
- どちらから変更しても、保存前に差分を確認する
- 取り込み失敗時は、直前の正常データを保持する

## 安全性

- 大会ごとにデータを完全分離する
- 公開画面は読み取り専用にする
- 重要な変更には確認画面を付ける
- 画像エラーはシルエット表示へ切り替える
- 画像は事前に同じ比率へ最適化する
- 最後に正常表示できた大会データを端末へ保存する
- 通信断でも現在の対戦カードを表示し続ける
- 再接続後にサーバーの最新状態へ安全に同期する
- すべての変更に時刻と変更者を記録する

## 段階的な移行

### Phase 1: 現行UIZIN版の保存

- 現在の本番版を変更せず固定する
- テスト・データ仕様・公開URLを記録する

### Phase 2: 大会固有情報の分離

- `UIZIN` の固定文字列や色を大会設定へ移す
- 選手・試合・音楽・写真を共通データ型へ統一する
- URLに `eventId` を持たせる

### Phase 3: 複数大会対応

- 大会一覧を追加する
- 大会の新規作成と複製を追加する
- 大会ごとの状態・番組表・画像を分離する

### Phase 4: 管理画面

- スプレッドシート取り込み
- 直接編集
- 差分確認
- 公開前診断

### Phase 5: 本番検証

- 別名のテスト大会を作成する
- PC・Mac・iPad・スマートフォンで確認する
- 通信断・再読込・画像エラー・曲なしを確認する
- 現行UIZIN版へ影響がないことを確認する

## 受け入れ条件

次の条件をすべて満たした時点を、汎用版v1の完成とする。

1. UIZIN以外の大会を管理画面から作成できる
2. 大会名・ロゴ・配色・会場・日付をコード変更なしで設定できる
3. 選手・試合・写真・意気込み・契約体重・入場曲を差し替えられる
4. 大会ごとに固有URLで開ける
5. 別大会のデータが混ざらない
6. 本番画面に管理操作が常時表示されない
7. 前後の試合移動と入場曲操作が迷わず使える
8. 画像がなくても画面全体が止まらない
9. 通信断・再読込後も直前の表示を復元できる
10. 公開データとソースコードに連絡先などの個人情報が含まれない
11. 既存UIZIN本番版の表示と動作を壊さない
12. 自動テスト・ビルド・別大会を使った通し操作がすべて成功する

## 今回追加しないもの

- 採点システム
- 受付・決済
- OBS・配信連携
- 電子ゴング
- AI実況
- Apple Musicの自動操作

まずは「別の格闘技大会でも、安全に同じ運営体験を再利用できること」に集中する。

## 実装状況

汎用版v1では、次を実装済みとする。

- 大会IDをURLの `?event=` で指定
- 大会IDごとにDurable Object、オフライン保存、音声設定を分離
- `/admin/` からGoogleスプレッドシートを指定して取り込み
- `/entry/` の大会名・日時・会場・料金・締切を管理画面から大会ごとに設定
- 受付番号を自動発行し、選手情報・意気込み・入場曲・顔写真・同意を収集
- 申込原本と、連絡先を除いたTournament OS用CSVを分離して出力
- Google Sheets障害時の `event` / `matches` / `music` CSV手貼り取り込み
- 既存UIZIN端末の接続設定とオフライン保存を引き継ぐ互換処理
- 既存UIZINとは別の `tournament-os` Cloudflare Pages／Workerへ公開できるスクリプト

本番公開は、別大会のテストデータによるブラウザ確認とユーザー承認後に行う。

## エントリーサイトの使い方

1. `/admin/?event=大会ID` を開く
2. 「エントリーサイトを作る」に大会情報を入力する
3. 内容確認後だけ「エントリー受付を公開する」をONにして保存する
4. `/entry/?event=大会ID` のリンクを参加者へ案内する
5. 申込後は「OS用CSV（連絡先なし）」を大会運営へ使う
6. 「申込原本CSV（個人情報あり）」は大会責任者だけが安全に保管する
