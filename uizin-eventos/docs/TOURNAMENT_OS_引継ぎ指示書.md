## 8. 経験から分かった落とし穴

1. **ワークフロー（Workflowツール）の再開は、過去の呼び出しの順番と中身が同じときだけ、結果を再利用する。** 台本の「前のほう」を直すと、それ以降が全部やり直しになる（実際に数日ぶんを失った）。直すなら、まだ実行していない後ろだけ。
2. 同時に動ける作業役は2人まで。長い作業役は再起動で消える。**動いている作業を止めない。** 止まったと判断するのは、作業役のファイルが30分以上更新されず、負荷もゼロのときだけ。
3. このコンテナでは、作業役が `git add/commit` を安全装置に止められる。**commit と push は、メインのセッションが直接やる。**
4. サンドボックスの時計は飛ぶことがある。一度の見た目で「止まった」と決めない。
5. 「使える量の上限」に当たると、作業役がまとめて即失敗し、ワークフローが「完了」と出て終わる。**失敗が並んでいたら、上限が解けてから再開する。**
6. 以前の実機の失敗：別のMac（matsumotohitoshi）にはフォルダとCloudflareログインが無かった。公開は `jin@jinnoMacBook-Pro` で。Safariの「ダウンロード後、安全なファイルを開く」はオフにするか、ZIPを開かない。
