## 2. 番組表の入れ方（2通り。どちらでもよい）

**A. スプレッドシートが使えるとき**
`/op/` →「番組表」→「取り込み直す」

**B. Google にログインできないとき（当日の本命）**
`/op/` →「CSVを貼って取り込む」→「貼り付けて取り込む」

1. `matches` の欄に、対戦カードのCSVをそのまま貼る（必須）
2. `music` の欄に、曲のCSVを貼る（無くてもよい）
3. 画面に出る **「取り込むと: 試合◯件／曲◯件」** を見て、数が合っているか確かめる
4. 「この内容で取り込む」を押す

> 数が合わないときは押さない。貼り忘れた行がある。
> 取り込みに失敗しても、**いまの番組表はそのまま残る**。大会は止まらない。

## 3. 本番で使う操作は4つだけ（`/live/`）

| 操作 | どうなる |
|---|---|
| 選手の下の ▶ | その人の入場曲が鳴る（もう一度押すと止まる） |
| いちばん下の大きい緑のボタン | 次の試合へ進む |
| その左の「← 第◯試合」 | 1つ前に戻る（進めすぎたとき） |
| 何もしない | 大会は止まらない |

**迷ったら触らない。** それで事故は起きない。

---

## 4. 困ったときの3手（この順に試す）

### ① 画面の上に黄色い帯が出た → 通信が切れている

- **「次の試合へ」は押してよい。** 押すと「預かっています」に変わり、
  **通信が戻った瞬間に自動で1回だけ送られる。**
- まだ試合は進んでいない。90秒で自動的に取り消される。
- やめたいときは「予約を取り消す」を押す。
- 手が空いていれば、**スマホのテザリングに切り替える**（いちばん早い）。

### ② 画面が固まった／真っ白になった

- ブラウザを**再読み込み**（F5、Macは Command+R）。
- 進行状況はサーバーに残っているので、**今の試合から続けられる**。

### ③ 試合を進めすぎた／間違えた

- `/live/` の「← 第◯試合」で1つ戻す。
- それでも直らないときは `/op/` の「元に戻す」。
