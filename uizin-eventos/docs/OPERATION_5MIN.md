# 5分で分かる UIZIN EventOS

初見のスタッフに、この1枚を読ませて終わりにできることを目標にしています。

---

## 0. 覚えることは3つだけ

1. **操作できるのはオペレーター1人だけ。** MC画面・表示画面・Event Mix画面にはボタンが1つもありません。
2. **押すのは基本「次へ」だけ。** 入場 → 1R → インターバル → 2R → 結果 → 次の試合、と自動でつながります。
3. **何かあったら「停止」。** 全画面が「しばらくお待ちください」になります。直ったら「再開」。

---

## 1. 前日にやること（5分）

1. Google スプレッドシートに、対戦カードと曲を入れる（→ [SPREADSHEET_TEMPLATE.md](SPREADSHEET_TEMPLATE.md)）
2. ダッシュボードで **「取り込み直す」** を1回押す
3. **音源チェック画面** を開いて、**赤がゼロ**になるまで直す

> **赤がゼロになるまで大会を開始しません。** これは決まりごとです。
> 緑 = Apple Music で再生できる（第一優先）
> 黄 = YouTube だけ（第二優先）または尺（秒数）が未設定 — 進めてよい
> 赤 = URLが無い／形が違う／リンク切れ — **必ず直す**

---

## 2. 当日、開始前（1分）

1. ダッシュボード（`/op/`）を自分の端末で開く
2. MC の端末で `/mc/` を開く
3. 大型モニターの端末で `/screen/` を開く
4. 音響の端末で `/mix/` を開く
5. 4画面すべての右上が **緑の「同期中」** になっていることを確認する

> 「同期中」が黄（低速同期）や赤（未接続）のときは、Wi-Fi を確認してください。
> 赤でも**画面は消えません**。最後に受け取った内容を出したまま待ちます。

---

## 3. 進行中（これだけ）

| したいこと | 押すもの |
|---|---|
| 次に進む | **次へ**（スペースキーでも押せます） |
| 止める | **停止**（Escキーでも押せます） |
| 再開する | **再開**（Escキーでも押せます） |
| 押し間違えた | **元に戻す**（戻せるのは直前の一手だけ） |
| 試合を選び直す | 下の番号ボタン（確認が出ます） |
| 曲を進める | Event Mix の「次の曲」 |
| 曲を再生した | 「再生した（カウント開始）」を押す（**音はシステムが鳴らしません。人が外部サービスで再生します**） |

「次へ」ボタンには、**押すと次に何が起きるか**が小さく書いてあります。読んでから押してください。

---

## 4. 困ったときは

| 症状 | すること |
|---|---|
| 画面が固まって見える | 何もしなくてよい。復帰すると勝手に追いつきます |
| 端末を落とした／ブラウザを閉じた | 開き直すだけ。試合・タイマー・停止状態はすべて元に戻ります |
| 選手が来ない／救護が入った | **停止**を押す。全画面が待機表示になります |
| 「次へ」を押しすぎた | **元に戻す**。1手だけ戻ります |
| Google スプレッドシートが開けない | 番組表は取り込み済みなので、**そのまま進めて大丈夫**です |
| 接続先を変えたい | URLの末尾に `?api=https://…` を付けて開く |

---

## 5. やらないこと

- **大会当日に新機能を追加しない。** これは禁止です。
- MC画面・表示画面の端末に**操作キーを入れない**。閲覧専用のまま使います。
- 「元に戻す」を連打しない。戻るのは1手だけです。
