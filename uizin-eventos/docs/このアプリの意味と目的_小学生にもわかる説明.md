# Tournament OS（対戦カードアプリ）の「意味」と「目的」
## 小学生にもわかる説明（はじめて読む人向け）

作成：2026-10-06／この文書は、技術に詳しくない人（ほかのジムの会長、保護者、スタッフ、手伝ってくれるAI）が、「何のために、何を作ったのか」をつかむためのものです。

---

## 1. ひとことで言うと

> **格闘技の大会を開く「ジムの会長さん」が、パソコンが苦手でも、一人で、15分ぐらいで、「選手の申込ページ」を作れるようにする道具です。**
> そのあと、集まった選手を「赤コーナー」と「青コーナー」に組んで、当日は「前の試合」「次の試合」のボタンだけで進められます。

---

## 2. どうして、これを作ったの？（目的）

格闘技の大会を開くとき、会長さんは、たくさんのことをします。

1. 選手を集める（名前、体重、写真、入場曲…）
2. 「この子とこの子を戦わせよう」と、対戦を組む（赤と青を決める）
3. 当日、試合を順番に進める（入場曲を流す、紹介する）

これまでは、紙や、バラバラの表で、とても大変でした。しかも、会長さんの多くは、パソコンが得意ではありません（60代の人もいます）。

だから、**「むずかしい設定を、ほとんどしなくていい道具」** を作りたい、と考えました。

---

## 3. この道具のしくみ（3つの場所）

町の「申込所」にたとえます。

| 場所 | たとえ | 本当は何？ | 何を持つ？ |
|---|---|---|---|
| ① **選手のスマホの画面** | 申込用紙 | Cloudflare（クラウドフレア）という場所に置いた、**空っぽのページ** | 何も持たない。ただ、用紙の形を見せるだけ |
| ② **会長さんのGoogleのシート** | かぎ付きの金庫 | 会長さん本人のGoogleのスプレッドシートとDrive | 選手の申込（連絡先も）、写真 |
| ③ **対戦カードのアプリ** | 会長さんの机 | 会長さんのパソコンの中 | 名前、写真、体重、対戦カード。**連絡先は持たない** |

**だいじなところ：** 選手が書いた内容は、**会長さんの金庫（②）に、まっすぐ入ります。** 空っぽのページ（①）は、中身を見ません。だから、**電話番号やメールは、会長さん以外の手に渡りません。**

---

## 4. 会長さんの作業を短くするために、工夫したこと

### 前は、こうでした（約25回の操作）

長い「お手伝いロボットの文字」をコピーして、Googleの画面に貼って、保存して…。画面を行ったり来たりして、間違えやすい作業でした。（実際にテストしたとき、アカウント違い、貼り間違い、古い画面のコピーなどで、何度も止まりました）

### いまは、こうです

**「お手本ノート」を、先に1冊だけ作っておきます。** 会長さんは、それを**コピーするだけ**です。お手伝いロボットも、いっしょについてきます。

| 前 | いま |
|---|---|
| ロボットの文字を、自分で貼る | **お手本をコピーするだけ**（ロボットもついてくる） |
| 大会の情報を、2か所に入れる | **シートの「設定」タブの1か所だけ** |
| 大会の番号を、自分で考える | **自動** |
| 長い確認コードを、コピーして貼る | **なし**（アプリが自動で確かめる） |
| メールアドレスを入れる | **入れない**（実行した本人が、自動で分かる） |
| テストの申込を、手で送る | **自動で、架空の1件を試す** |
| 「自分／全員」の選び方で迷う | **最初から選ばれている** |
| 画面が5段階 | **3段階** |
| 入場曲の「あり／なし」を忘れる | **必ず選ばないと、先へ進めない** |

### 会長さんの流れ（6つ）

1. 「ひな形のコピーを作る」を押す。
2. シートの「設定」タブに、大会名・日にち・会場・主催者名・問い合わせ先・申込の締切を書く。**入場曲は、「あり」か「なし」を▼から選ぶ。**
3. メニュー「Tournament OS」→「① 最初の設定」を押す。（許可を聞かれたら、許可する）
4. 公開して、できたURLをアプリに貼る。
5. メニュー「② 受付を開始」を押す。
6. 「選手へ渡すURLをコピー」を押して、LINEなどで選手に送る。

---

## 5. 「入場曲のあり／なし」を、必ず選ぶのは、なぜ？

試合では、入場曲を流す大会と、流さない大会があります。

- **「あり」** のとき、選手の申込ページに「入場曲」の欄が出ます。選手は、曲を入れます。
- **「なし」** のとき、その欄は出ません。

これを、**最初に、会長さんが、はっきり決める** ことにしました。理由は、あとから「入場曲の欄が、あるはずなのに、ない」「ないはずなのに、ある」と、**選手が混乱しないため** です。決めないと先に進めないので、うっかり忘れません。

---

## 6. 当日は、どうなるの？

対戦カードの画面は、**大きな画面でも、スマホでも、見やすい形** にします。

- 左が **赤コーナー**、右が **青コーナー**。
- それぞれに、**写真、名前、ジム、戦績、意気込み、入場曲のボタン**。
- 下に、**「前の試合」「次の試合」** の大きなボタンと、**試合の番号**。

会長さん（や係の人）は、**「次の試合」を押して、「入場曲」を押す** だけです。

---

## 7. 安全のための約束

- **連絡先（電話・メール）は、会長さん本人のGoogleの中だけ。** 対戦カードのアプリには、渡しません。
- **お手本ノートは「見るだけ」で公開します。** ほかの人が書き換えることはできません。中には、プログラムと、空の「設定」の見出しだけ。**個人情報は、入っていません。**
- **写真は、会長さんのDriveの「会長さんだけ」の箱** に入ります。
- 「かぎ」や「パスワード」を、会長さんに入力させません。
- テストは、**架空の人** だけで行います。

---

## 8. 今、どこまでできている？（正直に）

**できたこと（本物のGoogleで確かめた）**
- 申込を送ると、シートに1行入り、写真もDriveに入る。
- 電話番号の先頭の「0」が消える不具合を見つけて、直した。
- **お手本ノートをコピーすると、ロボットもついてくる。** メニューと「設定」タブも出る。（別のアカウントで確認）

**できたこと（コンピュータの中のテストで確かめた）**
- 設定の間違いを、「どこを直すか」つきで教える。
- 入場曲の「あり／なし」を、必ず選ばせる。
- 連絡先が、アプリや、渡すファイルに出ないこと。
- 自動テスト285本と、画面の動きの確認が、すべて合格。

**まだ、確かめていないこと**
1. 「① 最初の設定」を、本物のGoogleで押して、自動テストが通るか。
2. 公開して、アプリがつながるか。
3. 選手のスマホ・LINEの中で、申込ができるか。
4. **会長さんご本人が、説明なしで、15分以内に作れるか。**（これが一番大事です）
5. 申込ページを、インターネットに公開すること。（公開は、オーナーの許可がいります）

## 9. 言葉の説明

| 言葉 | 小学生向けの説明 |
|---|---|
| **スプレッドシート** | Googleの、ネットの表（エクセルのようなもの） |
| **GAS（ガス）／Apps Script** | 表の中に入れる「お手伝いロボット」。申込を受け取って、表に書いてくれる |
| **Cloudflare（クラウドフレア）** | 空っぽのページを、世界中に配ってくれる場所 |
| **ひな形** | コピーして使う「お手本」 |
| **デプロイ** | ロボットの入口を、ネットに開くこと |
| **ZIP** | 名簿と写真を、まとめて入れる「お弁当箱」 |
| **ping（ピング）** | 「元気？」と聞いて、返事を見ること（アプリが自動でやる） |
| **PR（プルリクエスト）** | 「この変更を、取り入れてもいい？」という、確認の依頼 |

## 10. よくある質問

**Q. 選手の電話番号は、だれが見られるの？**
A. 会長さん本人だけです。対戦カードのアプリにも、渡しません。

**Q. 間違えて、設定を変えてしまったら？**
A. 画面に「どこを直すか」が出ます。それでも困ったら、お手本ノートを、もう一度コピーすれば、新しく作り直せます。（古いノートは、消さなくて大丈夫です）

**Q. 別の大会でも、使える？**
A. 使えます。大会ごとに、お手本をコピーして、新しい設定を書きます。

**Q. パソコンが苦手でも、本当にできる？**
A. それを、これから、**実際の会長さんで確かめます。** 確かめるまでは、「できる」と言い切りません。
