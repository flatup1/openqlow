# 小学生でも進められる Tournament OS の作り方

> 現在使うのは「主催者Google受付＋パソコン内保存版」です。この説明だけを使ってください。旧版の `/admin/` とは接続しません。

## 現在の版：会長のGoogleへ保存し、大会画面は自分のパソコンで使う

### 最初に知っておくこと

- Cloudflareに置くのは、入力欄と大会画面のプログラムだけです。選手情報を保存するサーバーは置きません。
- ネット申し込みは、大会を開く会長本人のGoogleへ直接送ります。別の会長の受付URLをコピーして使いません。
- 申込表・写真フォルダは「制限付き・主催者本人だけ」です。共有を広げると、この受付は止まります。
- 大会当日は、名簿と写真を自分のパソコンに入れます。別のパソコンには自動で移りません。
- この仕組みでも、Googleやパソコンの盗難・不正ログインなどを含む危険を0%にはできません。会長のGoogleで2段階認証を使い、共用パソコンを避けてください。

### 1. 会長が最初の設定をする

1. `/private/` の大会準備画面を開きます。
2. 大会名・開催日・会場を入力します。入場曲の有無もここで決めます。
3. 「はじめてのGoogle受付設定を開く」を押します。
4. 黄色の場所だけ、1から5まで進めます。

画面に貼るプログラムは自動で会長・大会専用になります。Googleでは、主催者本人のアカウントを選びます。
「関数なし ▼」は、Google画面の上にある選択ボタンです。プログラムの文字をコピーする場所ではありません。

### 2. 先に架空の申し込みを1件だけ試す

1. Googleのデプロイ画面で「ウェブアプリ URL」の「コピー」を押し、設定画面の「Googleの受付URL」へ貼ります。「デプロイID」ではありません。URLの最後は `/exec` です。
2. 「Googleの接続を確かめる」を押します。同じタブでGoogle画面が開きます。白い欄の文字をすべてコピーし、ブラウザ左上の「←」で戻ります。「Googleの接続確認コード」へ貼って「この大会の保存先を確認する」を押します。途中の設定は残ります。会長ごとにコードを書き直す必要はありません。
3. 「テスト申込画面を開く」を押し、架空の名前・連絡先・確認用の画像を入力します。「入力内容を確認する →」では、まだ送信しません。内容を見て「この内容で送信する」を押します。実在する選手の情報を使いません。
4. 「申し込みが完了しました」と受付番号が出たことを確認します。
5. Googleで `openEntries` を選び「実行」▶を押します。
6. 設定画面の「Googleの接続を確かめる」をもう一度押し、新しい確認コードを貼り直します。公開された受付プログラムの状態を確認します。
7. 主催者名・問い合わせ先・開催日・会場を確認し、「完成：選手へ渡すURLをコピー」を押します。

Googleがテスト原本・OS用名簿・写真の一致を調べます。確認できるまでは選手用URLをコピーできません。テスト情報は本番名簿と分けて保存します。
本番受付を開始せずに大会画面まで試す場合は、Googleの `exportTestTournament` を実行します。最後の確認済みテスト申込1件と写真だけのZIPを保存します。本番とは別のテスト大会へ取り込みます。
確認コードは自分の設定画面にだけ貼ります。他の人やSNSに送るのは、最後にできた**選手用URLだけ**です。
確認コードは15分以内のものを使います。別の大会・別の会長・古い公開プログラム・違う確認回のコードでは、選手用URLを作れません。画面の「できた」を押すだけでは、接続成功と判断しません。

### 他の会長へ渡してよいか、最後に確かめる

1. 松元さんとは別の主催者Googleアカウントで、初めから設定を試します。
2. その会長のGoogleで、架空の申込1件と写真が保存され、受付番号が出るか確認します。
3. その名簿・写真をOSへ取り込み、試合の前・次、赤青の交換、並べ替え、保存・復元を試します。
4. 実際のiPhone・Android・LINEから、同じ選手用URLを開いて送信まで試します。
5. PCに慣れていない会長が、横から説明しなくても設定できるか試します。

自動テストや仮のGoogle応答が成功しただけでは、上の検査に合格したことにはなりません。Googleのログイン・権限の承認・公開設定は本人が確認する必要があり、完全な「1クリック」や外部障害を含むエラーゼロは約束できません。

### 3. 申し込みが届いたら、自分のパソコンへ入れる

1. Google画面で `exportTournament` を選び「実行」▶を押します。
2. 実行ログの「OSへ取り込むファイル」のリンクを開きます。
3. Googleドライブの「ダウンロード」でZIPを保存します。
4. `/private/` の「返ってきた提出ファイルを選ぶ」で、そのZIPを選びます。
5. 名前・写真・身長・体重・戦績を確認します。電話とメールはZIPに入りません。
   追加の申し込みを取り込んでも、元の選手・写真・対戦カード・試合順は削除しません。同じ管理番号は更新、新しい番号は追加します。ファイルにない選手も残るため、欠場は主催者が対戦カードで確認します。
6. 「＋ 試合を追加」で赤・青を選びます。順番は「↑ 上へ」「↓ 下へ」、赤青の交換は「赤青を入替」です。
7. 「このパソコンの中だけに保存」を押してから、大会画面を開きます。

写真付きZIPは合計80MB以下が目安です。大量の写真ではGoogleの容量・実行時間制限があり、無料で無制限には使えません。
ブラウザのデータを消すと、パソコン内の名簿も消えます。名簿や対戦カードを直したら「暗号化して保存」で予備ファイルを取り、USBなどにも保管してください。パスワードは別に控えます。予備ファイルには名簿・写真・試合順・募集項目が入ります。Google受付の接続設定は入りません。
ボタンを押した後は、パソコンの「ダウンロード」に `.tournament.enc` で終わるファイルがあるか確認します。画面の表示だけで保存できたと判断しません。

### 2つの画面を開いているときの保存

大会画面で試合を進めた後、古い準備画面から保存すると、上書き防止の案内が出ます。進めた試合は戻りません。入力した内容をメモしてから準備画面を読み直し、最新の内容へ入力して保存します。2つの準備画面で別々に編集する使い方は避けてください。

### 次の日・次の大会も使いたいとき

- 同じ大会の受付は、通常は毎回つなぎ直しません。配った選手用URLは、15分で無効になるわけではありません。
- 「確認コードの15分」は、設定時の安全確認の時間です。過ぎたら「Googleの接続を確かめる」を押して新しく確認します。申込表は作り直しません。
- 申込締切を過ぎたら、新しい申し込みは止まります。受付を閉じても、届いた名簿・写真は消しません。
- 次の大会は別の管理番号にします。新しい大会の名前・日付・締切・専用Google受付を用意します。前の大会のデータを上書きしません。
- ブラウザのデータ消去や別PCへの移行では、Google受付設定の復元・再確認が必要です。Googleに保存した申込表や写真は、それだけで消えません。接続を作り直す前に、会長のGoogleに残っているプログラムと保存先をAIに確認してもらいます。
- Googleの仕様・利用制限・Driveの空き容量・PC故障の影響を受けるため、「永久」「絶対にエラーなし」は約束できません。募集前に架空の1件を試し、大会前に予備ファイルを実際に復元して確認します。

### Googleの画面で迷ったとき

- 貼り付けはMacなら `⌘ V`、Windowsなら `Ctrl V` です。
- 「関数なし ▼」でなく英語の名前が表示されていることもあります。その右の `▼` を押し、指定された名前を選びます。
- 「実行完了」は最初の準備の完了です。申込の保存テストまで完了した意味ではありません。
- Googleの許可画面は本人が読みます。未確認アプリの警告は、知らないプログラムなら進みません。自分が作ったものか確認できないときは、その画面をAIへ見せます。
- LINEの中で送信画面が開かないときは、同じURLをSafari・Chromeで開きます。すでに送信した場合は、再入力の前に会長へ受付状況を確認します。

### 止まったら

- 受付番号が出ていなければ、まだ完了と判断しません。
- 「同じ申込を確認・再開する」を押します。同じ整理番号を使い、途中の保存を再開します。
- 送信後に名前や写真を変えて再送すると、訂正の案内で止まります。元の申込を勝手に上書きしません。主催者に訂正を依頼します。
- ページを閉じて最初から入力すると整理番号が変わるため、二重申し込みになる可能性があります。解決しない場合は主催者に確認します。
- Googleプログラムを貼り替えたら、保存だけでは更新されません。「デプロイを管理」→鉛筆→「新バージョン」→「デプロイ」で更新し、新しいテスト申込を行います。
- 古い設定の選手用リンクは新しい受付方式には使えません。切り替え前に、新しく作ったURLで通しテストを行います。

