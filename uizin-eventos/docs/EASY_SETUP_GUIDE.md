# 小学生でも進められる Tournament OS の作り方

## この仕組みで使うもの

1. **募集ページ**: 選手・保護者が申し込む場所
2. **Googleスプレッドシート原本**: 申し込みを1行ずつ保存する場所
3. **Tournament OS**: 大会当日に対戦カード・写真・意気込み・入場曲を見る場所

受付番号が3つをつなぐ共通の整理番号です。

## 最初の1回だけ行うこと

### 1. 非公開の原本を作る

Googleドライブで新しいGoogleスプレッドシートを作ります。名前は「大会名 エントリー原本」にします。
この原本には電話番号やメールが入るため、**リンクを知っている全員へ公開しません**。

### 2. AIへこの文章を送る

```text
Tournament OSのエントリー原本をGoogleスプレッドシートへ自動保存したいです。
docs/templates/entry-sheet-apps-script.gs を使い、私が押す場所を1つずつ説明してください。
秘密の文字はあなたが安全に作り、公開画面やGitHubへ書かないでください。
まだ本番公開はしないでください。
```

AIの説明どおり、スプレッドシートの「拡張機能」→「Apps Script」を開きます。
コードを貼り、「デプロイ」→「新しいデプロイ」→「ウェブアプリ」を選びます。

### 3. 管理画面を上から進める

`/admin/` を開き、1から5まで番号順に進めます。

1. 大会を選びます。
2. 募集ページを書きます。
3. 最初の1回だけ接続情報を入れます。
4. 「申込選手を読み込む」を押します。
5. 赤・青の選手と試合順を決めます。

### 対戦カードを作る

1. 「＋ 試合を追加」を押します。
2. 赤コーナーと青コーナーの選手を選びます。
3. 順番を変えるときは「一つ上へ」「一つ下へ」を押します。
4. 赤と青を逆にするときは「赤青を入れ替える」を押します。
5. 全試合を見直してから「確認した対戦カードを大会画面へ反映」を押します。

最後のボタンを押すまでは、大会画面の内容は変わりません。間違えても何度でも直せます。

## 申し込み後に原本へ入る内容

受付番号、所属ジム、選手名、ふりがな、性別、学年、年齢、参加区分、身長、希望体重、試合経験、戦績、
2試合可否、意気込み、入場曲の有無、入場曲URL、使用許可のある顔写真URL、広報同意、連絡先氏名、電話、
メール、申込日時、大会IDです。

## 大事な安全ルール

- 原本は非公開のままにします。
- Tournament OSへ電話番号・メール・保護者名を出しません。
- Googleへの保存が一時的に失敗しても、申込はTournament OS側に「未反映」として残します。
- 「未反映」がある場合は、大会運営用名簿と原本を受付番号で照合します。
- 操作キー、秘密の文字、パスワードはLINEやメールで送らず、GitHubにも書きません。
