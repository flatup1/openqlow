# 階級分け（体重の区分）の要件（2026-10-19）

## オーナーの決定（原文）
- 「階級分けをしたいとのこと。申込の時点で」
- 「こちらで −37 −40 など提示し、選手がエントリー時に選択肢を選ぶ方式にしました」

## 決まったこと
- 階級は、**主催者（シートの「設定」タブ）が選択肢を出します**。たとえば「-37」「-40」…。
- **選手が、申込のときに、選択肢から選びます。**（A/Bクラスと同じ「選手が自分で選ぶ」やり方）
- A/Bクラス（勝ち数）とは**別の項目**です。両方とも、申込画面に出ます。

## まだ決まっていないこと（答えがないので、おすすめを仮に採用。あとで変えられます）
| 項目 | 仮に採用するおすすめ |
|---|---|
| 階級の選択肢の一覧 | **オーナーに聞く**（「-37」「-40」のあと、何kgまでか。「+」の階級があるか） |
| 書き方 | 「-37kg」のように、kgを付けて見せる（選択肢は、設定の1つのマスに、読点「、」か改行で区切って書く） |
| 切りかえ | 「階級分け」あり／なし（なしのとき、申込画面にも名簿にも出ない） |
| 申込画面 | 必ず選ぶ（A/Bクラスと同じ。選ばないと、赤い言葉で止まる） |
| 体重からの目安 | 出さない（選手が選ぶだけ。あとで追加できる） |
| シートへの保存 | 「申込原本」と「OS取込用」の、いちばん右に「階級」の列を足す。古い表は、見出しを自動で足す |
| 準備画面（名簿・対戦カード） | 名簿に「階級：-40kg」と言葉で出す。階級がちがう組み合わせは、**赤の注意（保存は止めない）** |
| 当日画面（1試合ずつ・一覧） | 階級を言葉で出す |
| ほかのジム用の入力画面・ZIP | 「階級」の列を足す（なければ今までと同じ） |

## 作る順番（A/Bクラスと同じ作り方）
1. Google受付スクリプト（設定の行・列・読み書き・古い表の自動アップグレード）
2. 公開の設定（受付をつくる画面が、階級の選択肢を読む）
3. 申込画面（選択肢・必須・赤の言葉）
4. 準備画面（名簿・取り込み・対戦カードの注意）
5. 当日画面
6. テスト（単体・画面）と、マニュアル・ひな形の新しい版
7. 全部のテスト → 点検 → 公開（オーナーのMac）→ ひな形の入れ替え

## 注意
- A/Bクラスと同じく、ひな形の入れ替えと、**新しいコピーの作り直し**が必要です（古いコピーには、階級の行が入りません）。
- 今日の会長さんの作り直しは、A/Bクラスだけの版で進めます。階級分けは、別の枝で作ります（公開版は変えません）。

### A/Bクラスの文（案内の言葉）
- Aクラス（アマチュア3勝以上・トーナメント共通）：ジュニア90秒×2R／一般2分×2R（インターバル30秒）／首相撲5秒／蹴り足キャッチはワンアタック。※ワンマッチは顔面への膝蹴り禁止。※3勝以下の選手でも、会長・指導者の許可があればAクラスに出られる。
- Bクラス（アマチュア3勝以下）：ジュニア90秒×1R／一般2分×1R／首相撲なし・キャッチなし・膝蹴りなし・回転技なし。
- 食いちがい：案内は「Bクラス＝3勝以下」。オーナーの決定（2026-10-10）は「3勝0敗はA、2勝1敗はB」。→ **オーナーの決定（3勝ちょうどはA）をそのまま使う**。案内の言葉は、のちほど確認する。
- いまのアプリの文（Aクラスのルール「首相撲あり／膝蹴りあり／蹴り足キャッチ」）は、案内と少しちがう（案内は「顔面への膝蹴りは禁止」「首相撲5秒」）。設定の文は、シートで直せる。

**気をつけること（オーナー向け）**
- 新しい版を公開しても、**すでに配ったA/Bクラスの申込リンク**は、文が新しい初期の文に変わって見える（リンクに「初期の文」を入れていないため）。大会の前にリンクを作り直して送る。
- ひな形の入れかえ（プログラムとマニフェスト）をして、**新しいコピーを作り直す**。ひな形では「① 最初の設定」を押さない。
- **ひな形の「設定」タブの古い値を新しくする。** プログラムを入れかえても、書いてあるマスは書き換わらないので、古いひな形には「任意」と古いA/B文が残る。入れ替えページの「手順3」で B10〜B29 に貼る（または「設定」タブを消して作り直す）。しないと、学年・年齢・意気込みが「任意」のコピーが配られる。
- 古い版のシート（3.20261010.5）も受付はできる。階級分け・ロゴは使えない（セットアップ画面に黄色の説明が出る）。

- 取り込む名簿に「区分」「階級」の列があると、階級分けを使わない大会でも、その値が名簿に入り、札と赤い注意（⚠、止めない）が出る。使わない大会で出したくないときは、その列を消して取り込む。（直す画面で消す欄は、階級分けの大会にしか出ない。）
