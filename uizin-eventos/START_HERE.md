## 残っている作業

### ① 入場曲の赤13件をゼロにする ← **いちばん急ぐ**

**赤が1件でもあると、ダッシュボードが「開始しないでください」と警告し続けます。**

| 種類 | 件数 | どうする |
|---|---|---|
| 入場曲URLが**空欄** | **10件** | 本人に聞く。曲を使わないなら `入場曲` 欄に **`なし`** と書く（灰色＝対象外になり、赤から外れる） |
| Apple / YouTube **以外**のリンク | **3件** | Google広告リンク1・LINE1・Amazon Music1。Apple Music か YouTube のURLに貼り替える |

該当する No. は https://uizin-eventos.pages.dev/check/ を開けば**赤が一番上に並びます。**

**選手に送る文面（そのまま使えます）**

> 入場曲のURLを教えてください。**Apple Music のリンクが一番確実です**（YouTube でも大丈夫です）。
> 入場曲を使わない場合は「**なし**」とだけ返信してください。

> **なぜ急ぐか**: これは工数ではなく**日数**がかかる作業です。選手の返事待ちが発生します。
> 実質の締切は**9月20日ごろ**です。

### ② 対戦カードを `matches` タブに入れる ← **リハーサルの前提**

進行表の `matches` タブが **0件**です。このままだと試合を1つも進められません。

**確定を待たないでください。** 暫定でいいので入れてください。変わったら書き換えて、`/op/` の「取り込み直す」を押すだけで反映されます。

1行 = 1試合。列はこうです。

```
no,class,rule,rounds,round_seconds,break_seconds,red_name,red_team,red_record,red_comment,blue_name,blue_team,blue_record,blue_comment,note
1,キッズ,アマチュアキック,2,1:30,60,赤の選手名,赤の所属,赤の戦績,赤の意気込み,青の選手名,青の所属,青の戦績,青の意気込み,
```

書き方の詳細: [SPREADSHEET_TEMPLATE.md](docs/SPREADSHEET_TEMPLATE.md)

### ③ `venue` と `start_at` を埋める

`event` タブの2か所が空です。会場名と開始時刻を入れてください。

## JIN から受け取る必要があるもの

**これらはリポジトリに入っていません（入れてはいけないものです）。**

| # | 受け取るもの | 何に使う |
|---|---|---|
| 1 | **操作キー**（OPERATOR_KEY） | `/op/` で進行を操作するため。**MC・表示・音響の端末には入れない** |
| 2 | **進行表スプレッドシートの編集権限** | 対戦カードと入場曲を入れるため |
| 3 | GitHub `flatup1/openqlow` への書き込み権限 | コードを直す場合のみ。**当日は不要** |
| 4 | Cloudflare アカウント | 再公開する場合のみ。**当日は不要** |

> **申込の原本スプレッドシート（メール・電話番号・保護者氏名入り）は受け取らないでください。**
> EventOS に繋いではいけないもので、触る必要もありません。

## 開発する場合だけ（当日運用には不要）

```bash
git clone https://github.com/flatup1/openqlow.git
cd openqlow
git checkout claude/uizin-eventos-v1-6f2l8p
cd uizin-eventos
npm ci
npm run verify        # テスト78件 + ビルド。これが通らない状態で push しない
```

必要なもの: **Node.js 22以上**。依存パッケージは**ゼロ**です（Next.js と wrangler 以外に何も入れていません）。

本番へ再公開するとき（**JIN の承認後**）:

```bash
npm run go-live -- <進行表のシートID>
```
