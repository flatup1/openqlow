# UIZIN EventOS v1.0

大会運営者が一人でも、迷わず・止まらず・ミスなく大会を最後まで進行するための Event Operating System。

**v1の絶対ルール: 大会を止めないことだけに集中する。**
AI実況・DJ自動化・Apple Music自動再生・OBS連携は、すべて Version 2 以降。大会当日の機能追加は禁止。

---

## 1分で分かる仕組み

```
                   Google スプレッドシート（v1唯一のCMS）
                    event / matches / music の3シート
                                │ 取り込みは操作者が押したときだけ
                                ▼
   ┌───────────────────────────────────────────────────────┐
   │  Cloudflare Worker + Durable Object「EventRoom」       │
   │  ここが イベントステート = 唯一の真実。自動保存。         │
   └───────────────┬───────────────────────────────────────┘
       書き込みは  │  配信は WebSocket で全画面へ（実測 12ms）
       操作者だけ  │
   ┌───────────────┴───────────────────────────────────────┐
   │ ダッシュボード │ MC │ 表示画面 │ Event Mix │ 音源チェック │
   │  操作できる    │ ← ここから右はすべて完全に閲覧専用 →     │
   └───────────────────────────────────────────────────────┘
```

- 画面同士は**直接通信しない**。「次へ」「停止」「再開」はすべてイベントステートを書き換えるだけで、
  全画面はそれを監視しているだけ。
- タイマーは「残り秒」を保存しない。**開始時刻（サーバー時刻）と積算だけ**を保存して、
  各画面がその場で計算する。だから再読み込みしても、遅れて繋いだ端末でも、必ず同じ値になる。
- 保存ボタンは無い。すべて自動保存。

## 5つの画面

| URL | 誰が見る | 何が出る | 操作 |
|---|---|---|---|
| `/op/` | オペレーター（あなただけ） | 現在の試合・次の試合・選手情報・意気込み・次へ・停止 | **できる** |
| `/mc/` | MC | 読み上げる文章だけを大きく | 一切できない（ボタン0個） |
| `/screen/` | 大型モニター | 対戦カードと意気込みだけ | 一切できない（ボタン0個） |
| `/mix/` | 音響 | 今の曲・次の曲・あと何秒 | 一切できない（再生は人が押す） |
| `/check/` | 前日準備 | 音源の緑/黄/赤。赤がゼロになるまで開始しない | 検査の実行だけ操作者 |

## はじめかた

```bash
npm install
npm run verify      # テスト63件 → 画面のビルド（TypeScript検査込み）まで通す

# 個別に走らせるとき
npm run test        # 中核ロジックのテスト（依存ゼロ・ネットワーク不要）
npm run build       # 画面を out/ に静的書き出し
npm run typecheck   # tsc 単体（Next の型が要るので build のあとに実行する）
```

ローカルで通しで動かす（3端末同期の実機確認）:

```bash
npm run worker:dev                # 別ターミナル
node scripts/rehearsal.mjs        # 模擬大会スモークテスト
```

公開手順は [docs/DEPLOY.md](docs/DEPLOY.md)。

## v1 の完成条件（4つ）

| 条件 | 確認方法 | 状態 |
|---|---|---|
| 3端末同時同期で問題なく動作する | `node scripts/rehearsal.mjs` | 実測 11〜12ms で3端末一致 |
| 30分の模擬大会を完走できる | `npm run test`（rehearsal.test.ts） | 5試合・30.1分・「次へ」26回で完走 |
| 緊急停止と復元が動作する | 同上 ＋ スモークテスト | 停止中は残り時間が1msも減らない／再読み込みで完全復元 |
| 音源チェックで赤が残らない | `/check/` 画面 | 赤>0 のあいだダッシュボードに警告 |

**これ以外の機能追加は、すべて Version 2 以降に回すこと。**
